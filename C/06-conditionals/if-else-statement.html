The if-else Statement in C

🟢 Beginner Level | Binary C Decision Branching

📖 Definition

The if-else statement in C evaluates a scalar expression. If non-zero (true), the if block executes; if 0 (false), the else block executes.

🤔 Purpose

Enables low-level C software to handle alternative error handling paths—such as validating memory allocation success vs logging an out-of-memory error.

🌐 Multilingual Explanations

English

The if-else construct provides two alternative execution branches in C. Either the if block or the else block runs, never both.

Hindi

C mein if (condition) non-zero aane par if block chalta hai, varna 0 hone par else block chalta hai.

Marathi

Condition 0 (false) aslyas else madhla code execute hoto.

Hinglish

Binary error check: if (ptr != NULL) { process(); } else { logError(); } pattern use karein.

📝 Syntax & Parameters

if (condition) {
    // Executed if condition != 0
} else {
    // Executed if condition == 0
}

⚡ Execution Flow

  1. Evaluate (condition).
  2. If non-zero, execute if block.
  3. If 0, execute else block.

💡 Progressive Examples

Example 1: Even or Odd Checker

#include <stdio.h>

int main(void) {
    int num = 7;

    if (num % 2 == 0) {
        printf("%d is Even\n", num);
    } else {
        printf("%d is Odd\n", num);
    }
    return 0;
}

🖥️ Expected Output

7 is Odd

🔍 Line-by-Line Code Breakdown

  • num % 2 == 0: Evaluates 7 % 2 (yields 1, false). Executes else block.

⚠️ Variations & Edge Cases

Single statement blocks do not strictly require braces { }, but using them prevents dangling else bugs.

❌ Common Beginner Mistakes

Dangling Else Bug: Unbraced nested if statements associate the else with the nearest preceding if.

🛠️ Real-World Practical Usage

Hardware sensor status validation.

🎯 Tiered Practice Exercises

  1. Beginner: Write a C program checking if a number is positive or negative using `if-else`.
  2. Intermediate: Write an `if-else` block checking return codes of C library functions.
  3. Advanced: Create an `if-else` check validating memory allocation alignment.
