06. The Ternary Operator in C

🟢 Difficulty: Beginner | Inline Expression Branching & Conditional Assignment

📖 Definition

The ternary operator (? :) is C's only three-operand operator. It evaluates a condition expression and returns one of two sub-expressions: the first if the condition is non-zero (true), or the second if the condition is zero (false).

🎯 Why It Is Used

  • Inline Expression Assignment: Initializing const variables conditionally at declaration time (e.g. const int max = (a > b) ? a : b;).
  • Compact Formatting: Conditionally picking text labels inside printf() format calls without bulky if-else structures.

⚙️ How It Works: Expression vs Statement

Unlike if-else (which is a statement that controls execution flow), the ternary operator is an expression that produces a concrete value. ISO C evaluates only the selected branch (short-circuit property for ternary expressions).

📝 Syntax

result_variable = (condition_expression) ? value_if_true : value_if_false;

🔀 Type Promotion in Ternary Branches

Both return branch expressions (expr1 and expr2) in a ternary operator are converted to a single common data type following usual arithmetic conversions! For example, in (flag) ? 5 : 2.5, the integer 5 is promoted to double 5.0 so the overall expression returns a double.

🌱 Beginner Example: Finding Maximum Value

#include <stdio.h>

int main(void) {
    int num1 = 45, num2 = 78;
    int max = (num1 > num2) ? num1 : num2;

    printf("The larger number between %d and %d is %d.\n", num1, num2, max);
    return 0;
}

🌼 Intermediate Example: Inline Pluralization in Output

#include <stdio.h>

void print_item_count(int count) {
    // Uses ternary operator to format singular vs plural word ending
    printf("You have %d %s in your cart.\n",
           count, (count == 1) ? "item" : "items");
}

int main(void) {
    print_item_count(1);
    print_item_count(5);
    return 0;
}

🌲 Advanced Example: Side Effect Pitfalls in Ternary Macros

#include <stdio.h>

// UNSAFE MACRO (Evaluates argument twice!)
#define UNSAFE_MAX(a, b) ((a) > (b) ? (a) : (b))

int get_next_val(int *seed) {
    printf("[Side Effect] Fetching next val...\n");
    return (*seed)++;
}

int main(void) {
    int seed1 = 10, seed2 = 20;

    // Unsafe macro evaluates get_next_val(&seed2) TWICE!
    int result = UNSAFE_MAX(get_next_val(&seed1), get_next_val(&seed2));
    printf("Result: %d, seed2 final value: %d\n", result, seed2);

    return 0;
}

🔍 Line-by-Line Explanation

  • (num1 > num2) ? num1 : num2: Evaluates 45 > 78 (false), so it returns num2 (78).
  • (count == 1) ? "item" : "items": Evaluates inline to select string literal without requiring separate if-else blocks.
  • UNSAFE_MAX(...): Demonstrates side-effect trap when ternary macros re-evaluate function arguments.

💻 Expected Terminal Output

The larger number between 45 and 78 is 78.
You have 1 item in your cart.
You have 5 items in your cart.
[Side Effect] Fetching next val...
[Side Effect] Fetching next val...
[Side Effect] Fetching next val...
Result: 21, seed2 final value: 22

⚠️ Common Mistakes & Pitfalls

  • Over-nesting Ternary Operators: Writing complex expressions like a ? b : c ? d : e ? f : g degrades readability severely. Use if-else for complex logic.
  • Type Mismatch Between Branches: Returning incompatible types in true and false branches can trigger truncation warnings.

📌 Important Rules & Limitations

  • Ternary operator produces an rvalue expression, not a statement.
  • Both branches undergo usual arithmetic conversion to match types.
