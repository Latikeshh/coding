01. The If Statement in C

🟢 Difficulty: Beginner | Single-Branch Conditional Execution & Truth Evaluation

📖 Definition

The if statement is the most fundamental decision-making control structure in C. It evaluates a specified condition expression inside parentheses; if the condition evaluates to any non-zero value (true), the associated code block is executed. If the condition evaluates to zero (false), the block is bypassed.

🎯 Why It Is Used

  • Selective Execution: Running code only when specific criteria are satisfied (e.g., verifying user credentials or checking temperature thresholds).
  • Error & Guard Checking: Checking for invalid inputs or null pointers before attempting memory access.

⚙️ How It Works

The compiler emits conditional jump instructions (such as jz or jne in x86 assembly). If the condition expression evaluates to non-zero, execution continues sequentially into the block; otherwise, the instruction pointer jumps past the closing brace }.

📝 Syntax

if (condition_expression) {
    // Code executed ONLY if condition_expression is non-zero (true)
}

🔀 Single-Statement vs Compound Block

In C, if a block contains only one statement, curly braces {} are technically optional. However, omitting braces is considered bad practice because adding a second line later creates a severe logic bug!

🌱 Beginner Example

#include <stdio.h>

int main(void) {
    int age = 20;

    if (age >= 18) {
        printf("You are eligible to vote!\n");
    }
    return 0;
}

🌼 Intermediate Example: Multiple Guard Checks

#include <stdio.h>

int main(void) {
    int score = 92;

    if (score >= 90) {
        printf("Grade: A\n");
        printf("Congratulations on achieving honors!\n");
    }

    if (score < 60) {
        printf("Grade: F - Remedial coursework required.\n");
    }
    return 0;
}

🌲 Advanced Example: Memory Guard Checks in Pointer Operations

#include <stdio.h>
#include <stdlib.h>

void process_buffer(int *buffer, size_t size) {
    // Guard Clause using 'if' to prevent segmentation fault
    if (buffer == NULL) {
        printf("Error: Null pointer passed to process_buffer!\n");
        return;
    }

    if (size == 0) {
        printf("Warning: Buffer size is 0. Nothing to process.\n");
        return;
    }

    printf("Processing %zu buffer elements cleanly...\n", size);
}

int main(void) {
    int *valid_buf = (int*) malloc(5 * sizeof(int));

    process_buffer(NULL, 10);        // Triggers null guard
    process_buffer(valid_buf, 0);   // Triggers size guard
    process_buffer(valid_buf, 5);   // Executes successfully

    free(valid_buf);
    return 0;
}

🔍 Line-by-Line Explanation

  • if (buffer == NULL): Evaluates whether the pointer address is zero. If true, prints error and exits function safely.
  • if (size == 0): Evaluates if byte size parameter is zero to avoid illegal zero-length loops.
  • if (age >= 18): Relational test returning 1 for 20 >= 18, entering the block.

💻 Expected Terminal Output

Error: Null pointer passed to process_buffer!
Warning: Buffer size is 0. Nothing to process.
Processing 5 buffer elements cleanly...

⚠️ Common Mistakes & Pitfalls

  • Putting a Semicolon After the Condition: Writing if (x > 5); { printf("High"); } terminates the if statement immediately! The block runs unconditionally regardless of x.
  • Accidental Assignment = Instead of Comparison ==: Writing if (x = 0) assigns 0 to x, which evaluates to false!
  • Omitting Braces {}: Writing: 
    if (is_admin)
    log_access();
    grant_admin_privileges(); // RUNS UNCONDITIONALLY! NOT PART OF IF!

📌 Important Rules & Limitations

  • Conditions in C do not require a boolean type; any non-zero integer is true, and 0 is false.
  • Always use explicit curly braces {} even for single-line blocks.
