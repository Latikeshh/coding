If-Else Statement in C in C Language

🟢 Beginner

📖 Definition

An if-else statement provides two mutually exclusive execution paths.

⚡ Code Example

#include <stdio.h>
int main() {
    int num = 7;
    if (num % 2 == 0) {
        printf("Even\n");
    } else {
        printf("Odd\n");
    }
    return 0;
}
