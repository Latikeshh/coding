The if Statement in C

🟢 Beginner Level | C Control Structure

📖 Definition

The if statement in C controls execution flow by evaluating a conditional expression inside parentheses (condition). If the expression evaluates to any non-zero value, it is considered true and the inner block executes.

🤔 Purpose

In low-level programming, system checks must validate conditions—such as verifying file handle pointers or validating non-negative memory allocation sizes—before proceeding.

🌐 Multilingual Explanations

English

In ISO C, there was historically no dedicated Boolean type prior to C99 (<stdbool.h>). Any numeric expression evaluating to 0 is false; any non-zero integer (like 1, -5, or 100) evaluates as true in an if condition.

📝 Syntax & Parameters

if (condition) {
    // Statement block executed if condition != 0
}

⚡ Execution Flow

  1. The compiler evaluates (condition).
  2. If the scalar value is non-zero (true), execution enters the { ... } block.
  3. If the value equals 0 (false), the compiler jumps past the closing brace.

💡 Progressive Examples

Example 1: Basic Non-Zero Check

#include <stdio.h>

int main(void) {
    int sensorSignal = 1;

    if (sensorSignal) {
        printf("Sensor active! Reading telemetry data...\n");
    }
    return 0;
}

Example 2: Pointer Validation

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *ptr = malloc(sizeof(int) * 10);

    if (ptr != NULL) {
        printf("Memory allocation successful at address: %p\n", (void*)ptr);
        free(ptr);
    }
    return 0;
}

🖥️ Expected Output

Sensor active! Reading telemetry data...
Memory allocation successful at address: 0x7ff8a0b04080

🔍 Line-by-Line Code Breakdown

  • int *ptr = malloc(...): Requests Heap memory space.
  • if (ptr != NULL): Verifies pointer is not NULL (0).
  • printf(...): Displays success output.
  • free(ptr): Deallocates allocated memory block.

⚠️ Variations & Edge Cases

In C99+, including #include <stdbool.h> provides type bool with constants true (1) and false (0).

❌ Common Beginner Mistakes

Assignment inside `if`: Writing if (status = 0) assigns 0 to status (evaluating to false!), whereas if (status == 0) correctly checks equality.

🛠️ Real-World Practical Usage

Defensive program checks before dereferencing pointers:

void processBuffer(char *buf) {
    if (buf == NULL) {
        return; // Guard clause against null pointer dereference
    }
    printf("Buffer payload: %s\n", buf);
}
