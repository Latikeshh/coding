# Introduction to CSS

> 🟢 Beginner

## 📖 Definition

CSS is a style language used to design web pages. It controls how HTML elements look and behave on the page.

## 🤔 Why Do We Use It?

CSS helps make pages clear, attractive, and easier to use. It makes headings stand out, paragraphs readable, and content easier to scan.

## 🧠 Simple Explanation

If HTML is the building structure, CSS is the paint, furniture, and layout. It makes the page look like a finished website instead of a plain document.

## 📝 Syntax

```css
body {
  background-color: white;
  color: black;
  font-family: Arial, sans-serif;
}
```

## 💡 Example

```css
body {
  background-color: #f5f5f5;
  color: #222;
  font-family: Arial, sans-serif;
}

h1 {
  color: darkgreen;
}
```

## 🌐 HTML + CSS Example

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Intro Page</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>My Travel Notes</h1>
  <p>I am learning how CSS changes the design of a page.</p>
</body>
</html>
```

```css
body {
  background-color: #f5f5f5;
  color: #222;
  font-family: Arial, sans-serif;
}

h1 {
  color: darkgreen;
}
```

## 👀 What You Will See

The page gets a light background, a readable font, and a green heading. The content appears cleaner and easier to read.

## 🧪 Try It Yourself

Change the background color and heading color in the example. See how quickly the page mood changes.

## ✅ Remember

- CSS makes pages look more polished.
- CSS can be written in a separate file to keep code organized.
- You can style many elements at once by using a selector.
