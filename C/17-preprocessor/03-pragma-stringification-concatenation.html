03. #pragma, Stringification (#) & Token Concatenation (##)

🔴 Difficulty: Advanced | Advanced Preprocessor Operators, Predefined Diagnostic Macros & #pragma

📖 Definition

The stringification operator (#) converts a macro parameter into a double-quoted string literal. The token concatenation operator (##) merges two separate tokens into a single combined token during macro expansion. The #pragma directive provides compiler-specific control instructions (e.g. #pragma once for header guards).

🎯 Why It Is Used

  • Printing Variable Names & Values (#): Creating assertion or debugging macros that print the literal source code expression along with its evaluated value.
  • Automatic Code Generation (##): Generating repetitive variable names, function stubs, or table lookup identifiers programmatically.
  • Pre-Defined Diagnostic Context: Printing source file names (__FILE__), line numbers (__LINE__), compilation dates (__DATE__), and function names (__func__) during error logging.

⚙️ How It Works: Built-in Preprocessor Macros

📝 Syntax

// 1. Stringification Operator (#)
#define PRINT_EXPR(expr) printf(#expr " = %d\n", (expr))

// 2. Token Concatenation Operator (##)
#define MAKE_VAR(prefix, id) prefix ## _ ## id

// 3. Modern Header Protection Directive
#pragma once

🔀 #pragma once vs Standard #ifndef Guards

While standard #ifndef HEADER_H include guards work across all C compilers, modern C compilers (GCC, Clang, MSVC) support #pragma once. Placing #pragma once at the top of a header file achieves the exact same header protection with faster compilation times.

🌱 Beginner Example: Diagnostic File Location Logging

#include <stdio.h>

void log_checkpoint(const char *msg) {
    printf("[%s:%d] Checkpoint in %s(): %s\n",
           __FILE__, __LINE__, __func__, msg);
}

int main(void) {
    printf("Compiled on: %s at %s\n", __DATE__, __TIME__);
    log_checkpoint("System Initialized");
    return 0;
}

🌼 Intermediate Example: Printing Expressions with #

#include <stdio.h>

// Converts 'expr' into string literal using #
#define DBG_PRINT_INT(expr) printf("[DEBUG] Expression '%s' evaluates to: %d\n", #expr, (expr))

int main(void) {
    int x = 10, y = 20;

    DBG_PRINT_INT(x + y);       // Prints: Expression 'x + y' evaluates to: 30
    DBG_PRINT_INT(x * 5 - y);   // Prints: Expression 'x * 5 - y' evaluates to: 30
    return 0;
}

🌲 Advanced Example: Token Concatenation ## Stubs

#include <stdio.h>

// Generates variable declarations like: int sensor_temp = 100;
#define DECLARE_SENSOR(type, name, init_val) type sensor_ ## name = (init_val)

int main(void) {
    DECLARE_SENSOR(int, temp, 25);     // Declares 'int sensor_temp = 25;'
    DECLARE_SENSOR(double, voltage, 3.3);// Declares 'double sensor_voltage = 3.3;'

    printf("Sensor Temp   : %d C\n", sensor_temp);
    printf("Sensor Voltage: %.1lf V\n", sensor_voltage);
    return 0;
}

🔍 Line-by-Line Explanation

  • #expr: Converts raw text token passed to DBG_PRINT_INT(x + y) into double-quoted string "x + y".
  • sensor_ ## name: Merges token sensor_ with token temp to produce new identifier sensor_temp.
  • __FILE__, __LINE__, __func__: Automatically injects current source filename, line number, and function signature at compile time.

⚠️ Common Mistakes & Pitfalls

  • Creating Invalid Identifiers with ##: Concatenating tokens that form invalid C syntax (e.g. 1 ## + 2) causes compilation errors.
  • Nested Macro Expansion with #: The stringification operator # prevents inner macro parameters from expanding. Use a double-expansion helper macro when stringifying pre-defined macros like __LINE__!

📌 Important Rules & Limitations

  • # turns a macro argument into a string literal.
  • ## glues two separate tokens into a single token.
  • #pragma once is widely supported by modern compilers as an alternative to header include guards.
