# Padding

> 🟢 Beginner

## 📖 Definition

Padding is the space inside an element, between the element's content and its border.

## 🤔 Why Do We Use It?

Padding makes content feel less crowded and gives elements more breathing room.

## 🧠 Simple Explanation

If margin is space outside the box, padding is the space inside the box around the text.

## 📝 Syntax

```css
.box {
  padding: 20px;
}
```

## 💡 Example

```css
.button {
  padding: 12px 20px;
  background-color: #2d6cdf;
  color: white;
}
```

## 🌐 HTML + CSS Example

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Padding Example</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <button class="button">Read More</button>
</body>
</html>
```

```css
.button {
  padding: 12px 20px;
  background-color: #2d6cdf;
  color: white;
}
```

## 👀 What You Will See

The button text has more space around it, making the button easier to click and read.

## 🧪 Try It Yourself

Increase the padding on a button and notice how the button becomes larger without changing the text.

## ✅ Remember

- Padding adds space inside the element.
- Margin adds space outside the element.
- Good spacing makes a page feel cleaner and easier to use.
