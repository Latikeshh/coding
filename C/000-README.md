# 🧠 Learn C

C is a powerful programming language used for system software, embedded systems, and many fast, efficient programs. It is a strong language for beginners because it teaches how code really works behind the scenes.

> 🟢 **Beginner-friendly:** start small, write simple programs, and test them in a terminal or compiler.

## 📖 What You Will Learn

- How a C program is written and run
- How variables, values, and data types work
- How to print output and read input
- How conditions and loops make programs decide and repeat
- How functions help organize code
- How to build confidence with small, practical examples

## 📚 Current C Content

This folder currently contains the C learning homepage. More C lessons will be added here as they are created.

## 🧪 How to Study C

1. Read the idea carefully.
2. Copy the example into a file like `main.c`.
3. Run the program and look at the result.
4. Change one small part and observe what happens.
5. Try the practice idea before moving on.

## ✅ Beginner Mindset

C is not about memorizing everything at once. The goal is to understand the basics clearly and practice them often.

- Start with small programs.
- Learn one idea at a time.
- Check errors carefully.
- Practice by writing code yourself.
