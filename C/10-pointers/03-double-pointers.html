03. Double Pointers & Multi-Level Indirection

🔴 Difficulty: Advanced | Pointers to Pointers (**ptr), Dynamic 2D Arrays & Pointer Mutation

📖 Definition

A double pointer (pointer to a pointer) is a pointer variable declared with two asterisks (**ptr) that stores the memory address of another pointer variable. Dereferencing once (*pptr) yields the intermediate pointer address; dereferencing twice (**pptr) yields the target data value.

🎯 Why It Is Used

  • Mutating Pointer Parameters inside Functions: Allowing a function to modify a caller's pointer variable (e.g. allocating heap memory inside a helper function or modifying a linked list head pointer).
  • Dynamic 2D Heap Allocations: Allocating ragged 2D arrays via an array of row pointers (int **matrix).
  • Command Line Argument Vector: Handling command line string arrays (char **argv).

⚙️ How It Works: Multi-Level Indirection Chain

[ Variable: val = 50 ]  <---  [ Pointer: ptr = &val ]  <---  [ Double Pointer: pptr = &ptr ]
(Address: 0x1000)             (Address: 0x2000)               (Address: 0x3000)
                              (Stores: 0x1000)                (Stores: 0x2000)
  • pptr contains 0x2000
  • *pptr yields 0x1000 (the address stored in ptr)
  • **pptr yields 50 (the value stored in val)

📝 Syntax

int val = 50;
int *ptr = &val;     // Single pointer storing address of val
int **pptr = &ptr;   // Double pointer storing address of ptr

**pptr = 100; // Modifies 'val' to 100 through two levels of indirection!

🔀 Caller Pointer Mutation Function Pattern

Just as mutating an int in a caller requires passing an int *, mutating an int * pointer in a caller requires passing an int ** double pointer!

🌱 Beginner Example: Dereferencing Chain Breakdown

#include <stdio.h>

int main(void) {
    int x = 42;
    int *p = &x;
    int **pp = &p;

    printf("x value                : %d\n", x);
    printf("*p (via single ptr)    : %d\n", *p);
    printf("**pp (via double ptr)  : %d\n", **pp);

    printf("p address (RAM)        : %p\n", (void*)p);
    printf("*pp address stored     : %p\n", (void*)*pp);

    return 0;
}

🌼 Intermediate Example: Allocating Heap Buffer via Helper Function

#include <stdio.h>
#include <stdlib.h>

// Accepts double pointer to allocate heap buffer and assign to caller's pointer!
void allocate_buffer(int **out_ptr, size_t count) {
    if (out_ptr == NULL) return;

    *out_ptr = (int*)malloc(count * sizeof(int));
    if (*out_ptr != NULL) {
        for (size_t i = 0; i < count; i++) {
            (*out_ptr)[i] = (int)(i + 1) * 10;
        }
    }
}

int main(void) {
    int *my_array = NULL;
    allocate_buffer(&my_array, 5); // Pass address of pointer 'my_array'!

    if (my_array != NULL) {
        printf("Heap Buffer Allocated Successfully:\n");
        for (int i = 0; i < 5; i++) {
            printf("%d ", my_array[i]);
        }
        printf("\n");
        free(my_array);
    }
    return 0;
}

🌲 Advanced Example: Dynamic 2D Ragged Matrix Allocation

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    size_t rows = 3;
    size_t cols = 4;

    // 1. Allocate array of row pointers (int*)
    int **matrix = (int**)malloc(rows * sizeof(int*));
    if (matrix == NULL) return 1;

    // 2. Allocate each individual row buffer
    for (size_t r = 0; r < rows; r++) {
        matrix[r] = (int*)malloc(cols * sizeof(int));
        for (size_t c = 0; c < cols; c++) {
            matrix[r][c] = (int)(r * 10 + c);
        }
    }

    // 3. Print 2D matrix
    printf("=== Dynamic 2D Matrix (Double Pointer) ===\n");
    for (size_t r = 0; r < rows; r++) {
        for (size_t c = 0; c < cols; c++) {
            printf("%2d ", matrix[r][c]);
        }
        printf("\n");
    }

    // 4. Clean up memory in REVERSE order!
    for (size_t r = 0; r < rows; r++) {
        free(matrix[r]); // Free each row first
    }
    free(matrix); // Free outer row pointer array
    return 0;
}

🔍 Line-by-Line Explanation

  • allocate_buffer(&my_array, 5);: Passes address of single pointer variable my_array.
  • *out_ptr = malloc(...);: Modifies caller's my_array variable to point to newly allocated heap memory.
  • int **matrix = malloc(rows * sizeof(int*));: Allocates a contiguous array of row pointers on the heap.
  • free(matrix[r]); free(matrix);: Demonstrates proper sequential deallocation to avoid memory leaks.

⚠️ Common Mistakes & Pitfalls

  • Passing Single Pointer instead of Double Pointer: Writing allocate_buffer(my_array, 5) passes a pointer copy by value, leaving caller's my_array as NULL and leaking heap memory.
  • Freeing Outer Pointer Before Rows: Calling free(matrix) before freeing row buffers free(matrix[r]) loses row addresses, creating unrecoverable heap memory leaks.

📌 Important Rules & Limitations

  • To modify a single pointer variable inside a function, pass its address as a double pointer (&ptr).
  • Always deallocate dynamic 2D double-pointer matrices in reverse allocation order (rows first, outer array last).
