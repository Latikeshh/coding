# 🧠 Learn C

C is a powerful, low-level programming language used for operating systems, embedded hardware, compilers, and high-performance applications. It provides direct memory access and helps you understand how computers work under the hood.

> 🟢 **Beginner-friendly:** learn step by step from basic syntax, variables, and loops to functions, pointers, and memory management.

## 📖 What You Will Learn

- Setting up GCC compiler and running C programs
- C program structure, syntax, and `main()` function
- Data types, variables, and format specifiers (`printf`, `scanf`)
- Decision making with `if/else` and loops (`for`, `while`)
- Reusable logic with functions
- Arrays, strings, pointers, and memory addresses
- Custom data types using `struct`
- CLI mini projects in C

## 🧪 Practice Routine

1. Read the explanation and code example.
2. Type the C code into a `.c` file using VS Code or your preferred editor.
3. Compile using `gcc filename.c -o program` and run the executable.
4. Experiment by modifying variables and logic.
5. Complete the practice tasks.

## ✅ Progress Checklist

- [ ] I can compile and run C programs using GCC.
- [ ] I understand primitive data types and format specifiers.
- [ ] I can read user input with `scanf` and display formatted output with `printf`.
- [ ] I can write functions and control execution with loops and conditionals.
- [ ] I understand arrays and string null-terminators (`\0`).
- [ ] I understand memory addresses (`&`) and pointers (`*`).
- [ ] I can group related data into a `struct`.
