# Text Styling

> 🟢 Beginner

## 📖 Definition

Text styling in CSS changes how text looks, such as color, size, weight, alignment, and spacing.

## 🤔 Why Do We Use It?

Good text styling helps readers understand the page and makes content easier to scan.

## 🧠 Simple Explanation

Text is one of the most important parts of a webpage. CSS helps you decide how it should look, just like choosing a font and font size in a document.

## 📝 Syntax

```css
p {
  color: #333;
  font-size: 18px;
  text-align: center;
}
```

## 💡 Example

```css
h1 {
  color: #1d3557;
  text-align: center;
}

p {
  font-size: 18px;
  line-height: 1.6;
}
```

## 🌐 HTML + CSS Example

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Text Styling</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>My Daily Routine</h1>
  <p>I study, practice coding, and take short breaks to stay focused.</p>
</body>
</html>
```

```css
h1 {
  color: #1d3557;
  text-align: center;
}

p {
  font-size: 18px;
  line-height: 1.6;
}
```

## 👀 What You Will See

The heading is centered and dark blue, while the paragraph has a comfortable size and line spacing.

## 🧪 Try It Yourself

Change the text alignment to the left and increase the paragraph font size.

## ✅ Remember

- `text-align` controls horizontal alignment.
- `font-size` sets the size of text.
- `line-height` improves readability by making lines easier to follow.
