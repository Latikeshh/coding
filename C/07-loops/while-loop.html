The while Loop in C Programming

🟢 Beginner Level | Pre-tested Condition Loop

📖 Definition

The while loop in C tests an expression prior to each iteration. The loop body executes repeatedly as long as the expression evaluates to a non-zero value.

🤔 Purpose

Used when iteration count depends on dynamic runtime events—such as reading characters from a file stream until EOF is encountered.

🌐 Multilingual Explanations

English

A while (condition) tests the condition first. If false (0) initially, the loop body runs zero times.

Hinglish

Stream reading pattern: while ((ch = getchar()) != EOF) use hota hai.

📝 Syntax & Parameters

while (condition) {
    // Body statements
}

⚡ Execution Flow

  1. Evaluate (condition).
  2. If non-zero, execute body statements.
  3. Repeat from Step 1 until condition evaluates to 0.

💡 Progressive Examples

Example 1: Reading File Characters until EOF

#include <stdio.h>

int main(void) {
    int ch;
    // Reading from standard input
    printf("Type characters (Ctrl+D / Ctrl+Z to stop):\n");
    while ((ch = getchar()) != EOF) {
        putchar(ch);
    }
    return 0;
}

🖥️ Expected Output

Type characters (Ctrl+D / Ctrl+Z to stop):
Hello C World!
Hello C World!

🔍 Line-by-Line Code Breakdown

  • (ch = getchar()) != EOF: Assigns next input char to ch and tests against EOF marker.

⚠️ Variations & Edge Cases

Always ensure the loop control variable is modified within the body to avoid infinite loops.

❌ Common Beginner Mistakes

Placing Semicolon after while: Writing while (i < 5); { ... } creates an empty infinite loop body!

🛠️ Real-World Practical Usage

Stream parsing and protocol buffer reading.
