02. The While Loop & Event-Driven Iteration

🟢 Difficulty: Beginner | Entry-Gated Iteration, Stream Polling & Sentinel Loops

📖 Definition

A while loop is an entry-controlled loop structure in C that evaluates a condition expression before executing the loop body. The loop repeats continuously as long as the condition evaluates to any non-zero value (true).

🎯 Why It Is Used

  • Indefinite / Event-Driven Iteration: Ideal when the number of iterations depends on dynamic runtime events (e.g. reading until EOF, waiting for a hardware flag, or processing user menu inputs until exit).
  • Zero-Execution Safety: If the condition is false initially, the loop body is bypassed entirely without executing even once.

⚙️ How It Works

Before executing the loop body, C tests the expression inside while (condition). If non-zero, control enters the block {}. At the end of the block, control jumps back to re-evaluate the condition expression. If zero, execution skips past the loop.

📝 Syntax

while (condition_expression) {
    // Loop body statements
    // Must update state variables involved in condition_expression!
}

🔀 Event Polling vs Sentinel Loops

  • Sentinel Loop: Loops until a special termination value (like -1 or EOF) is encountered in input stream.
  • Event Polling Loop: Continually checks hardware state or socket status: while (!is_ready) { ... }.

🌱 Beginner Example: Simple Counter Loop

#include <stdio.h>

int main(void) {
    int count = 5;

    while (count > 0) {
        printf("Countdown: %d...\n", count);
        count--; // Decrement state variable
    }
    printf("Liftoff!\n");
    return 0;
}

🌼 Intermediate Example: Sentinel User Input Summation

#include <stdio.h>

int main(void) {
    int number;
    int total_sum = 0;

    printf("Enter integers to sum (Enter -1 to stop):\n");
    printf("> ");

    while (scanf("%d", &number) == 1 && number != -1) {
        total_sum += number;
        printf("> ");
    }

    printf("Final Calculated Sum: %d\n", total_sum);
    return 0;
}

🌲 Advanced Example: Euclidean Greatest Common Divisor (GCD) Algorithm

#include <stdio.h>

unsigned int compute_gcd(unsigned int a, unsigned int b) {
    // Euclidean algorithm using a while loop
    while (b != 0) {
        unsigned int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

int main(void) {
    unsigned int x = 48, y = 18;
    printf("Greatest Common Divisor of %u and %u is: %u\n",
           x, y, compute_gcd(x, y));
    return 0;
}

🔍 Line-by-Line Explanation

  • while (b != 0): Re-evaluates Euclidean remainder condition. Iterates until remainder b becomes 0.
  • b = a % b;: Replaces b with the division remainder of a and b.
  • return a;: Returns final non-zero divisor when loop terminates.

💻 Expected Terminal Output

Countdown: 5...
Countdown: 4...
Countdown: 3...
Countdown: 2...
Countdown: 1...
Liftoff!
Greatest Common Divisor of 48 and 18 is: 6

⚠️ Common Mistakes & Pitfalls

  • Infinite Loops (Forgetting Counter Update): Omitting count-- or state variable updates inside the loop causes the condition to remain permanently true.
  • Accidental Semicolon After while: Writing while (x < 10); { x++; } creates an immediate infinite loop because the empty semicolon statement runs forever!

📌 Important Rules & Limitations

  • The condition in a while loop is evaluated BEFORE the first iteration. If false initially, the loop body never runs.
  • Always guarantee that state variables inside the condition change during loop execution.
