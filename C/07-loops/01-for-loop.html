01. The For Loop & C99 Block Declarations

🟢 Difficulty: Beginner | Entry-Controlled Counters, Block Scope & Iteration

📖 Definition

A for loop in C is an entry-controlled iterative control structure used to execute a block of code a specific number of times. It bundles initialization, condition testing, and counter modification into a single header statement.

🎯 Why It Is Used

  • Deterministic Iteration: Ideal when the total number of iterations is known beforehand (e.g. iterating over array indices from 0 to N-1).
  • C99 Block-Scoped Counter Scope: Declaring variables inside the loop header (for (int i = 0; ...)) keeps the counter scoped strictly to the loop body, preventing variable leakage.

⚙️ How It Works: Execution Sequence

  1. Initialization: Executes once before entering the loop.
  2. Condition Test: Evaluates the condition expression. If non-zero (true), execution enters the loop body; if zero (false), the loop terminates immediately.
  3. Body Execution: Executes the code block inside {}.
  4. Modifier Step: Executes the increment/decrement expression (e.g. i++), then jumps back to Step 2.

📝 Syntax

for (initialization; condition; modifier) {
    // Loop body statements
}

🔀 Infinite Loops & Multi-Variable Headers

  • Infinite Loop Pattern: Omitting all three parts for (;;) { ... } creates an intentional infinite loop.
  • Multi-Variable Initialization: Using comma operators: for (int i = 0, j = 10; i < j; i++, j--).

🌱 Beginner Example

#include <stdio.h>

int main(void) {
    // C99 block-scoped counter 'i'
    for (int i = 1; i <= 5; i++) {
        printf("Iteration %d\n", i);
    }
    return 0;
}

🌼 Intermediate Example: Array Traversal & Sum Calculation

#include <stdio.h>

int main(void) {
    int numbers[] = {12, 24, 36, 48, 60};
    size_t len = sizeof(numbers) / sizeof(numbers[0]);
    int sum = 0;

    for (size_t i = 0; i < len; i++) {
        sum += numbers[i];
        printf("Index %zu: Value = %d | Running Sum = %d\n", i, numbers[i], sum);
    }
    return 0;
}

🌲 Advanced Example: Multi-Variable Convergence Loop

#include <stdio.h>

int main(void) {
    printf("=== Dual Pointer Converging Loop ===\n");
    for (int left = 0, right = 10; left <= right; left++, right--) {
        printf("Left Index: %d <-> Right Index: %d\n", left, right);
    }
    return 0;
}

🔍 Line-by-Line Explanation

  • for (size_t i = 0; i < len; i++): Standard idiom for array traversal starting at index 0 up to len - 1.
  • sizeof(numbers) / sizeof(numbers[0]): Computes element count for fixed array at compile time.
  • for (int left = 0, right = 10; ...): Uses comma operators to maintain two converging counter variables simultaneously.

⚠️ Common Mistakes & Pitfalls

  • Off-by-One Array Boundary Errors: Writing i <= len instead of i < len causes Out-of-Bounds memory reads/writes.
  • Semicolon After Loop Header: Writing for (int i=0; i<5; i++); executes an empty loop body 5 times, then runs the block below once!
  • Modifying Counter Inside Loop Body: Altering i inside both the loop body and header causes unexpected skips or infinite loops.

📌 Important Rules & Limitations

  • Variables declared inside C99 for (int i = 0; ...) headers exist only inside the loop block.
  • Always use size_t for loop counters indexing memory arrays.
