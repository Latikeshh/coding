The for Loop in C Programming

🟢 Beginner Level | Pre-determined Iteration

📖 Definition

The for loop in C executes a block of statements repeatedly for a pre-determined iteration count controlled by initialization, condition testing, and step counter updates.

🤔 Purpose

In low-level systems and embedded computing, iterating over fixed-size arrays or hardware buffers requires exact counter bounds without incurring dynamic overhead.

🌐 Multilingual Explanations

English

In C99 and later, the control variable can be declared directly inside the initialization header: for (int i = 0; i < N; i++). In ANSI C (C89), variables must be declared at the top of the enclosing block before the loop.

Fixed iteration count ke liye for (int i = 0; i < n; i++) use karein. Array memory sequential iterate hoti hai.

📝 Syntax & Parameters

for (initialization; condition; increment) {
    // Body statements
}
  • initialization: Sets up the initial counter value.
  • condition: Tested before each iteration. Evaluates as non-zero (true) or 0 (false).
  • increment: Modifies the loop counter after each iteration.

⚡ Execution Flow

  1. Counter initialization runs once.
  2. The condition expression is evaluated. If 0 (false), loop terminates.
  3. The loop body statements run.
  4. The counter increment expression executes, and execution loops back to condition evaluation.

💡 Progressive Examples

Example 1: Array Traversal

#include <stdio.h>

int main(void) {
    int scores[3] = {88, 92, 79};

    for (int i = 0; i < 3; i++) {
        printf("Student %d Score: %d\n", i + 1, scores[i]);
    }
    return 0;
}

🖥️ Expected Output

Student 1 Score: 88
Student 2 Score: 92
Student 3 Score: 79

🔍 Line-by-Line Code Breakdown

  • int scores[3] = {88, 92, 79};: Allocates contiguous 3-element integer array.
  • for (int i = 0; i < 3; i++): Iterates i from 0 through 2.
  • printf(...): Accesses scores[i] via index pointer offset.

⚠️ Variations & Edge Cases

In C, accessing array indices outside bounds (e.g. scores[3] when array size is 3) causes Undefined Behavior (UB)!

❌ Common Beginner Mistakes

Off-by-One Buffer Overrun: Using i <= size instead of i < size causes buffer overruns into adjacent memory locations.

🛠️ Real-World Practical Usage

Checksum calculation over memory buffers:

unsigned char calculateChecksum(const unsigned char *buf, size_t len) {
    unsigned char sum = 0;
    for (size_t i = 0; i < len; i++) {
        sum ^= buf[i];
    }
    return sum;
}
