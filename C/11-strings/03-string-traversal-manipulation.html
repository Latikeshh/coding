03. Pointer-Based String Traversal & In-Place Manipulation

🟡 Difficulty: Intermediate | Pointer Increment Traversal, ctype.h Transformations & In-Place Reversal

📖 Definition

In C, strings can be traversed and mutated using pointer arithmetic (e.g., while (*str != '\0') { ... str++; }) instead of array bracket indexing. The <ctype.h> library provides character classification and case conversion functions that work seamlessly alongside pointer string loops.

🎯 Why It Is Used

  • High-Speed Loop Traversal: Incrementing a raw pointer directly in assembly avoids re-calculating array base-plus-offset address arithmetic inside tight loops.
  • In-Place Transformations: Transforming strings (e.g. converting to uppercase, stripping whitespace, or reversing in-place) without allocating extra memory buffers.

⚙️ How It Works: ctype.h Utilities

The <ctype.h> header provides boolean tests and conversion routines that operate on single character values:

Function Return Condition / Effect
isalpha(c)Returns non-zero if c is an alphabetic letter (A-Z, a-z).
isdigit(c)Returns non-zero if c is a numeric digit ('0'-'9').
isalnum(c)Returns non-zero if c is alphanumeric.
isspace(c)Returns non-zero if c is whitespace (space, tab, newline).
toupper(c)Returns uppercase character equivalent.
tolower(c)Returns lowercase character equivalent.

📝 Syntax

#include <ctype.h>

// Pointer-Based Idiomatic String Loop
void process_chars(char *str) {
    if (str == NULL) return;

    while (*str != '\0') { // Loop until null terminator
        if (islower((unsigned char)*str)) {
            *str = (char)toupper((unsigned char)*str);
        }
        str++; // Advance pointer to next character
    }
}

🔀 Two-Pointer In-Place Reversal Pattern

To reverse a string in-place without creating a copy, initialize a start pointer at the first character and an end pointer at strlen(s) - 1, swapping characters inward until the pointers meet in the middle.

🌱 Beginner Example: Pointer-Based String Length Counter

#include <stdio.h>

size_t compute_len_pointer(const char *str) {
    if (str == NULL) return 0;

    const char *p = str;
    while (*p != '\0') {
        p++;
    }
    return (size_t)(p - str); // Pointer subtraction yields length!
}

int main(void) {
    const char *text = "Embedded C";
    printf("Length of \"%s\" = %zu characters\n", text, compute_len_pointer(text));
    return 0;
}

🌼 Intermediate Example: In-Place Uppercase Transformation

#include <stdio.h>
#include <ctype.h>

void to_uppercase_in_place(char *str) {
    if (str == NULL) return;

    for (char *p = str; *p != '\0'; p++) {
        *p = (char)toupper((unsigned char)*p);
    }
}

int main(void) {
    char title[] = "learn coding in c11!";
    printf("Original String : %s\n", title);

    to_uppercase_in_place(title);

    printf("Uppercase Output: %s\n", title);
    return 0;
}

🌲 Advanced Example: In-Place String Reversal & Whitespace Trimming

#include <stdio.h>
#include <string.h>

void reverse_string_in_place(char *str) {
    if (str == NULL) return;

    size_t len = strlen(str);
    if (len < 2) return;

    char *start = str;
    char *end = str + len - 1;

    while (start < end) {
        char temp = *start;
        *start = *end;
        *end = temp;

        start++;
        end--;
    }
}

int main(void) {
    char phrase[] = "System Programming";
    printf("Before Reversal: %s\n", phrase);

    reverse_string_in_place(phrase);

    printf("After Reversal : %s\n", phrase);
    return 0;
}

🔍 Line-by-Line Explanation

  • while (*p != '\0') p++;: Iterates pointer p until encountering the null terminator.
  • *p = (char)toupper((unsigned char)*p);: Converts character to uppercase using <ctype.h>, casting input to unsigned char to avoid negative index traps.
  • char *end = str + len - 1;: Positions pointer directly at the final character before '\0'.

⚠️ Common Mistakes & Pitfalls

  • Casting Signed Char to ctype.h Functions: Passing a signed char value directly to isalpha() or toupper() can cause array index out-of-bounds assertions if the character is negative (e.g. non-ASCII bytes). Always cast: toupper((unsigned char)*p).
  • Overwriting Null Terminator During Reversal: Initializing end = str + strlen(str) instead of str + strlen(str) - 1 swaps the null terminator into the middle of the string!

📌 Important Rules & Limitations

  • In-place string transformations require a modifiable stack or heap buffer (never call on read-only string literals).
  • Always cast char arguments to (unsigned char) when invoking <ctype.h> functions.
