# Borders

> 🟢 Beginner

## 📖 Definition

A border is a line around an element. It can separate content, highlight boxes, and improve layout structure.

## 🤔 Why Do We Use It?

Borders help group related content and make areas easier to see on the page.

## 🧠 Simple Explanation

A border is like the frame around a picture. It helps define where one element starts and ends.

## 📝 Syntax

```css
.card {
  border: 2px solid #333;
}
```

## 💡 Example

```css
.card {
  border: 2px solid #4a4a4a;
  padding: 16px;
}
```

## 🌐 HTML + CSS Example

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Border Example</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="card">
    <h2>Student Card</h2>
    <p>Grade: A</p>
  </div>
</body>
</html>
```

```css
.card {
  border: 2px solid #4a4a4a;
  padding: 16px;
}
```

## 👀 What You Will See

The content sits inside a visible rectangular box, making it easier to read.

## 🧪 Try It Yourself

Change the border thickness and color on the card. Try a red border and see the effect.

## ✅ Remember

- `border` controls the visible line around an element.
- Border width, style, and color can be set together.
- Borders help separate sections in a page.
