Function Prototypes & Stack Frames in C

🟢 Beginner Level | ISO C Function Specifications

📖 Definition

A Function Prototype in C informs the compiler about a function's return type, name, and parameter types before its definition body appears in source code.

🤔 Purpose

Allows functions to be called in `main()` regardless of their physical placement in source files, ensuring compile-time type-safety.

🌐 Multilingual Explanations

English

Prototypes (e.g. int add(int, int);) enable single-pass C compilers to validate parameter types before function definitions.

Hindi

Function prototype int calculate(int a, int b); compiler ko batata hai ki function lower file position par defined hai.

Marathi

C compiler sathi main() chya aadhi prototype declaration mahatvache asate.

Hinglish

Prototype declaration: int power(int base, int exp); top-of-file placement follow karein.

📝 Syntax & Parameters

// Prototype (Declaration)
int addNumbers(int a, int b);

int main(void) {
    int res = addNumbers(5, 10);
    return 0;
}

// Definition
int addNumbers(int a, int b) {
    return a + b;
}

⚡ Execution Flow

  1. Compiler verifies call argument types against prototype declaration.
  2. Execution allocates a stack frame pushing arguments in reverse order.
  3. Function executes, pops stack frame, and places return value into register.

💡 Progressive Examples

Example 1: Prototype with Pass-by-Value

#include <stdio.h>

// Prototype
double celsiusToFahrenheit(double celsius);

int main(void) {
    double tempC = 25.0;
    double tempF = celsiusToFahrenheit(tempC);
    printf("%.1f C = %.1f F\n", tempC, tempF);
    return 0;
}

double celsiusToFahrenheit(double celsius) {
    return (celsius * 9.0 / 5.0) + 32.0;
}

🖥️ Expected Output

25.0 C = 77.0 F

🔍 Line-by-Line Code Breakdown

  • double celsiusToFahrenheit(double celsius);: Informs compiler of return type and double parameter.
  • celsiusToFahrenheit(tempC): Passes value of tempC into function stack frame.

⚠️ Variations & Edge Cases

Calling a function without a prototype in C99/C11 causes an implicit declaration warning/error.

❌ Common Beginner Mistakes

Mismatch Between Prototype and Definition: Declaring int calc(double) as prototype but defining int calc(int) produces linker errors.

🛠️ Real-World Practical Usage

Structuring multi-file modular libraries in C (`.h` headers with `.c` implementations).
