# Colors

> 🟢 Beginner

## 📖 Definition

Colors in CSS are used to change the appearance of text, backgrounds, borders, and other elements.

## 🤔 Why Do We Use It?

Color helps organize content, highlight important text, and improve the visual design of a page.

## 🧠 Simple Explanation

A page without color can feel flat. Color helps people notice headings, buttons, and important information quickly.

## 📝 Syntax

```css
h1 {
  color: blue;
}

.card {
  background-color: #f0f0f0;
}
```

## 💡 Example

```css
body {
  background-color: #f8f8f8;
}

h1 {
  color: darkgreen;
}

button {
  background-color: orange;
  color: white;
}
```

## 🌐 HTML + CSS Example

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Student Profile</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Aisha Khan</h1>
  <button>View Profile</button>
</body>
</html>
```

```css
body {
  background-color: #f8f8f8;
}

h1 {
  color: darkgreen;
}

button {
  background-color: orange;
  color: white;
}
```

## 👀 What You Will See

The page background is light, the heading is green, and the button stands out with orange and white.

## 🧪 Try It Yourself

Change the heading color and button background to a different combination. Try a dark blue heading and a light gray button.

## ✅ Remember

- `color` changes text color.
- `background-color` changes the background of an element.
- Use colors consistently so your page looks clean and readable.
