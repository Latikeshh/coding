02. Introduction to C & System Memory Model

🟢 Difficulty: Beginner | History, Language Fundamentals & Virtual Memory Layout

📖 Definition

C is a procedural, general-purpose, compiled programming language created by Dennis Ritchie between 1969 and 1972 at Bell Labs. C is called the "mother of modern languages" because it provides clean syntax abstractions while retaining direct pointer access to physical and virtual memory addresses.

🎯 Why It Is Used

Virtually all modern system infrastructure is built in C or relies on C runtimes:

  • Operating System Kernels: Linux kernel, Windows NT kernel components, macOS XNU kernel, iOS/Android base systems.
  • Database Engines: SQLite, PostgreSQL, MySQL storage engines, Redis in-memory cache.
  • Embedded Systems: Automotive ECU microcontrollers, IoT devices, robotics, and medical devices.
  • Language Runtimes: CPython (Python interpreter), Ruby MRI, V8 JavaScript engine core.

⚙️ How It Works: Virtual Memory Layout of a C Program

When an operating system loads a C executable into RAM, it constructs a Virtual Address Space divided into five distinct segments:

+---------------------------------------+ High Addresses (0x7FFF...)
| Environment Variables & CLI Arguments |
+---------------------------------------+
| STACK SEGMENT (Grows Downward v)      | Local variables, stack frames, return addresses
|   |                                   |
|   v                                   |
|                                       |
|   ^                                   |
|   |                                   |
| HEAP SEGMENT (Grows Upward ^)         | Dynamic allocations (malloc, calloc, realloc)
+---------------------------------------+
| BSS SEGMENT (Block Started by Symbol) | Uninitialized global & static variables (zeroed)
+---------------------------------------+
| DATA SEGMENT                          | Initialized global & static variables
+---------------------------------------+
| TEXT / CODE SEGMENT                   | Read-only binary machine instructions & literals
+---------------------------------------+ Low Addresses (0x0000...)

#include <stdio.h> // Preprocessor header inclusion

🌲 Advanced Example: Memory Segment Address Exploration

#include <stdio.h>
#include <stdlib.h>

// Initialized global variable -> Data Segment
int global_init_var = 42;

// Uninitialized global variable -> BSS Segment
int global_uninit_var;

int main(void) {
    // Local stack variable -> Stack Segment
    int stack_var = 100;

    // Dynamically allocated memory -> Heap Segment
    int *heap_var = (int*) malloc(sizeof(int));
    if (heap_var == NULL) {
        return 1;
    }
    *heap_var = 200;

    printf("=== Process Virtual Memory Address Map ===\n");
    printf("Text Segment (main function)     : %p\n", (void*)main);
    printf("Data Segment (global_init_var)  : %p\n", (void*)&global_init_var);
    printf("BSS Segment (global_uninit_var)  : %p\n", (void*)&global_uninit_var);
    printf("Heap Segment (heap_var pointer)  : %p\n", (void*)heap_var);
    printf("Stack Segment (stack_var local)  : %p\n", (void*)&stack_var);

    free(heap_var);
    heap_var = NULL;
    return 0;
}

🔍 Line-by-Line Explanation

  • int global_init_var = 42;: Allocated in the read-write Data Segment at binary load time.
  • int global_uninit_var;: Placed in the BSS segment and automatically initialized to zero by OS CRT.
  • int stack_var = 100;: Allocated on top of the function call frame inside the Stack Segment.
  • int *heap_var = (int*) malloc(...);: Allocates memory dynamically inside the Heap Segment.
  • (void*)main: Casting function pointer address to void* for standard %p output printing.
  • free(heap_var); heap_var = NULL;: Releases heap allocation and prevents dangling pointer bugs.

⚠️ Common Mistakes & Pitfalls

  • Assuming Fixed Types Sizes: Assuming sizeof(int) is always 4 bytes. In C, sizes are implementation-defined; only minimum bounds are specified by the standard.
  • Confusing Stack and Heap: Local variables automatically disappear when functions exit, whereas Heap memory must be explicitly released using free().
  • Missing Semicolons: Omitting semicolons at the end of C statements.
  • Case Sensitivity: Writing Main() or Printf() instead of lowercase main() and printf().

📌 Important Rules & Limitations

  • Every standalone executable C program must have exactly one main() function.
  • Use int main(void) in standard C rather than void main() to avoid compiler warnings.
  • Cast pointers to (void*) when printing memory addresses with %p in printf().

🌐 Multilingual Explanation: English

C is a low-level compiled language that manages memory through five primary virtual segments: Text (instructions), Data (initialized globals), BSS (uninitialized globals), Heap (dynamic allocations), and Stack (local variables). This architecture enables high execution speed and direct hardware control.
