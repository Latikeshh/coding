Module 14: Unions & Bit-Fields Guide

🟡 Difficulty: Intermediate to Advanced | Memory Re-use, Variant Types & Hardware Register Bit-Packing

A union in C is a special composite data type where all member fields share the exact same starting RAM memory address, reserving only enough bytes for its single largest member. A bit-field allows integer structure fields to be packed into explicitly declared bit widths (e.g. 1 bit for flags), enabling ultra-compact memory layouts for hardware register drivers.
