15. Enumerations (enum) & State Machines in C

🟢 Difficulty: Beginner | Named Integer Constants, Type Safety & State Machines

📖 Definition

An enumeration (enum) in C is a user-defined data type consisting of a set of named integer constants (enumerators). By default, enumerators start at integer value 0 and increment sequentially by 1 for each subsequent member, unless explicit integer values are assigned.

🎯 Why It Is Used

  • Self-Documenting Code: Replacing "magic numbers" (like status code 0, 1, 2) with meaningful names (HTTP_OK, HTTP_NOT_FOUND, HTTP_SERVER_ERROR).
  • Type Safety in Switch Dispatching: Compilers (gcc -Wall) issue warnings if a switch statement on an enum variable omits one of the declared enumeration cases.
  • Finite State Machines (FSM): Controlling protocol state transitions (e.g., IDLE → CONNECTING → CONNECTED).

⚙️ How It Works: Integer Underpinnings

In C, enumerations are stored internally as standard int types. Assigning custom integer values is supported, and subsequent unassigned members continue incrementing from the last explicit value:

enum Status {
    SUCCESS = 200, // Explicit 200
    CREATED,       // Automatically 201
    BAD_REQUEST = 400,
    UNAUTHORIZED   // Automatically 401
};

📝 Syntax

// 1. Standard Enum Declaration
enum Day { MON = 1, TUE, WED, THU, FRI, SAT, SUN };

// 2. Typedef Alias (Recommended in Production)
typedef enum {
    STATE_INIT,
    STATE_RUNNING,
    STATE_PAUSED,
    STATE_STOPPED
} ProcessState;

ProcessState current_state = STATE_INIT;

🌱 Beginner Example: Days of the Week

#include <stdio.h>

typedef enum {
    MONDAY = 1,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY,
    SUNDAY
} DayOfWeek;

int main(void) {
    DayOfWeek today = WEDNESDAY;

    if (today == SATURDAY || today == SUNDAY) {
        printf("Day %d: It's the Weekend!\n", today);
    } else {
        printf("Day %d: It's a Workday.\n", today);
    }
    return 0;
}

🌼 Intermediate Example: Protocol State Machine Handler

#include <stdio.h>

typedef enum {
    STATE_DISCONNECTED,
    STATE_CONNECTING,
    STATE_CONNECTED,
    STATE_ERROR
} ConnectionState;

const char* get_state_name(ConnectionState state) {
    switch (state) {
        case STATE_DISCONNECTED: return "DISCONNECTED";
        case STATE_CONNECTING:   return "CONNECTING";
        case STATE_CONNECTED:    return "CONNECTED";
        case STATE_ERROR:        return "ERROR";
        default:                 return "UNKNOWN_STATE";
    }
}

int main(void) {
    ConnectionState net_state = STATE_CONNECTING;

    printf("Current Network State: %s (Code: %d)\n",
           get_state_name(net_state), net_state);
    return 0;
}

🌲 Advanced Example: Bitmask Enums for Combined Feature Flags

#include <stdio.h>

// Bitmask enum using power-of-two bitwise values
typedef enum {
    FLAG_READ    = 1 << 0, // 0x01
    FLAG_WRITE   = 1 << 1, // 0x02
    FLAG_EXECUTE = 1 << 2, // 0x04
    FLAG_ADMIN   = 1 << 3  // 0x08
} SecurityFlags;

void inspect_permissions(int user_flags) {
    printf("Permissions: ");
    if (user_flags & FLAG_READ)    printf("READ ");
    if (user_flags & FLAG_WRITE)   printf("WRITE ");
    if (user_flags & FLAG_EXECUTE) printf("EXECUTE ");
    if (user_flags & FLAG_ADMIN)   printf("ADMIN ");
    printf("\n");
}

int main(void) {
    int user_access = FLAG_READ | FLAG_WRITE; // Combines Read + Write
    inspect_permissions(user_access);
    return 0;
}

🔍 Line-by-Line Explanation

  • DayOfWeek today = WEDNESDAY;: Assigns the named integer constant WEDNESDAY (value 3).
  • switch (state) { case STATE_DISCONNECTED: ... }: Evaluates state codes and converts them cleanly to string names.
  • int user_access = FLAG_READ | FLAG_WRITE;: Uses bitwise OR to combine bitmask enumeration flags into a single integer.

⚠️ Common Mistakes & Pitfalls

  • Assuming Enum Is a String: Attempting printf("%s", today) prints garbage or crashes because enums store integers! Write a helper function like get_state_name() to convert enums to strings.
  • Enum Name Collisions: Enum member names exist in the global/file namespace; declaring enum E1 { OK }; and enum E2 { OK }; in the same file causes name collision errors.

📌 Important Rules & Limitations

  • In C, enums are represented as int under the hood.
  • Enum member names must be unique within their scope namespace.
