# Mini Projects

> 🟡 Intermediate

## 📖 Definition

Mini projects are small pages or sections you build to practise CSS together with HTML.

## 🤔 Why Do We Use It?

Reading CSS is useful, but building small pieces helps you connect ideas like colors, spacing, layout, and responsiveness.

## 🧠 Simple Explanation

Think of mini projects as small practice builds. You use simple HTML and style it with CSS to make a complete page or section.

## 📝 Syntax

```css
.card {
  background-color: #f7f7f7;
  border: 1px solid #ddd;
  padding: 20px;
  border-radius: 8px;
}
```

## 💡 Example

```css
.profile-card {
  width: 280px;
  background-color: #fff;
  border: 1px solid #ccc;
  padding: 20px;
  border-radius: 10px;
  box-shadow: 0 4px 8px rgba(0,0,0,0.1);
}
```

## 🌐 HTML + CSS Example

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Profile Card</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="profile-card">
    <h2>Samir</h2>
    <p>Web Developer</p>
  </div>
</body>
</html>
```

```css
.profile-card {
  width: 280px;
  background-color: #fff;
  border: 1px solid #ccc;
  padding: 20px;
  border-radius: 10px;
  box-shadow: 0 4px 8px rgba(0,0,0,0.1);
}
```

## 👀 What You Will See

A simple clean card appears with a border, padding, and shadow, making it look polished.

## 🧪 Try It Yourself

Build one simple page: a portfolio card, a restaurant menu, or a login form. Use at least three CSS properties you already learned.

## ✅ Remember

- Start with a small project before adding complex styling.
- Reuse ideas from earlier lessons.
- Check your page in a browser after each change.
