# Margins

> 🟢 Beginner

## 📖 Definition

A margin is the space outside an element, between the element and other elements around it.

## 🤔 Why Do We Use It?

Margins help separate content and create cleaner page layout. Without margins, elements can look cramped or packed together.

## 🧠 Simple Explanation

Think of margins as the empty space around a box. They create breathing room so the page feels balanced.

## 📝 Syntax

```css
.box {
  margin: 20px;
}
```

## 💡 Example

```css
.card {
  margin: 30px;
  background-color: #f5f5f5;
}
```

## 🌐 HTML + CSS Example

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Margins Example</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="card">This is a card with space around it.</div>
  <p>Another section below.</p>
</body>
</html>
```

```css
.card {
  margin: 30px;
  background-color: #f5f5f5;
  padding: 20px;
}
```

## 👀 What You Will See

There is space between the card and nearby content, which makes the layout easier to read.

## 🧪 Try It Yourself

Add a bigger margin to the box and see how it affects the spacing between sections.

## ✅ Remember

- Margin is outside the element.
- Padding is inside the element.
- Margins help create separation between blocks.
