Module 12: Dynamic Memory Allocation (Heap) Guide

🟡 Difficulty: Intermediate to Advanced | Heap Allocation, Dynamic Sizing & Memory Leak Prevention

Dynamic Memory Allocation allows a C program to request RAM storage from the system Heap Segment at runtime, whose size can grow or shrink based on execution demands. Standard functions (malloc, calloc, realloc, and free from <stdlib.h>) manage heap memory lifecycles.
