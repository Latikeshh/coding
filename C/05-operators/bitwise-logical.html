Bitwise & Logical Operators in C

🟢 Intermediate Level | Low-Level Bit Operations

📖 Definition

Bitwise Operators (&, |, ^, ~, <<, >>) manipulate individual bits inside integral operands. Logical Operators (&&, ||, !) perform short-circuit boolean evaluation.

🤔 Purpose

Used in microcontroller register masking, flags management, protocol header parsing, and low-level C system optimization.

🌐 Multilingual Explanations

English

Bitwise & performs bitwise AND; left shift a << b multiplies a by $2^b$; right shift a >> b divides by $2^b$.

Hindi

Bitwise operators &, |, ^ binary bits par kaam karte hain. Left shift 1 << 3 value ko $2^3 = 8$ se multiply karta hai.

Marathi

Bitwise shift operators mule binary bit positions move hotat.

Hinglish

Bit masking pattern: flags |= (1 << bit_pos); bit setting ke liye standard hai.

📝 Syntax & Parameters

unsigned int flags = 0x05; // Binary: 00000101
flags |= (1 << 3);       // Set bit 3 -> 00001101 (13)
int isBitSet = (flags & (1 << 3)) != 0; // Check bit 3

⚡ Execution Flow

  1. CPU loads operand binary register values.
  2. Applies bitwise instruction AND, OR, XOR, NOT, or Bit-Shift.
  3. Stores modified bitmask result in target register.

💡 Progressive Examples

Example 1: Setting & Testing a Bitmask

#include <stdio.h>

int main(void) {
    unsigned char mask = 0x00; // 0000 0000

    // Set bit 2
    mask |= (1 << 2); // 0000 0100

    if (mask & (1 << 2)) {
        printf("Bit 2 is SET! Mask: 0x%02X\n", mask);
    }
    return 0;
}

🖥️ Expected Output

Bit 2 is SET! Mask: 0x04

🔍 Line-by-Line Code Breakdown

  • mask |= (1 << 2): Shifts 1 left by 2 positions (`0x04`) and performs bitwise OR.
  • mask & (1 << 2): Bitwise AND masks bit 2 to test if non-zero.

⚠️ Variations & Edge Cases

Shifting by negative counts or by amounts equal to or greater than the operand width is undefined behavior in C!

❌ Common Beginner Mistakes

Confusing Bitwise `&` with Logical `&&`: Writing if (a & b) performs bitwise AND instead of boolean short-circuit evaluation.

🛠️ Real-World Practical Usage

Embedded systems GPIO pin mode configuration.

🎯 Tiered Practice Exercises

  1. Beginner: Write a C function using `& 1` to check if an integer is odd or even.
  2. Intermediate: Write a C function toggling bit 4 of an integer using `^=`.
  3. Advanced: Create a C program parsing flags from a packed 32-bit protocol header.
