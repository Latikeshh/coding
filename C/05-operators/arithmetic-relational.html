Arithmetic & Relational Operators in C

🟢 Beginner Level | ISO C Basic Operations

📖 Definition

Arithmetic Operators (+, -, *, /, %) calculate numerical expressions in C. In integer division (int / int), the fractional part is truncated toward zero. Relational Operators (==, !=, >, <, >=, <=) evaluate to 1 (true) or 0 (false).

🤔 Purpose

Performs fundamental calculations and conditional evaluation in systems code.

🌐 Multilingual Explanations

English

In ISO C, integer division 7 / 2 truncates to 3. Relational operators return integer 1 for true or 0 for false.

Hindi

C mein 7 / 2 result 3 deta hai (integer truncation). Modulo 7 % 2 remainder 1 deta hai.

Marathi

Integer division madhye point nantar chi value drop hote.

Hinglish

📝 Syntax & Parameters

int a = 7, b = 2;
int intDiv = a / b;     // 3
double realDiv = (double)a / b; // 3.5
int isGreater = (a > b); // 1

⚡ Execution Flow

  1. Evaluate operand values from memory or registers.
  2. Perform arithmetic or comparison at CPU instruction level (ALU).
  3. Store integer result (or 0/1 condition code flag).

💡 Progressive Examples

Example 1: Integer Division vs Floating-Point Division

#include <stdio.h>

int main(void) {
    int total = 10;
    int count = 4;

    int avgInt = total / count;
    double avgFloat = (double)total / count;

    printf("Integer Division: %d\n", avgInt);
    printf("Float Division: %.2f\n", avgFloat);
    return 0;
}

🖥️ Expected Output

Integer Division: 2
Float Division: 2.50

🔍 Line-by-Line Code Breakdown

  • total / count: Truncates 10 / 4 to integer `2`.
  • (double)total / count: Explicitly casts `total` to double, producing floating point result `2.5`.

⚠️ Variations & Edge Cases

Dividing by zero (x / 0) triggers an unhandled hardware exception (SIGFPE process termination).

❌ Common Beginner Mistakes

Assignment `=` in Place of Equality `==`: Writing if (x = 5) assigns 5 to x and evaluates as true, overriding x!

🛠️ Real-World Practical Usage

Hardware timer calculations and array index offset arithmetic.

🎯 Tiered Practice Exercises

  1. Beginner: Write a C snippet calculating the average of three integers using explicit double casting.
  2. Intermediate: Use modulo `%` to determine if an integer is odd or even.
  3. Advanced: Create a function converting total seconds into hours, minutes, and remaining seconds using division and modulo.
