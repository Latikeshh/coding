07. Special C Operators (sizeof, Ternary, Comma, Member Access)

🟡 Difficulty: Intermediate | Memory Sizing, Inline Expressions, Pointer Dereferencing & Alignment

📖 Definition

In addition to basic arithmetic, relational, and bitwise operators, C provides special utility operators: sizeof (unary compile-time memory query operator), ? : (ternary conditional operator), , (comma sequence operator), & (address-of), * (pointer indirection), . (struct member access), and -> (struct pointer arrow operator).

🎯 Why It Is Used

  • Compile-time Memory Sizing (sizeof): Safely allocates heap blocks via malloc(count * sizeof(int)) and calculates array lengths.
  • Inline Conditional Expressions (? :): Concise single-line conditional assignments.
  • Comma Operator (,): Combines multiple sub-expressions inside for loop headers.
  • Structure Member Access (. / ->): Accessing structure fields directly or via pointer offsets.

⚙️ How It Works: Compile-Time vs Runtime Evaluation

In C, sizeof is a compile-time operator (except when applied to C99 Variable Length Arrays). Its operand is not evaluated at runtime! For example, sizeof(i++) does NOT increment i during execution because sizeof only queries the data type's byte size at build time.

🔀 Array Length Idiom via sizeof

In C, the number of elements in a fixed stack-allocated array is calculated using:

size_t element_count = sizeof(arr) / sizeof(arr[0]);

*(Note: This idiom works ONLY for fixed array declarations, NOT for array decay pointers passed into functions!)*

🌱 Beginner Example: sizeof and Ternary Operator

#include <stdio.h>

int main(void) {
    int arr[] = {10, 20, 30, 40, 50};
    size_t len = sizeof(arr) / sizeof(arr[0]);

    printf("Array total size: %zu bytes | Element count: %zu\n", sizeof(arr), len);

    int a = 15, b = 25;
    int max_val = (a > b) ? a : b;
    printf("Max of %d and %d is: %d\n", a, b, max_val);
    return 0;
}

🌼 Intermediate Example: Comma Operator in Multi-Index Loops

#include <stdio.h>

int main(void) {
    int arr[5] = {1, 2, 3, 4, 5};

    printf("Reversing array in-place using Comma Operator in for loop:\n");
    // Comma operator allows initializing and updating two variables (i, j) in one loop header
    for (int i = 0, j = 4; i < j; i++, j--) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }

    for (int k = 0; k < 5; k++) {
        printf("%d ", arr[k]);
    }
    printf("\n");
    return 0;
}

🌲 Advanced Example: sizeof Non-Evaluation Guarantee & Pointer Arrow Access

#include <stdio.h>

typedef struct {
    int id;
    double score;
} Student;

int main(void) {
    int i = 10;
    // sizeof operand is NOT evaluated at runtime! 'i++' does NOT execute!
    size_t sz = sizeof(i++);

    printf("sizeof(i++) = %zu bytes, value of i = %d (Unchanged!)\n", sz, i);

    Student s = {101, 95.5};
    Student *ptr = &s;

    // Dot operator on struct instance vs Arrow operator on struct pointer
    printf("Student ID via dot  : %d\n", s.id);
    printf("Student ID via arrow: %d\n", ptr->id);

    return 0;
}

🔍 Line-by-Line Explanation

  • size_t len = sizeof(arr) / sizeof(arr[0]);: Divides total array memory footprint by the size of a single element to compute array length.
  • for (int i = 0, j = 4; i < j; i++, j--): Comma operator sequences multiple initializations and increment steps inside loop header.
  • sizeof(i++): Demonstrates compile-time evaluation. i remains 10 because no runtime code is emitted for the operand.
  • ptr->id: Equivalent shorthand for (*ptr).id.

Max of 15 and 25 is: 25

Student ID via dot  : 101
Student ID via arrow: 101

⚠️ Common Mistakes & Pitfalls

  • Expecting sizeof(arr) inside Functions to give Array Length: When an array is passed to a function, it decays to a pointer. Calling sizeof(arr) inside a function returns pointer size (4 or 8 bytes), NOT total array size!
  • Expecting Side-Effects in sizeof: Writing sizeof(function_call()) does NOT execute function_call() at runtime.

📌 Important Rules & Limitations

  • Format specifier for sizeof returns is strictly %zu.
  • The comma operator evaluates operands left-to-right and yields the result of the rightmost operand.
