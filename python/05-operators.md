### Equality, Identity, and Precedence

`==` checks value equality; `is` checks whether two names refer to the same object. Two separate lists can be equal (`a == b`) without being identical (`a is b`). Use `value is None` for the `None` singleton. Multiplication binds more tightly than addition, so `7 + 3 * 2` is `13`; parentheses can make grouping clearer. `/` is true division and `//` floors the quotient.
