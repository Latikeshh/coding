### Verify the Installation

Use the command supported by your system; not every installation exposes all command names.

```bash
py --version       # Windows Python launcher
python --version
python3 --version  # common on macOS/Linux
```

At a `>>>` prompt, enter `2 + 3` for an immediate REPL result. In script mode, save `print("Hello, Python!")` as `hello.py` and run `py hello.py`, `python hello.py`, or `python3 hello.py` from its folder. On Windows, enable the launcher or add Python to PATH if needed; reopen the terminal after PATH changes. In VS Code, select the interpreter you installed.
