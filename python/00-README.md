# Learn Python 3

## Introduction

Python is a high-level, general-purpose language with readable syntax and a broad ecosystem. It is dynamically typed and indentation-sensitive. In CPython, source code is compiled to bytecode and executed by its virtual machine; implementations differ, so ?purely interpreted? is an oversimplification. Python is popular with beginners and professionals and is used for automation, web development, backend services, data science, AI/ML, scripting, and developer tools. Beginners can focus on programming logic while building practical programs.

## Prerequisites

- Basic computer knowledge, such as creating files and folders.
- No previous programming language is required.
- Curiosity and willingness to practice.

## Mini Project Briefs

For each project, state its goal, concepts, requirements, expected behavior, suggested structure, edge cases, and extensions. Build the smallest useful version first.

| Project | Goal, concepts, requirements and behavior | Edge cases and extensions |
|---|---|---|
| Number Guessing Game | random number, input loop, hints and attempt count | invalid range; difficulty levels |
| Calculator | functions, operators and menu | division by zero; history |
| Student Marks Manager | lists/dicts, grades and summaries | empty class, invalid marks; sorting/export |
| Contact Book | dictionary CRUD and search | duplicate/missing contact; JSON storage |
| Expense Tracker | dates, categories and totals | invalid amount, empty month; budgets |
| Quiz Application | questions, loops and scoring | empty quiz, invalid answer; categories |
| To-Do CLI | tasks, status and persistence | duplicate task, missing file; priorities |
| Password Generator | secrets and input validation | invalid length; character choices |
| File Organizer | pathlib and moving files | name collisions; dry run |
| Text/File Analyzer | reading, strings and counters | missing/empty file; top words |
| CSV Student Report | csv, numeric conversion, averages | missing columns, malformed rows; grade summary |
| JSON Notes App | modules, JSON, search and CRUD | corrupt/missing JSON; tags |

Larger projects can use `main.py`, focused modules, a data file, and `tests/`. Specify prompts and results, then verify normal and edge cases.
