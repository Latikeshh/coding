01. Iterators & Iterable Protocol in Python 3

🟢 Intermediate Level | `__iter__()` and `__next__()` Magic Methods

📖 What is an Iterator?

An Iterator is an object representing a stream of data. Objects implementing the __iter__() and __next__() special methods satisfy the Python iterator protocol.

📝 Code Example

class CountDown:
    def __init__(self, start):
        self.num = start

    def __iter__(self):
        return self

    def __next__(self):
        if self.num <= 0:
            raise StopIteration
        self.num -= 1
        return self.num + 1

for i in CountDown(3):
    print(i) # Outputs: 3, 2, 1
