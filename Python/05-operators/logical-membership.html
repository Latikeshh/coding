Logical, Identity & Membership Operators in Python 3

🟢 Beginner Level | Pythonic Keywords

📖 Definition

Python uses English keywords for Logical Operators (and, or, not). Identity Operators (is, is not) check memory object identity. Membership Operators (in, not in) test sequence membership.

🤔 Purpose

Enables clear reading syntax for checking list/string contents and comparing object identities (such as checking `x is None`).

🌐 Multilingual Explanations

English

Use is to check if two variables point to the exact same object memory location (`id(a) == id(b)`). Use == for value equality.

📝 Syntax & Parameters

# Identity Test
val = None
if val is None:
    print("Value is None")

# Membership Test
fruits = ["apple", "banana"]
if "apple" in fruits:
    print("Found apple!")

⚡ Execution Flow

  1. `A is B` compares `id(A) == id(B)` memory pointers.
  2. `item in container` invokes `__contains__()` method on target sequence.
  3. `and`/`or` perform truthy/falsy short-circuit evaluation returning object values.

💡 Progressive Examples

Example 1: Identity vs Equality & Membership

list1 = [1, 2, 3]
list2 = [1, 2, 3]

print("Equal Values (==):", list1 == list2)
print("Same Memory Object (is):", list1 is list2)
print("Is 2 in list1?:", 2 in list1)

🖥️ Expected Output

Equal Values (==): True
Same Memory Object (is): False
Is 2 in list1?: True

🔍 Line-by-Line Code Breakdown

  • list1 == list2: Compares list elements for equality (True).
  • list1 is list2: Compares memory object references (False, separate heap objects).
  • 2 in list1: Checks membership (True).

⚠️ Variations & Edge Cases

Python caches small integers (-5 to 256) and short string literals, so `a = 100` and `b = 100` may evaluate `a is b` to `True` due to string interning!

❌ Common Beginner Mistakes

Using `is` Instead of `==` for Value Comparison: Writing if name is "Latikesh" relies on implementation-dependent string caching and fails on dynamic strings.

🛠️ Real-World Practical Usage

Filtering query result sets and checking dictionary key membership.

🎯 Tiered Practice Exercises

  1. Beginner: Test if `"py"` is in `"python"` using `in`.
  2. Intermediate: Write a check determining if a variable `val` is NOT None using `is not`.
  3. Advanced: Explain why `[1] == [1]` is True but `[1] is [1]` is False in Python.
