Arithmetic & Comparison Operators in Python 3

🟢 Beginner Level | Pythonic Mathematics

📖 Definition

In Python 3, division / ALWAYS returns a float. Floor division // truncates toward negative infinity returning an integer. Exponentiation is calculated via **. Python uniquely supports Chained Comparisons (e.g. 10 < x < 50).

🤔 Purpose

Enables clear mathematical calculations and chained range checks without redundant and operators.

🌐 Multilingual Explanations

English

Python 3 standard division 7 / 2 evaluates to float 3.5. Floor division 7 // 2 yields integer 3.

Hindi

Python 3 mein 7 / 2 always float 3.5 hota hai. Integer division ke liye floor division 7 // 2 write karein.

Marathi

Float division / aani floor division // madhye farak asato.

Hinglish

Chained comparison: if 18 <= age <= 65: syntax clean and readable hota hai.

📝 Syntax & Parameters

real_div = 7 / 2    # 3.5 (float)
floor_div = 7 // 2  # 3 (int)
power = 2 ** 5      # 32

# Chained Comparison
age = 25
valid = 18 <= age <= 60  # True

⚡ Execution Flow

  1. Python bytecode instruction `BINARY_TRUE_DIVIDE` yields floating point result.
  2. `BINARY_FLOOR_DIVIDE` applies floor math calculation.
  3. Chained comparison `18 <= age <= 60` expands internally into `(18 <= age) and (age <= 60)` with short-circuiting.

💡 Progressive Examples

Example 1: Floor Division vs Float Division

val1 = 15
val2 = 4

print("True Division (/):", val1 / val2)
print("Floor Division (//):", val1 // val2)
print("Power (**):", val2 ** 3)

🖥️ Expected Output

True Division (/): 3.75
Floor Division (//): 3
Power (**): 64

🔍 Line-by-Line Code Breakdown

  • val1 / val2: Produces exact floating point value `3.75`.
  • val1 // val2: Truncates decimal toward negative infinity to return `3`.

⚠️ Variations & Edge Cases

Floor division with negative numbers truncates downward: -7 // 2 evaluates to -4 (not -3!).

❌ Common Beginner Mistakes

Expecting Integer Division with `/`: Expecting 7 / 2 to return integer `3` as in C or Java; in Python 3 it always returns float `3.5`.

🛠️ Real-World Practical Usage

Grid coordinate calculation and pagination total page count math.

🎯 Tiered Practice Exercises

  1. Beginner: Calculate $3^4$ in Python using `**`.
  2. Intermediate: Use chained comparison to test if a score is between 50 and 100 inclusive.
  3. Advanced: Compare results of `-11 // 3` vs `int(-11 / 3)` in Python.
