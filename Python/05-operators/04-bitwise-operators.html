Bitwise Operators in Python

🟢 Beginner

📖 Definition

Bitwise Operators perform bit-level operations directly on binary representations of integers.

🌍 Multilingual Summary

English

Use &, |, ^ (XOR), ~ (NOT), <<, and >> for bit manipulation.

Hindi

Binary bits par direct operation karne ke liye bitwise operators use hote hain.

⚡ Pythonode Example

int a = 5;  // 0101 in binary
int b = 3;  // 0011 in binary
int res = a & b; // 0001 = 1
