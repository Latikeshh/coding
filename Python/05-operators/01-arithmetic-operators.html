Arithmetic & Floor Division in Python

🟢 Beginner

📖 Definition

Python arithmetic operators include addition (+), subtraction (-), multiplication (*), float division (/), floor division (//), modulo (%), and exponentiation (**).

⚡ Code Example

a, b = 10, 3
print(a / b)  # 3.333... (float division)
print(a // b) # 3 (floor division)
print(a ** b) # 1000 (10 to power 3)
