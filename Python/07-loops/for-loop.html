The for Loop in Python 3

🟢 Beginner Level | Sequence Traversal

📖 Definition

The for loop in Python iterates over the items of any sequence (such as a list, tuple, string, or range object) in the order that they appear.

🤔 Purpose

Unlike traditional counter-based loops in C, Python's for loop acts as a high-level iterator, eliminating manual index management when traversing collections.

🌐 Multilingual Explanations

English

📝 Syntax & Parameters

for item in sequence:
    # Indented body statements
    pass

⚡ Execution Flow

  1. Python requests an iterator from the sequence object.
  2. For each element, Python binds it to item.
  3. The indented loop body executes with item bound to the current value.
  4. When StopIteration is encountered, the loop completes naturally.

💡 Progressive Examples

Example 1: Sequence Iteration

frameworks = ["Django", "FastAPI", "Flask"]

for fw in frameworks:
    print(f"Backend framework: {fw}")

Example 2: Range Counting

for i in range(1, 4):
    print(f"Counting: {i}")

🖥️ Expected Output

Backend framework: Django
Backend framework: FastAPI
Backend framework: Flask
Counting: 1
Counting: 2
Counting: 3

🔍 Line-by-Line Code Breakdown

  • frameworks = [...]: Instantiates list of string objects.
  • for fw in frameworks:: Sequentially binds each element to local variable fw.
  • print(f"..."): Formats and outputs string representation.

⚠️ Variations & Edge Cases

Python supports a for...else clause: the else block executes ONLY if the loop completes without hitting a break statement!

❌ Common Beginner Mistakes

Modifying List While Iterating: Mutating (adding or removing elements from) a list while iterating over it with a for loop causes skipped elements or unexpected behavior.

🛠️ Real-World Practical Usage

Data processing and filtering:

prices = [19.99, 5.50, 100.00, 45.00]
discounted = []

for p in prices:
    if p > 20.0:
        discounted.append(p * 0.9)

print("Discounted prices:", discounted)
