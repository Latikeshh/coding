02. Python Packages & `__init__.py`

🟢 Intermediate Level | Hierarchical Package Namespaces

📖 What is a Python Package?

A Package is a directory containing Python modules and an __init__.py initializer file. Packages allow structuring multi-file libraries using dot-notation namespaces (e.g. mypackage.submodule).

📝 Directory Layout & Code Example

mypackage/
├── __init__.py
├── string_utils.py
└── math_utils.py
