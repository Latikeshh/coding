# 🐍 Learn Python 3 Programming

Python is a high-level, dynamically-typed, general-purpose programming language celebrated for its readable syntax, powerful standard library, and massive ecosystem across web development, backend APIs, data science, machine learning, and automation.

> 🟢 **Beginner to Advanced:** Start with Python 3 setup, master dynamic typing, data structures (Lists, Tuples, Sets, Dicts), functions, list comprehensions, OOP, decorators, generators, Exception handling, File I/O, JSON, CSV, Type Hints, Dataclasses, testing (`unittest`), virtual environments (`venv`), and capstone mini projects.

## 📖 What You Will Learn

- Setting up Python 3 interpreters, REPL interactive shell, and executing `.py` scripts
- Dynamic typing, variable scope, f-string formatting, and I/O (`input()` and `print()`)
- Control flow, modern Truthiness rules, `if...elif...else`, loops (`for`, `while`), and `for...else`
- Functions, positional vs keyword arguments, `*args`, `**kwargs`, closures, and LEGB scope rules
- Data structures: Lists, Tuples, Sets, Dictionaries, String methods, and List Comprehensions
- Modules, packages, imports, standard library (`math`, `random`, `sys`, `os`), and `if __name__ == "__main__":`
- Context managers (`with open(...)`), File I/O, JSON serialization, and CSV processing
- Exception handling (`try`, `except`, `else`, `finally`), custom exception classes
- Object-Oriented Programming (OOP): Classes, `__init__`, `self`, Inheritance, Encapsulation, and Duck Typing
- Iterators, Memory-efficient Generators (`yield`), and Decorators (`@functools.wraps`)
- Functional programming with `lambda`, `map()`, `filter()`, and `functools.reduce()`
- Regular Expressions (`re`), Datetime API (`datetime`), Type Hints, and Dataclasses (`@dataclass`)
- Automated unit testing (`unittest`), debugging (`breakpoint()` / `pdb`), `venv`, `pip`, and PEP 8 best practices

## 🎯 Suggested Learning Flow

`01–08 Python Fundamentals` → `09–14 Data Structures & Comprehensions` → `15–18 Advanced Functions, Modules & Files` → `19–22 OOP, Generators, Decorators & Functional Tools` → `23–27 Data Processing, Regex, JSON, CSV & Dataclasses` → `28–31 Testing, Virtual Environments, PEP 8 & Mini Projects`

## 🧪 Practice Routine

1. Read the lesson explanation, study the analogy, and analyze the Python code example.
2. Run every code example using `python3 script.py` or `py script.py`.
3. Experiment by tweaking parameters, testing null/falsy inputs, and observing errors.
4. Solve the **Try It Yourself** and **Mini Challenge** exercises.
5. Build capstone CLI projects using virtual environments (`venv`).

## ✅ Progress Checklist

- [ ] I can write and execute Python scripts in REPL and terminal.
- [ ] I understand dynamic typing, variable scope, f-strings, and type casting.
- [ ] I can use `if...elif...else`, truthiness, loops (`for`, `while`), and `for...else`.
- [ ] I can write functions with default args, `*args`, `**kwargs`, and closures.
- [ ] I can manipulate Lists, Tuples, Sets, Dictionaries, Strings, and List Comprehensions.
- [ ] I can organize code into Modules, Packages, and use standard library tools.
- [ ] I can handle files safely using `with open()`, process JSON, and write CSV files.
- [ ] I can handle exceptions using `try...except...else...finally` and custom exceptions.
- [ ] I understand OOP principles: Classes, `__init__`, `self`, Inheritance, Encapsulation, and Duck Typing.
- [ ] I can write memory-efficient Generators (`yield`) and Decorators (`@functools.wraps`).
- [ ] I can use `lambda`, `map()`, `filter()`, and `reduce()` for functional data transformations.
- [ ] I can validate text using Regular Expressions (`re`) and track dates using `datetime`.
- [ ] I can write Type Hints and concise Dataclasses (`@dataclass`).
- [ ] I can write automated unit tests using `unittest` and debug with `breakpoint()`.
- [ ] I can manage isolated project dependencies using `venv`, `pip`, and `requirements.txt`.
- [ ] I follow PEP 8 style guidelines and clean modular project structures.
