Elif-Else Ladder in Python in Python

🟢 Beginner

📖 Definition

An elif ladder evaluates sequential conditions using elif in Python.

⚡ Code Example

score = 85
if score >= 90: print("A")
elif score >= 80: print("B")
else: print("C")
