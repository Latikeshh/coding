The if Statement in Python 3

🟢 Beginner Level | Pythonic Control Flow

📖 Definition

The if statement in Python evaluates a expression and executes an indented code block if the condition evaluates to a truthy value. Unlike C or JavaScript, Python uses strict 4-space Indentation instead of curly braces { } to define code blocks.

🤔 Purpose

Conditionals enable Python programs to perform dynamic decision making—such as checking if a user authentication token is valid or checking if a database query returned results.

🌐 Multilingual Explanations

English

In Python, an if statement ends with a colon :. Statements within the if block must be indented by exactly 4 spaces. Any non-indented statement marks the end of the block.

Hindi

Python mein if condition: ke baad 4-space indentation aavashyak hai. Python mein { } braces nahi hote, code grouping purely indentation se hoti hai.

Marathi

Python madhye if statement saathi colon : ani 4-space indentation vaparatat. Code block indentation varun tharto.

Hinglish

Decision making ke liye if user_is_active: use karein. Inconsistent spacing IndentationError throw karti hai.

📝 Syntax & Parameters

if condition:
    # Indented block (4 spaces)
    pass
  • condition: Any expression evaluating to a boolean or truthy/falsy object.
  • : (colon): Mandatory syntax marker indicating the start of an indented block.

⚡ Execution Flow

  1. Python evaluates the expression following if.
  2. Implicit truthiness is determined (empty sequences [], "", 0, and None evaluate to False).
  3. If True, all indented lines following the colon execute sequentially.
  4. If False, Python skips the indented block.

💡 Progressive Examples

Example 1: Truthy Sequence Verification

items = ["Python", "JavaScript", "C"]

if items:
    print(f"List contains {len(items)} learning modules.")

🖥️ Expected Output

List contains 3 learning modules.

🔍 Line-by-Line Code Breakdown

  • items = [...]: Instantiates non-empty list.
  • if items:: Evaluates list truthiness (non-empty list yields True).
  • print(...): Executes indented formatted string output.

⚠️ Variations & Edge Cases

In Python, falsy values include False, None, 0, 0.0, "", [], (), and {}.

❌ Common Beginner Mistakes

Tab/Space Mixing: Mixing tabs and spaces results in an IndentationError: unindent does not match any outer indentation level.

🛠️ Real-World Practical Usage

Verifying API responses:

response = {"status": 200, "data": "OK"}

if response.get("status") == 200:
    print("API request successful!")

🎯 Tiered Practice Exercises

  1. Beginner: Write an `if` statement checking if a number is positive.
  2. Intermediate: Write an `if` statement checking if a key exists in a dictionary before accessing it.
  3. Advanced: Use Python's `all()` function inside an `if` statement to verify that all inputs in a list meet validation criteria.
