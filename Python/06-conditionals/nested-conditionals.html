Nested Conditionals in Python 3

🟢 Intermediate Level | Multi-Level Indented Logic

📖 Definition

A Nested Conditional in Python is an if block defined inside another if block. In Python, each nested level increases indentation by an additional 4 spaces (8 spaces, 12 spaces, etc.).

🤔 Purpose

Allows dependent multi-step criteria verification—such as checking if a file exists before verifying its read permissions.

🌐 Multilingual Explanations

English

Nested conditions in Python require strict indentation alignment. Inner blocks execute only when the outer if expression evaluates to True.

Nested if ka matlab hai if ke andar doosra if block hona. Har extra level par 4 extra spaces zaroori hain.

Hinglish

📝 Syntax & Parameters

if outer_condition:
    # Level 1 (4 spaces)
    if inner_condition:
        # Level 2 (8 spaces)
        pass

⚡ Execution Flow

  1. Evaluate outer_condition.
  2. If True, enter Level 1 and evaluate inner_condition.
  3. If inner_condition is True, execute Level 2 statements.

💡 Progressive Examples

Example 1: Nested Account Access

user_exists = True
is_active = True

if user_exists:
    if is_active:
        print("User authenticated and active!")
    else:
        print("User account deactivated.")

🖥️ Expected Output

User authenticated and active!

🔍 Line-by-Line Code Breakdown

  • if user_exists:: Evaluates True, entering outer block.
  • if is_active:: Evaluates True (8 spaces indented), printing success.

⚠️ Variations & Edge Cases

Refactor over-nested blocks using Python's and logical operator: if user_exists and is_active:.

❌ Common Beginner Mistakes

Inconsistent Indentation: Mixing 4-space and 2-space indentation levels throws an IndentationError.

🛠️ Real-World Practical Usage

Hierarchical dictionary key validation.
