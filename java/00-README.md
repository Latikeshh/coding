# Learn Java

This beginner-to-practical course teaches Java by writing small programs and building toward useful applications. It uses Java SE 25 (JDK 25) as its reference version; code uses stable language features and avoids preview features. Java SE 25 was released in September 2025 and is an LTS release. See the [JDK 25 documentation](https://docs.oracle.com/en/java/javase/25/) and [release announcement](https://www.oracle.com/news/announcement/oracle-releases-java-25-2025-09-16/).

## Introduction

Java is a general-purpose, class-based, statically and strongly typed programming language. Java source is normally compiled to bytecode, then executed by a Java Virtual Machine (JVM); modern JVMs may also compile frequently used code to native machine code while running. Java is not indentation-sensitive: braces define blocks, while indentation makes them readable.

Java is popular because it has a large ecosystem, a mature standard library, broad tooling, and JVM implementations for many platforms. It is used for backend and enterprise services, Android applications (alongside Kotlin), desktop tools, build systems, automation, and data-processing systems. Java can support scripting through tools such as JShell and single-file source launch, and libraries can be used in data science and machine learning; Python is more common for exploratory data science and ML workflows. Java is useful for beginners because its explicit types and structure make data, control flow, and object-oriented design visible while still letting learners build substantial programs.

## Prerequisites

- Basic computer and file management skills.
- No prior programming language is required.
- Curiosity, patience, and willingness to type, run, change, and debug code.

## Curriculum Roadmap

- **01–05 — Java Fundamentals:** setup, syntax, values, input/output, operators.
- **06–09 — Control Flow and Methods:** decisions, loops, methods, arrays.
- **10–13 — Core Java Types:** strings, collections, enums, records, and generics.
- **14–19 — Object-Oriented and Robust Programs:** classes, inheritance, interfaces, exceptions, packages, files.
- **20–24 — Practical Development:** lambdas and streams, dates, testing/debugging, build tools, projects.

## Practice Routine

1. Read the concept and compare it with the example.
2. Type and run the code yourself.
3. Change an input or rule and predict the result first.
4. Try the exercises without looking at a solution.
5. Build a small project that combines several lessons.
