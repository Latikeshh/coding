01. ORDER BY Multi-column Sorting in SQL

🟢 Beginner Level | Result Ordering & ASC/DESC Direction

📖 What is ORDER BY?

The ORDER BY clause sorts query results by one or more columns in ascending (ASC, default) or descending (DESC) order.

📝 Code Example

SELECT employee_name, department, salary
FROM employees
ORDER BY department ASC, salary DESC;
