02. LIMIT & OFFSET Pagination in SQL

🟢 Beginner Level | Query Result Capping & UI Pagination

📖 What are LIMIT & OFFSET?

The LIMIT clause bounds the maximum number of rows returned by a query. The optional OFFSET clause skips a specified number of initial rows before returning the result batch.

📝 Code Example: Fetching Page 3 (10 items per page)

SELECT product_id, product_name, price
FROM products
ORDER BY product_id ASC
LIMIT 10 OFFSET 20; -- Skips first 20 rows, returns next 10
