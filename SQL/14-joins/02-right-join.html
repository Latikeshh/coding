02. The RIGHT JOIN (RIGHT OUTER JOIN) Clause in SQL

🟢 Intermediate Level | Preserving Right Table Rows & NULL Padding

📖 What is a RIGHT JOIN?

A RIGHT JOIN returns all records from the right table (Table B), along with matched records from the left table (Table A). Unmatched left table fields return NULL.

📝 Code Example

SELECT customers.customer_name, orders.order_id
FROM customers
RIGHT JOIN orders ON customers.customer_id = orders.customer_id;
