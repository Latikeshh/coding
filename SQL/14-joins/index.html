SQL Joins & Table Relationships

🟢 Module Overview: Master relational queries, table joins, foreign key links, and data matching.

📖 What are SQL Joins?

A SQL JOIN clause combines rows from two or more database tables based on a related column between them (typically Primary Key $\leftrightarrow$ Foreign Key relationships).

📚 Module Lessons

  • 1. The INNER JOIN Clause: Matching records present in both related tables.
  • 2. The OUTER JOINs (LEFT, RIGHT, FULL): Including unmatched rows from left or right tables.
  • 3. The SELF JOIN: Joining a table with itself to model hierarchical tree data.
  • 4. The CROSS JOIN: Cartesian product row matrix generation.
