03. The FULL OUTER JOIN Clause in SQL

🟡 Intermediate Level | Combining Left and Right Outer Joins

📖 What is a FULL OUTER JOIN?

A FULL OUTER JOIN returns all records when there is a match in left or right table records. Unmatched fields from either side are padded with NULL.

📝 Code Example (PostgreSQL / Standard SQL)

SELECT customers.customer_name, orders.order_id
FROM customers
FULL OUTER JOIN orders ON customers.customer_id = orders.customer_id;
