SQL LEFT JOIN & RIGHT JOIN Outer Joins

🟢 Intermediate Level | Preserving Unmatched Relational Records

📖 Definition

A LEFT OUTER JOIN (or simply LEFT JOIN) returns all records from the left table, along with matching records from the right table. If no match exists, NULL values are populated for right table columns.

🤔 Purpose

Preserves all primary records—such as listing all customers regardless of whether they have placed an order yet.

🌐 Multilingual Explanations

English

Unlike INNER JOIN, LEFT JOIN guarantees that every row from the left table appears in the output at least once. Unmatched right table fields return NULL.

Hindi

LEFT JOIN left table ke saare records preserve karta hai, chahe right table mein match ho ya na ho. Unmatched fields NULL show hote hain.

Marathi

Left table madhil sarv rows output madhye distat.

Hinglish

Preserve left table: SELECT * FROM users LEFT JOIN orders ON users.id = orders.user_id query use karein.

📝 Syntax & Parameters

SELECT u.user_name, o.order_id
FROM users u
LEFT JOIN orders o
  ON u.user_id = o.user_id;

⚡ Execution Flow

  1. All rows from left table (users) are fetched.
  2. For each row, right table (orders) is searched for matches.
  3. If matched, combined row is output. If no match, right fields are filled with NULL.

💡 Progressive Examples

Example 1: Customers with and without Orders

SELECT u.user_name, o.order_id, o.order_total
FROM users u
LEFT JOIN orders o
  ON u.user_id = o.user_id;

🖥️ Expected Output

+-----------+----------+-------------+
| user_name | order_id | order_total |
+-----------+----------+-------------+
| Latikesh  |     1001 |      199.99 |
| Sarah     |     NULL |        NULL |
+-----------+----------+-------------+

🔍 Line-by-Line Code Breakdown

  • LEFT JOIN orders: Retains Sarah (user with 0 orders) while populating NULL for order fields.

⚠️ Variations & Edge Cases

Filtering with WHERE o.order_id IS NULL finds users who have NEVER placed an order!

❌ Common Beginner Mistakes

Filtering Left Joined Columns in WHERE: Adding WHERE o.order_status = 'COMPLETED' implicitly converts a LEFT JOIN into an INNER JOIN because NULLs fail the equality check!

🛠️ Real-World Practical Usage

Identifying inactive accounts or orphaned records.

🎯 Tiered Practice Exercises

  1. Beginner: Write a SQL `LEFT JOIN` showing all departments and their assigned employees.
  2. Intermediate: Write a `LEFT JOIN` query finding all products that have never been purchased (`WHERE order_id IS NULL`).
  3. Advanced: Use a `FULL OUTER JOIN` to combine unmatched rows from both left and right tables.
