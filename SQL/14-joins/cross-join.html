The CROSS JOIN Clause in SQL

🟢 Intermediate Level | Cartesian Product Generation

📖 Definition

A CROSS JOIN produces a Cartesian product between two database tables, pairing every row from Table A with every row from Table B. If Table A has $N$ rows and Table B has $M$ rows, the result set contains $N \times M$ rows.

🤔 Purpose

Used to generate complete matrices, product combinations (e.g. sizes $\times$ colors), date grids, and test data permutations.

🌐 Multilingual Explanations

English

A CROSS JOIN returns all possible combinations of rows from the joined tables without requiring an ON predicate.

📝 Syntax & Parameters

SELECT t1.column1, t2.column2
FROM table1 t1
CROSS JOIN table2 t2;

💡 Progressive Example

-- Generating all combinations of products and sizes
SELECT products.product_name, sizes.size_code
FROM products
CROSS JOIN sizes;
