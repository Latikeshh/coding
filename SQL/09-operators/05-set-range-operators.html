Set & Range Operators in SQL Database

🟢 Beginner

📖 Definition

SQL Set & Range Operators filter values within lists or ranges (IN, NOT IN, BETWEEN ... AND, EXISTS).

⚡ Code Example

SELECT * FROM products WHERE price BETWEEN 10 AND 50 AND category_id IN (1, 3, 5);
