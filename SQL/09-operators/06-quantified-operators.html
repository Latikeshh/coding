Quantified Operators in SQL Database

🟢 Beginner

📖 Definition

SQL Quantified Operators compare a single scalar value against every result in a subquery (ALL, ANY / SOME).

⚡ Code Example

SELECT * FROM products WHERE price > ALL (SELECT price FROM products WHERE category_id = 2);
