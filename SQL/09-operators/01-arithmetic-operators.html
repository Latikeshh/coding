Arithmetic Operators in SQL Database

🟢 Beginner

📖 Definition

SQL Arithmetic Operators perform math calculations on table columns (+, -, *, /, %).

⚡ Code Example

SELECT product_name, price * 1.18 AS price_with_tax FROM products;
