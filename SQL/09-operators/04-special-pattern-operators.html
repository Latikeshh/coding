Pattern Matching Operators in SQL Database

🟢 Beginner

📖 Definition

SQL Pattern Matching Operators search text strings using wildcards (LIKE, ILIKE, REGEXP / ~).

⚡ Code Example

SELECT * FROM customers WHERE email LIKE '%@gmail.com';
