Input & Output in Java (Scanner & System.out)

🟢 Beginner Level | Core Fundamentals

📖 Definition & Purpose

Java handles console output using System.out.println() and System.out.printf(), and parses user console input using the java.util.Scanner class or BufferedReader.

🌐 Multilingual Explanations

English

System.out.println() prints output followed by a new line. Scanner parses primitives and strings from System.in.

Hindi

User se input lene ke liye Scanner sc = new Scanner(System.in) use hota hai, aur output ke liye System.out.println().

Marathi

Console var input ghenyasathi Scanner class vapra aani display sathi System.out.println().

Hinglish

Scanner = User input reader (`sc.nextInt()`, `sc.nextLine()`). System.out.printf = Formatted output with `%d`, `%s`, `%.2f` placeholders.

💡 Production Code Example

import java.util.Scanner;

public class UserInputDemo {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = scanner.nextLine();

        System.out.print("Enter your age: ");
        int age = scanner.nextInt();

        System.out.printf("User: %s | Age: %d years old%n", name, age);
        scanner.close();
    }
}

🖥️ Expected Output

Enter your name: Alex
Enter your age: 24
User: Alex | Age: 24 years old

⚠️ Common Pitfalls

Scanner Newline Bug: Calling scanner.nextLine() immediately after scanner.nextInt() reads the leftover newline character instead of waiting for user text input! Fix by calling an extra scanner.nextLine() to clear the buffer.
