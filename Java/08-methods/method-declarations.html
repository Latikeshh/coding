Method Declarations & Overloading in Java SE

🟢 Beginner Level | Strongly-Typed Java OOP Logic

📖 Definition

A Java Method is a block of code declared inside a class containing an access modifier, return type, method name, and parameter list. Method Overloading defines multiple methods with identical names but distinct parameter signatures within the same class.

🤔 Purpose

Enables object behavior implementation and flexible polymorphism where methods handle different data type inputs cleanly.

🌐 Multilingual Explanations

English

Method overloading is resolved at compile-time (static polymorphism) based on parameter count, types, and sequence order.

📝 Syntax & Parameters

public class Calculator {
    // Overloaded Method 1 (int)
    public static int multiply(int a, int b) {
        return a * b;
    }

    // Overloaded Method 2 (double)
    public static double multiply(double a, double b) {
        return a * b;
    }
}

⚡ Execution Flow

  1. Java compiler selects overloaded method matching exact argument types at compile-time.
  2. JVM pushes stack frame for method invocation.
  3. Executes instructions and returns primitive value or object reference.

💡 Progressive Examples

Example 1: Method Overloading Demo

public class MethodDemo {
    public static int add(int a, int b) {
        return a + b;
    }

    public static int add(int a, int b, int c) {
        return a + b + c;
    }

    public static void main(String[] args) {
        System.out.println("2 args sum: " + add(10, 20));
        System.out.println("3 args sum: " + add(10, 20, 30));
    }
}

🖥️ Expected Output

2 args sum: 30
3 args sum: 60

🔍 Line-by-Line Code Breakdown

  • public static int add(int a, int b): Two-parameter overload returning integer.
  • public static int add(int a, int b, int c): Three-parameter overload.

⚠️ Variations & Edge Cases

Overloading CANNOT be achieved solely by changing the return type; parameter types or count MUST differ!

❌ Common Beginner Mistakes

Duplicate Method Error: Declaring public int calc(int a) and public double calc(int a) in the same class produces a compile-time error.
