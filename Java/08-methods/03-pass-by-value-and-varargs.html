Pass-by-Value & Varargs in Java

🟢 Beginner Level | Java Core Syntax

📖 Definition

Java is strictly pass-by-value. For primitives, copies of values are passed. For objects, copies of memory references are passed. Varargs (Type... args) accept arbitrary argument counts as an array.

⚡ Code Example

public static void printScores(String name, int... scores) {
    System.out.println(name + " has " + scores.length + " scores");
}
