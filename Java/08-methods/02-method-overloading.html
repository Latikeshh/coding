Method Overloading in Java

🟢 Beginner Level | Java Core Syntax

📖 Definition

Method Overloading allows a class to define multiple methods sharing the exact same name as long as their parameter lists differ in type, count, or order (compile-time polymorphism).

⚡ Code Example

public int multiply(int a, int b) { return a * b; }
public double multiply(double a, double b) { return a * b; }
