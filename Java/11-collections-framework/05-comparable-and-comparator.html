Comparable & Comparator Sorting in Java

🟢 Beginner Level | Java Core Syntax

📖 Definition

Comparable defines natural sorting order via compareTo(). Comparator defines custom external sorting strategies.

⚡ Code Example

List names = Arrays.asList("Bob", "Alice");
names.sort(Comparator.naturalOrder());
