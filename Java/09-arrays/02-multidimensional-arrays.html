Multidimensional & Jagged Arrays in Java

🟢 Beginner Level | Java Core Syntax

📖 Definition

Multidimensional Arrays are arrays of arrays (e.g. 2D grid matrix). Jagged Arrays are multidimensional arrays where sub-array rows have varying column lengths.

⚡ Code Example

int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};
