Ternary Operator in Java in Java

🟢 Beginner

📖 Definition

The Ternary Operator (cond ? val1 : val2) provides inline conditional assignment in Java.

⚡ Code Example

public class TernaryDemo {
    public static void main(String[] args) {
        int a = 10, b = 20;
        int max = (a > b) ? a : b;
        System.out.println("Max: " + max);
    }
}
