The if-else Statement in Java

🟢 Beginner Level | Java Strongly-Typed Control Flow

📖 Definition

The if-else statement in Java executes a code block if a test condition evaluates to Boolean true, or executes an alternative else block if it evaluates to false.

🤔 Purpose

In enterprise Java applications, strictly typed boolean checks—such as validating user permissions or verifying payment gateway transaction status—determine execution pathways.

🌐 Multilingual Explanations

English

In Java, the condition inside if (condition) must strictly evaluate to Java's primitive type boolean. Integers like 0 or 1 cannot be implicitly cast to boolean.

Hindi

Java mein if (condition) hamesha true ya false evaluate honi chahiye. C/C++ ki tarah 0 ya 1 non-zero numbers automatically boolean mein convert nahi hote.

Marathi

Java madhye condition hamesha explicit boolean pahije. Number la boolean mhanun waparata yet nahi.

Hinglish

Strict typing: if (balance >= amount) { ... } else { ... } execute hota hai.

📝 Syntax & Parameters

if (booleanExpression) {
    // Executed if booleanExpression is true
} else {
    // Executed if booleanExpression is false
}
  • booleanExpression: Expression yielding primitive Java boolean.

⚡ Execution Flow

  1. Java evaluates booleanExpression.
  2. If true, the if block executes, and the else block is skipped.
  3. If false, the if block is skipped, and the else block executes.

💡 Progressive Examples

Example 1: Bank Balance Check

public class BankCheck {
    public static void main(String[] args) {
        double balance = 450.00;
        double withdrawal = 500.00;

        if (balance >= withdrawal) {
            System.out.println("Transaction approved!");
        } else {
            System.out.println("Error: Insufficient funds.");
        }
    }
}

🖥️ Expected Output

Error: Insufficient funds.

🔍 Line-by-Line Code Breakdown

  • double balance = 450.00;: Declares double primitive variable.
  • if (balance >= withdrawal): Evaluates 450.0 >= 500.0, yielding false.
  • System.out.println(...): Outputs error string inside else block.

⚠️ Variations & Edge Cases

Java requires brackets { } for blocks with multiple statements. Omitting brackets applies the if condition to only the single immediate statement following it!

❌ Common Beginner Mistakes

Type Mismatch Error: Writing if (1) results in a Java compilation error: incompatible types: int cannot be converted to boolean.

🛠️ Real-World Practical Usage

Spring Boot Security authorization check:

if (user.hasRole("ADMIN")) {
    renderAdminDashboard();
} else {
    throw new AccessDeniedException("Unauthorized user role");
}
