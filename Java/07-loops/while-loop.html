While Loop in Java in Java

🟢 Beginner Level | Java Core Syntax

📖 Definition

The while loop is an entry-controlled loop that continues executing a statement block as long as its boolean condition evaluates to true.

⚡ Code Example

int count = 1;
while (count <= 3) {
    System.out.println("Count: " + count);
    count++;
}
