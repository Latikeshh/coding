while & do-while Loops in Java

🟢 Beginner Level | Pre-tested & Post-tested Condition Loops

📖 Definition

The while loop tests a boolean condition before executing its body. The do-while loop executes its body first, testing the condition at the end, guaranteeing at least one execution.

🤔 Purpose

Used when iteration count depends on dynamic events (such as reading InputStream data or validating Scanner user input in CLI apps).

🌐 Multilingual Explanations

English

Java's while (condition) pre-tests an expression. do { ... } while (condition); post-tests, running body first.

Hindi

while pehle condition check karta hai. do-while pehle ek baar code chala deta hai phir condition check karta hai.

Hinglish

Input validation loop: do { input = scanner.nextInt(); } while (input < 0); pattern follow karein.

📝 Syntax & Parameters

// Pre-tested while loop
while (booleanCondition) {
    // Body
}

// Post-tested do-while loop
do {
    // Body (runs at least once)
} while (booleanCondition);

⚡ Execution Flow

  1. while: Test condition $\rightarrow$ if true, run body $\rightarrow$ repeat.
  2. do-while: Run body $\rightarrow$ Test condition $\rightarrow$ if true, repeat.

💡 Progressive Examples

Example 1: Input Validation Loop

public class WhileDemo {
    public static void main(String[] args) {
        int count = 3;

        while (count > 0) {
            System.out.println("Processing queue item #" + count);
            count--;
        }
    }
}

🖥️ Expected Output

Processing queue item #3
Processing queue item #2
Processing queue item #1

🔍 Line-by-Line Code Breakdown

  • while (count > 0): Tests if integer count is greater than 0.
  • count--: Decrements state counter to avoid infinite loops.

⚠️ Variations & Edge Cases

Always place a trailing semicolon after while (condition); in a `do-while` loop construct.

❌ Common Beginner Mistakes

Infinite Loop: Omitting the state update step inside the loop body causes infinite execution freezing the thread.

🛠️ Real-World Practical Usage

Reading socket data buffers until EOF.
