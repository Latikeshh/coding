Enhanced For-Each Loop in Java

🟢 Beginner Level | Java Core Syntax

📖 Definition

The Enhanced For-Each loop simplifies iteration over arrays and Iterable collections without requiring explicit index tracking.

⚡ Code Example

String[] names = {"Alice", "Bob", "Charlie"};
for (String name : names) {
    System.out.println("Hello " + name);
}
