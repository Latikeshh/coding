Enhanced for-each Loop in Java

🟢 Beginner Level | Collection & Array Iteration

📖 Definition

The Enhanced for-each loop (introduced in Java 5) provides a clean syntax to iterate through elements of arrays or Iterable collections without using manual index counters.

🤔 Purpose

Eliminates index counter boilerplates and prevents ArrayIndexOutOfBoundsException when reading arrays or collections sequentially.

🌐 Multilingual Explanations

English

The for (ElementType item : collection) loop binds each element of collection sequentially to local variable item.

Hindi

Java mein for (String name : namesList) syntax collection ke har item ko बारी-बारी read karta hai. Index i ki zaroorat nahi hoti.

Marathi

Enhanced for loop mule array aani collections sahaj read karta yetat.

Hinglish

Clean array reading: for (int mark : marksArray) { sum += mark; } pattern follow karein.

📝 Syntax & Parameters

for (DataType element : arrayOrCollection) {
    // Body statements operating on element
}

⚡ Execution Flow

  1. Java fetches an internal iterator or array index offset.
  2. Assigns current element to element.
  3. Executes body statements. Repeats until all items are processed.

💡 Progressive Examples

Example 1: Iterating String Array

public class ForEachDemo {
    public static void main(String[] args) {
        String[] frameworks = {"Spring Boot", "Hibernate", "Quarkus"};

        for (String fw : frameworks) {
            System.out.println("Java Framework: " + fw);
        }
    }
}

🖥️ Expected Output

Java Framework: Spring Boot
Java Framework: Hibernate
Java Framework: Quarkus

🔍 Line-by-Line Code Breakdown

  • for (String fw : frameworks): Sequentially binds each String element to local fw.
  • System.out.println(...): Outputs element text to stdout.

⚠️ Variations & Edge Cases

The enhanced for-each loop is **read-only** regarding array references; modifying local element variable does NOT mutate the original array element!

❌ Common Beginner Mistakes

Modifying Collection During Iteration: Calling list.remove() inside a for-each loop throws a ConcurrentModificationException!

🛠️ Real-World Practical Usage

Processing Spring Data entity result lists.

🎯 Tiered Practice Exercises

  1. Beginner: Write a Java enhanced for-each loop summing numbers in an integer array.
  2. Intermediate: Write a for-each loop iterating over a List<String> filtering items starting with 'A'.
  3. Advanced: Iterate over a Map<String, Integer> using map.entrySet() with an enhanced for-each loop.
