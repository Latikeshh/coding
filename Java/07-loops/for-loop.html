For Loop in Java in Java

🟢 Beginner Level | Java Core Syntax

📖 Definition

The for loop is a entry-controlled loop used when the total number of iterations is known in advance.

⚡ Code Example

for (int i = 1; i <= 5; i++) {
    System.out.println("Iteration: " + i);
}
