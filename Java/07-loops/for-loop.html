The for Loop in Java

🟢 Beginner Level | Counting & Array Traversal

📖 Definition

The for loop in Java executes a statement block repeatedly for a fixed number of iterations governed by counter initialization, boolean condition testing, and step updates.

🤔 Purpose

When the number of iterations is known—such as processing all elements in a Java array or collection—a for loop provides a structured control header.

🌐 Multilingual Explanations

English

Java's standard for (int i = 0; i < N; i++) declares a local loop variable i scoped strictly to the loop header and body.

📝 Syntax & Parameters

for (initialization; booleanCondition; update) {
    // Loop body statements
}
  • initialization: Declares loop control variable (e.g. int i = 0).
  • booleanCondition: Evaluated before each iteration. Must return a primitive boolean.
  • update: Modifies counter variable after each iteration (e.g. i++).

⚡ Execution Flow

  1. initialization executes once.
  2. booleanCondition is evaluated. If false, loop terminates.
  3. The statements inside { ... } execute.
  4. The update expression executes, and control returns to condition evaluation.

💡 Progressive Examples

Example 1: Basic Counting

public class LoopDemo {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            System.out.println("Java Loop Count: " + i);
        }
    }
}

🖥️ Expected Output

Java Loop Count: 1
Java Loop Count: 2
Java Loop Count: 3

🔍 Line-by-Line Code Breakdown

  • int i = 1: Declares primitive int loop control variable.
  • i <= 3: Evaluates if i is less than or equal to 3.
  • System.out.println(...): Prints iteration count to standard output stream.

⚠️ Variations & Edge Cases

In Java 5+, the **Enhanced `for-each` loop** (for (String item : array)) simplifies reading elements without manual index management.

❌ Common Beginner Mistakes

ArrayIndexOutOfBoundsException: Accessing array[array.length] inside a for (int i = 0; i <= array.length; i++) loop throws a runtime exception because Java arrays are 0-indexed.

🛠️ Real-World Practical Usage

Accumulating values in a list:

int[] prices = {100, 200, 300};
int total = 0;

for (int i = 0; i < prices.length; i++) {
    total += prices[i];
}
System.out.println("Total Cart Price: $" + total);
