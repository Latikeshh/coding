Encapsulation in Java

🟢 Beginner Level | Java Core Syntax

📖 Definition

Encapsulation hides internal object data by declaring fields private and providing public getter and setter validation methods.

⚡ Code Example

public class Person {
    private int age;
    public void setAge(int age) { if (age > 0) this.age = age; }
}
