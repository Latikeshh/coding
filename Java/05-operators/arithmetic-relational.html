Arithmetic & Relational Operators in Java SE

🟢 Beginner Level | Strongly-Typed Java Arithmetic

📖 Definition

Arithmetic Operators (+, -, *, /, %) compute mathematical values in Java. Integer division (int / int) truncates fractional values toward zero. Relational Operators (==, !=, >, <, >=, <=) evaluate to boolean true or false.

🤔 Purpose

Provides strongly-typed numerical calculations and logical branching checks across JVM application threads.

🌐 Multilingual Explanations

English

In Java, 5 / 2 evaluates to integer 2. To retain precision, cast one operand to double (e.g. (double)5 / 2 = 2.5).

Hindi

Java mein 5 / 2 result integer 2 deta hai. Precision ke liye explicit double casting (double)5 / 2 require hoti hai.

Marathi

Integer division decimal truncation kartat.

Hinglish

Explicit cast: double res = (double)count / total; precision loss prevent karta hai.

📝 Syntax & Parameters

int a = 9, b = 2;
int div = a / b;            // 4
double exact = (double)a / b; // 4.5
boolean test = (a > b);    // true

⚡ Execution Flow

  1. JVM loads primitive stack values via bytecode instructions (`idiv`, `fdiv`).
  2. Performs mathematical calculation or relational comparison.
  3. Pushes resulting integer or boolean `1`/`0` value onto evaluation stack.

💡 Progressive Examples

Example 1: Precision Division & String Concatenation

public class OperatorDemo {
    public static void main(String[] args) {
        int items = 10;
        int rate = 3;

        System.out.println("Truncated Div: " + (items / rate));
        System.out.println("Exact Div: " + ((double)items / rate));
    }
}

🖥️ Expected Output

Truncated Div: 3
Exact Div: 3.3333333333333335

🔍 Line-by-Line Code Breakdown

  • items / rate: Evaluates integer division `10 / 3 = 3`.
  • (double)items / rate: Promotes operand to double for full floating-point precision.

⚠️ Variations & Edge Cases

Using == on Java objects compares memory references (addresses), NOT object contents! Use .equals() for object equality.

❌ Common Beginner Mistakes

Comparing Strings with `==`: Writing str1 == str2 tests reference identity, which fails when string instances differ in heap memory.

🛠️ Real-World Practical Usage

Financial calculations and pagination offset calculations.

🎯 Tiered Practice Exercises

  1. Beginner: Write a Java snippet calculating the remainder of 45 divided by 6 using `%`.
  2. Intermediate: Use explicit double casting to calculate exact percentage.
  3. Advanced: Explain why `str1.equals(str2)` is required instead of `str1 == str2`.
