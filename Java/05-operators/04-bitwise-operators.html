Bitwise & Shift Operators in Java

🟢 Beginner

📖 Definition

Bitwise & Shift Operators in Java include bitwise AND (&), OR (|), XOR (^), complement (~), signed left shift (<<), signed right shift (>>), and unsigned right shift (>>>).

⚡ Code Example

int a = -8;
int res = a >>> 2; // Unsigned right shift fills with zeros
