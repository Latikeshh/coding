Arithmetic Operators in Java

🟢 Beginner

📖 Definition

Arithmetic Operators perform mathematical calculations such as addition, subtraction, multiplication, division, and modulo.

🌍 Multilingual Summary

English

Use +, -, *, /, and % (modulo) for math operations.

Hindi

Basic math operations ke liye arithmetic operators use hote hain.

⚡ Javaode Example

int a = 10, b = 3;
int sum = a + b;   // 13
int rem = a % b;   // 1 (remainder)
