Increment & Decrement in Java

🟢 Beginner

📖 Definition

Increment (++) and Decrement (--) Operators increase or decrease an integer variable's value by 1.

🌍 Multilingual Summary

English

Pre-increment (++x) increases first; post-increment (x++) uses current value first.

Hindi

Value ko 1 se badhane ya ghatane ke liye ++ aur -- use hota hai.

⚡ Javaode Example

int count = 5;
int a = ++count; // count=6, a=6
int b = count++; // b=6, count=7
