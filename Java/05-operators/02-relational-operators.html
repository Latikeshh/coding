Relational Operators in Java

🟢 Beginner

📖 Definition

Relational Operators compare two values and return a boolean true (1) or false (0).

🌍 Multilingual Summary

English

Use ==, !=, <, >, <=, and >= to compare values.

Hindi

Do values ko compare karne ke liye relational operators use hote hain.

⚡ Javaode Example

int x = 5, y = 10;
if (x < y) {
    printf("x is smaller");
}
