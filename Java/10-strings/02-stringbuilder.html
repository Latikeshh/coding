StringBuilder Class in Java

🟢 Beginner Level | Java Core Syntax

📖 Definition

StringBuilder is a mutable, non-thread-safe character sequence container designed for efficient string modification inside single-threaded loops.

⚡ Code Example

StringBuilder sb = new StringBuilder("Hello");
sb.append(" World");
System.out.println(sb.toString()); // "Hello World"
