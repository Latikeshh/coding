Variables & The 8 Primitive Data Types

🟢 Beginner Level | Java Core Syntax

📖 Definition

A Variable is a named location in memory used to store data values. Java is a statically typed language featuring 8 Primitive Data Types: byte, short, int, long, float, double, boolean, and char.

🌐 Multilingual Explanations

English

Primitives store raw values directly on the JVM Stack memory. Each primitive has a fixed bit size (e.g. int is 32-bit, long is 64-bit).

Hindi

Java mein har variable ka data type declare karna zaroori hota hai. Primitive types direct values store karte hain Stack memory mein.

Marathi

Java madhye pratyek variable cha type sangava lagto. Primitive types raw values Stack memory madhye jatan kartat.

Hinglish

Variables are like labeled storage boxes. `int` for whole numbers, `double` for decimals, `boolean` for true/false.

⚡ Code Example

public class PrimitivesDemo {
    public static void main(String[] args) {
        int age = 25;
        long population = 8000000000L; // 'L' suffix required for long
        float pi = 3.14159f;           // 'f' suffix required for float
        double distance = 149600000.50;
        boolean isActive = true;
        char grade = 'A';

        System.out.println("Age: " + age + ", Population: " + population);
    }
}

⚠️ Common Pitfalls

Missing Literal Suffixes: Forgetting the L suffix on large integer values or f on float numbers causes compile-time syntax errors (`integer number too large` or `possible loss of precision`).

🎯 Tiered Practice Exercises

  1. Beginner: Declare variables representing a product's price, quantity, and in-stock boolean flag.
  2. Intermediate: Demonstrate the difference in precision between float and double during calculations.
  3. Advanced: Explain how JVM Stack memory handles local primitive variable declarations.
