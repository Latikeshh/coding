Checked vs Unchecked Exceptions in Java

🟢 Beginner Level | Java Core Syntax

📖 Definition

Checked Exceptions (e.g. IOException) are verified at compile-time. Unchecked Exceptions (e.g. NullPointerException) occur at runtime.

⚡ Code Example

// Unchecked ArithmeticException
int res = 10 / 0;
