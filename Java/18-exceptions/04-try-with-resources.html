Try-With-Resources in Java

🟢 Beginner Level | Java Core Syntax

📖 Definition

try-with-resources automatically closes declared AutoCloseable stream resources upon block completion.

⚡ Code Example

try (Scanner scanner = new Scanner(new File("data.txt"))) {
    // Scanner automatically closed
} catch (FileNotFoundException e) { e.printStackTrace(); }
