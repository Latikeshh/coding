Lambda Expressions in Java

🟢 Beginner Level | Java Core Syntax

📖 Definition

Lambda Expressions (() -> {}) provide concise functional implementations for single-abstract-method @FunctionalInterface targets.

⚡ Code Example

Runnable r = () -> System.out.println("Running in thread");
