File I/O & NIO.2 in Java

🟢 Beginner Level | Java Core Syntax

📖 Definition

Java NIO.2 (java.nio.file.Files, Path) provides modern asynchronous file reading, writing, and directory operations.

⚡ Code Example

Path path = Paths.get("data.txt");
List lines = Files.readAllLines(path);
