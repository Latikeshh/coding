Ordered Lists (<ol>, <li>, type, start)

🟢 Beginner

📖 Definition

An Ordered List (<ol>) groups items into numbered or alphabetical sequences where step order is essential.

🌍 Multilingual Summary

English

Use <ol> with type, start, and reversed attributes for sequential steps.

Hindi

Step-by-step numbered instructions ke liye <ol> tag use hota hai.

⚡ Code Example

<ol type="1" start="1">
  <li>Open VS Code Editor.</li>
  <li>Create an index.html file.</li>
  <li>Preview in Web Browser.</li>
</ol>
