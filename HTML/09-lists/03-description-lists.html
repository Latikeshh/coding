Description Lists (<dl>, <dt>, <dd>)

🟢 Beginner

📖 Definition

A Description List (<dl>) pairs term names (<dt>) with term descriptions (<dd>), ideal for glossaries, metadata, or key-value pairs.

🌍 Multilingual Summary

English

Use <dl> for term-definition pairs (<dt> for term, <dd> for description).

Hindi

Glossaries aur key-value definitions ke liye <dl>, <dt>, aur <dd> use hote hain.

⚡ Code Example

<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language for web page structure.</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets for layout styling.</dd>
</dl>
