Unordered Lists (<ul>, <li>)

🟢 Beginner

📖 Definition

An Unordered List (<ul>) groups items into bulleted list points where sequence order does not matter.

🌍 Multilingual Summary

English

Use <ul> containing <li> list items for bulleted lists.

Hindi

Bulleted lists ke liye <ul> tag aur <li> items use hote hain.
