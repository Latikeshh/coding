Colspan & Rowspan Attributes (colspan, rowspan)

🟢 Beginner

📖 Definition

The colspan and rowspan attributes span table cells across multiple columns or rows, enabling complex multi-cell table layouts.

🌍 Multilingual Summary

English

Use colspan="N" to merge N columns horizontally and rowspan="N" to merge N rows vertically.

Hindi

Columns merge karne ke liye colspan aur rows merge karne ke liye rowspan attribute use hota hai.

⚡ Code Example

<table border="1">
  <tr>
    <th colspan="2">Full Name</th>
  </tr>
  <tr>
    <td>First</td>
    <td>Last</td>
  </tr>
</table>
