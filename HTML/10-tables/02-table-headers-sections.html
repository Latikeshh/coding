Table Sections (<thead>, <tbody>, <tfoot>, <caption>)

🟢 Beginner

📖 Definition

Semantic table section tags—<thead>, <tbody>, <tfoot>, and <caption>—structure long data tables for screen reader accessibility and clean CSS styling.

🌍 Multilingual Summary

English

Use <caption> for title, <thead> for headers, <tbody> for rows, and <tfoot> for totals.

Hindi

Table title ke liye <caption>, header rows ke liye <thead>, main data ke liye <tbody>, aur totals ke liye <tfoot> tag hota hai.

⚡ Code Example

<table>
  <caption>Monthly Sales Report</caption>
  <thead>
    <tr><th>Month</th><th>Sales</th></tr>
  </thead>
  <tbody>
    <tr><td>Jan</td><td>$5,000</td></tr>
  </tbody>
  <tfoot>
    <tr><td>Total</td><td>$5,000</td></tr>
  </tfoot>
</table>
