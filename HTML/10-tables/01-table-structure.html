Table Structure (<table>, <tr>, <td>, <th>)

🟢 Beginner

📖 Definition

HTML Tables (<table>) organize structured data into grid rows (<tr>), header cells (<th>), and data cells (<td>).

🌍 Multilingual Summary

English

Use <table>, <tr> for rows, <th> for headers, and <td> for data cells.

Hindi

Tabular data display karne ke liye <table>, <tr>, <th>, aur <td> tags use hote hain.

⚡ Code Example

<table border="1">
  <tr>
    <th>Name</th>
    <th>Role</th>
  </tr>
  <tr>
    <td>Alex</td>
    <td>Developer</td>
  </tr>
</table>
