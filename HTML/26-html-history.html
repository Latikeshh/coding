📜 History, Evolution & Standards of HTML

🟡 Intermediate

📖 Definition

HTML (HyperText Markup Language) was invented by British computer scientist Sir Tim Berners-Lee in 1989–1991 at CERN (European Organization for Nuclear Research) to allow global researchers to share hyperlinked research papers across computer networks. Today, HTML is governed and continuously updated as the WHATWG HTML Living Standard.

---

🌐 Multilingual Explanation

English

From simple text documents with 18 basic tags in 1991, HTML evolved through strict standards (HTML4, XHTML) to become the foundation of modern web applications (HTML5). Today, HTML is no longer updated through static version numbers (like HTML6); instead, it is maintained as an evolving Living Standard by WHATWG.

📜 Detailed Historical Timeline of HTML 

1989–1991 ──► Tim Berners-Lee invents WWW & publishes first "HTML Tags" document (18 original tags)

1993      ──► Mosaic browser launched; IETF publishes early HTML draft specifications


1995      ──► HTML 2.0 published as the first formal IETF standard specification


1997      ──► HTML 3.2 & HTML 4.0 published as W3C Recommendations


1999      ──► HTML 4.01 standardizes web markup for desktop browsers


2000      ──► XHTML 1.0 enforces strict XML syntax rules (unclosed tags cause browser rendering breaks)


2004      ──► WHATWG formed by Apple, Mozilla, and Opera developers to build modern web app standards


2008      ──► HTML5 First Public Working Draft published


2014      ──► HTML5 officially approved as W3C Recommendation (Semantic elements, Canvas, Video/Audio)


2019      ──► W3C and WHATWG sign agreement making WHATWG the sole authority for HTML


Present   ──► WHATWG HTML Living Standard (continuously updated single HTML specification)

🧠 W3C vs WHATWG & The "Living Standard" Model

What was the W3C vs WHATWG conflict?

  • W3C (World Wide Web Consortium): Pushed for strict XML-based web standards (XHTML 2.0) that forced pages to break if developers forgot closing tags (

    ) or quotes.

  • WHATWG (Web Hypertext Application Technology Working Group): Formed by browser engine developers (Apple, Mozilla, Opera, Google) who wanted backward-compatible, pragmatic standards for real-world web applications.

Why is there no "HTML6"?

Under the WHATWG Living Standard model:

1. HTML is no longer released in snapshot versions (like HTML 4, HTML 5).

3. Web developers and browsers constantly adopt new HTML capabilities without waiting for major version release numbers.
