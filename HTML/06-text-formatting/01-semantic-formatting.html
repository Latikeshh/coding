Semantic Text Formatting (<strong>, <em>, <mark>, <ins>, <del>)

🟢 Beginner

📖 Definition

Semantic Text Formatting uses elements like <strong>, <em>, <mark>, <ins>, and <del> to convey structural meaning, importance, and emphasis to browsers, search engine crawlers, and screen readers.

🌍 Multilingual Summary

English

Semantic tags convey meaning: <strong> for importance, <em> for emphasis, <mark> for highlighting, and <del>/<ins> for edits.

Hindi

Semantic formatting tags text ko importance aur emphasis dete hain, jaise <strong> important text ke liye aur <em> emphasized text ke liye.

⚡ Code Example

<p><strong>Important Notice:</strong> Deadline is <mark>Today at 5 PM</mark>.</p>
<p>Special Price: <del>$99</del> <ins>$49</ins></p>
