Presentational Text Formatting (<b>, <i>, <u>, <small>, <s>)

🟢 Beginner

📖 Definition

Presentational Text Formatting elements like <b>, <i>, <u>, <small>, and <s> apply visual styling without imparting extra semantic importance to speech synthesizers or search engines.

🌍 Multilingual Summary

English

Use <b> for bold text, <i> for italic voice/terms, <u> for unarticulated annotations, and <small> for fine print.

Hindi

Bina extra semantic meaning ke text ko sirf bold ya italic dikhane ke liye <b> aur <i> use hote hain.

⚡ Code Example

<p>The key terms are <b>bolded</b> and technical words are <i>italicized</i>.</p>
