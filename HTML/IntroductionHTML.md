# Introduction to HTML

## 📖 Definition

HTML means **HyperText Markup Language**. It is the language used to describe the content of a web page.

## 🤔 Why Do We Use It?

Browsers use HTML to know what to show: titles, words, pictures, links, and more. Every web page begins with HTML.

## 🧠 Simple Explanation

Think of a web page as a house. HTML is its frame and rooms. CSS makes it look nice, and JavaScript makes parts move or react.

## 📝 Syntax

```html
<h1>Welcome to my website</h1>
<p>I am learning HTML.</p>
```

Tags such as `<h1>` tell the browser what each piece of content is.
