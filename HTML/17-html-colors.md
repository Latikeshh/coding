# HTML Colors

## 📖 Definition

HTML can name colors in some attributes, while CSS is normally used to color text, backgrounds, and borders.

## 🤔 Why Do We Use It?

Colors help create a visual identity and can guide attention to important parts of a page.

## 🧠 Simple Explanation

Colors are like paint choices for a shop. Use them to support the message, not to make every part shout.

## 📝 Syntax

```html
<p style="color: darkgreen;">Fresh vegetables today</p>
```

CSS colors can use names, hex values like `#228B22`, or `rgb()` values. Keep enough contrast between text and its background.

## 💡 Practical Example

For a garden shop, dark green text on a white background is easy to read and fits the theme. Pale yellow text on white is hard to see, even if it looks attractive.

## ✅ Remember

The `style` attribute is useful for a quick experiment. As a site grows, put colour rules in a separate CSS file so they are easier to reuse.
