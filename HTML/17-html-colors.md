# HTML Colors

> 🟢 Beginner

## 📖 Definition

CSS, rather than HTML, is used to color text, backgrounds, and borders.

## 🤔 Why Do We Use It?

Colors help create a visual identity and can guide attention to important parts of a page.

## 🧠 Simple Explanation

Colors are like paint choices for a shop. Use them to support the message, not to make every part shout.

## 📝 Syntax

```html
<p style="color: darkgreen;">Fresh vegetables today</p>
```

CSS colors can use names, hex values like `#228B22`, or `rgb()` values. Keep enough contrast between text and its background.

## 💡 Practical Example

For a garden shop, dark green text on a white background is easy to read and fits the theme. Pale yellow text on white is hard to see, even if it looks attractive.

## ✅ Remember

The `style` attribute is useful for a quick experiment. As a site grows, put colour rules in a separate CSS file so they are easier to reuse.

- CSS controls most colours on a web page.
- A colour can use a name, hex code, or `rgb()`.
- Text and background colours need good contrast.

## 💻 Example

```html
<p style="color: #0b5d1e; background-color: #ffffff;">
  Fresh herbs available today.
</p>
```

## 👀 Output

The sentence appears in dark green text on a white background.

## 🔍 How It Works

`color` changes text colour. `background-color` changes the area behind the text. `#0b5d1e` is a hex colour value.

## ⚠️ Common Mistakes

- Avoid low-contrast pairs such as light yellow text on white.
- Do not use colour as the only way to explain an important message.

## 🧪 Try It Yourself

Change a heading to a dark colour that is easy to read on a white page.

## 🎯 Mini Challenge

Choose two colours for a café notice and check that the text remains readable.
