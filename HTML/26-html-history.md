# HTML History

> 🟡 Intermediate

## 📖 Definition

HTML history is the story of how HTML was created and developed as part of the early World Wide Web.

## 🤔 Why Do We Use It?

Learning a little history helps us understand why HTML exists and how it became the foundation of the web.

## 🧠 Simple Explanation

HTML was not created in one perfect moment on one exact day. It grew from early ideas about linking and sharing documents on the web. Its development happened over several years.

## Who Created HTML?

HTML was developed by Tim Berners-Lee while working at CERN in Geneva, Switzerland.

## When Was HTML Created?

HTML was developed around 1989–1990. That was the period when the first ideas for the World Wide Web were being formed and the early web technologies were being built.

It is important to distinguish between:

- the early proposal for the World Wide Web (around 1989)
- the development of HTML and web technologies (around 1990)
- wider public availability and early documentation later on

So, the language was not suddenly invented as a finished product on one exact date.

## Where Was HTML Created?

HTML was created at CERN, in Geneva, Switzerland.

## Why Was HTML Created?

Tim Berners-Lee needed a way to organize and link documents so researchers could share information more easily on the emerging World Wide Web.

The original goal was simple: let people connect documents and access information across a network.

## What Does HTML Stand For?

```text
HTML = HyperText Markup Language
```

## Important Historical Points

```text
1989 → Proposal for the World Wide Web
1990 → HTML and early web technologies developed
1991 → Early public description/availability of the Web
1993 → HTML discussed and documented as an emerging standard
1995 → HTML 2.0
1997 → HTML 3.2
1997 → HTML 4.0
1999 → HTML 4.01
2014 → HTML5 became a W3C Recommendation
```

These dates are milestone markers. Some are more precise than others, and some represent early standardization or public availability rather than the exact moment of first creation.

## Simple Beginner Analogy

A simple beginner model is:

```text
HTML = structure
CSS = design
JavaScript = behavior
```

This is a simplified explanation for beginners. In real web development, HTML, CSS, and JavaScript work together, but each one has a different job.

## ✅ Remember

- HTML was developed around 1989–1990.
- Tim Berners-Lee created it at CERN in Geneva.
- HTML was designed to help people link and share information.
- The web and HTML evolved over time, not all at once.
