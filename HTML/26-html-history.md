# History & Standards of HTML

> 🟡 Intermediate

## 📖 Definition

**HTML** was invented by British computer scientist **Sir Tim Berners-Lee** in **1989–1990** at CERN (European Organization for Nuclear Research) to enable scientists to share documents across computer networks. Today, HTML is maintained as a **Living Standard** by the **WHATWG** (Web Hypertext Application Technology Working Group) and **W3C** (World Wide Web Consortium).

## 📜 Historical Timeline of HTML

```text
1989–1990 ──► Tim Berners-Lee invents World Wide Web and original HTML at CERN
1993      ──► HTML 1.0 specification published
1995      ──► HTML 2.0 (IETF standard)
1997      ──► HTML 3.2 & HTML 4.0 (W3C Recommendations)
1999      ──► HTML 4.01 standardizes web markup for desktop browsers
2000s     ──► XHTML attempt (strict XML syntax enforcement)
2004      ──► WHATWG formed by browser vendors to develop modern web standards
2014      ──► HTML5 official W3C Recommendation released
Present   ──► WHATWG HTML Living Standard (continuously updated specification)
```

## 🧠 What is the "HTML Living Standard"?

Unlike older versions where HTML had rigid version numbers (like HTML 2.0 or HTML 4.01), HTML is now treated as an **evolving Living Standard**:
- New tags, attributes, and browser capabilities are continually added based on real-world browser implementation and web developer needs.
- Web browsers automatically update to support new features without waiting for major version renames.
