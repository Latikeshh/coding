# History & Standards of HTML

> 🟡 Intermediate

## 📖 Definition

**HTML** was invented by British computer scientist **Sir Tim Berners-Lee** in **1989–1991** at CERN (European Organization for Nuclear Research) to enable scientists to share documents across computer networks. Today, HTML is maintained as a **Living Standard** by **WHATWG** (Web Hypertext Application Technology Working Group) in collaboration with **W3C** (World Wide Web Consortium).

## 📜 Historical Timeline of HTML

```text
1989–1991 ──► Tim Berners-Lee invents World Wide Web and publishes first "HTML Tags" document at CERN
1993      ──► Early IETF (Internet Engineering Task Force) HTML draft proposals
1995      ──► HTML 2.0 published as the first formal IETF standard specification
1997      ──► HTML 3.2 & HTML 4.0 published as W3C Recommendations
1999      ──► HTML 4.01 standardizes web markup for desktop browsers
2000s     ──► XHTML 1.0 enforces strict XML syntax rules
2004      ──► WHATWG formed by browser engine developers to create modern web application standards
2014      ──► HTML5 official W3C Recommendation published
Present   ──► WHATWG HTML Living Standard (continuously evolving single HTML specification)
```

## 🧠 What is the "WHATWG HTML Living Standard"?

Unlike earlier decades where HTML had rigid, static version numbers (like HTML 2.0 or HTML 4.01), HTML is now maintained as a **Living Standard**:
- New tags, attributes, and browser capabilities are continually added based on real-world browser implementation and web developer needs.
- Web browsers automatically update to support new features without waiting for major version renames (e.g. there is no static "HTML6" release planned).
