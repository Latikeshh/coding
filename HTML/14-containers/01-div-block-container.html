01. The Block Container `<div>` in HTML5

🟢 Beginner Level | Generic Block-level Wrapper & Flexbox/Grid Parent

📖 What is `<div>`?

The <div> (division) element is a generic block-level container with no intrinsic semantic meaning. By default, it starts on a new line and occupies 100% of available parent width.

📝 Code Example

<div class="card-wrapper">
  <h2>Product Title</h2>
  <p>Product description paragraph.</p>
</div>
