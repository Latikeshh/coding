02. The Inline Container `<span>` in HTML5

🟢 Beginner Level | Generic Inline Wrapper & Text Hooks

📖 What is `<span>`?

The <span> element is a generic inline container used to group text or inline elements for styling without causing line breaks.

📝 Code Example

<p>Status: <span class="badge badge-success">Active</span></p>
