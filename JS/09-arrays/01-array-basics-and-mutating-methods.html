Array Basics & Mutating Methods in JavaScript

🟢 Beginner Level | JavaScript Core Syntax

📖 Definition

Arrays are ordered list collections. Mutating Methods modify the original array in-place (e.g. push, pop, shift, unshift, splice, reverse, sort).

⚡ Code Example

const colors = ["red", "green"];
colors.push("blue"); // ["red", "green", "blue"]
colors.splice(1, 1, "yellow"); // ["red", "yellow", "blue"]
