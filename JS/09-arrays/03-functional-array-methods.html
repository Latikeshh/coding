Functional Array Transformations in JavaScript

🟢 Beginner Level | JavaScript Core Syntax

📖 Definition

Functional array methods (map, filter, reduce, flat, flatMap, toSorted) transform data without side-effects.

⚡ Code Example

const prices = [10, 20, 30];
const discounted = prices.map(p => p * 0.9); // [9, 18, 27]
const total = prices.reduce((sum, p) => sum + p, 0); // 60
