Function Declarations & Expressions in JavaScript

🟢 Beginner Level | JavaScript Core Syntax

📖 Definition

A Function Declaration uses the function keyword to define a named, hoisted block of code. A Function Expression assigns an anonymous or named function to a variable.

🤔 Purpose

Enables code reusability, modular encapsulation, and organized execution flow across application components.

🌐 Multilingual Explanations

English

Function declarations are hoisted to the top of their scope during parsing, allowing calls before definition. Expressions are evaluated at execution time.

📝 Syntax & Parameters

// Function Declaration (Hoisted)
function greet(name) {
    return "Hello, " + name;
}

// Function Expression (Not Hoisted)
const sayHi = function(name) {
    return "Hi, " + name;
};

⚡ Execution Flow

  1. JavaScript parser hoists function declarations into memory during creation phase.
  2. Function expressions remain uninitialized until execution reaches their assignment line.
  3. Invoking the function creates a new execution context on the Call Stack.

💡 Progressive Examples

Example 1: Function Declaration vs Expression

console.log(calcSquare(4)); // Works! (Hoisted)

function calcSquare(n) {
    return n * n;
}

const calcCube = function(n) {
    return n * n * n;
};
console.log(calcCube(3)); // 27

🖥️ Expected Output

16
27

🔍 Line-by-Line Code Breakdown

  • console.log(calcSquare(4)): Calls hoisted function before its literal line position.
  • const calcCube = function(n): Binds anonymous function expression to constant variable.

⚠️ Variations & Edge Cases

Invoking a function expression before its definition line throws a ReferenceError: Cannot access before initialization.

❌ Common Beginner Mistakes

Forgetting Return Statement: Functions without an explicit return statement return undefined by default.

🛠️ Real-World Practical Usage

Encapsulating utility functions in web applications.

🎯 Tiered Practice Exercises

  2. Intermediate: Convert a function declaration into a function expression.
  3. Advanced: Create an Immediately Invoked Function Expression (IIFE) to create a private scope.
