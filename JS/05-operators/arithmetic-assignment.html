Arithmetic & Assignment Operators in JavaScript

🟢 Beginner Level | JavaScript Foundations

📖 Definition

Arithmetic Operators (+, -, *, /, %, **) perform mathematical computations on numeric operands. Assignment Operators (=, +=, -=, *=) assign computed values to variables.

🤔 Purpose

Enables numerical calculations, counter updates, and state modification in frontend and backend JS scripts.

🌐 Multilingual Explanations

English

JavaScript supports standard arithmetic including the exponentiation operator ** (e.g. 2 ** 3 = 8) and compound assignment shorthands.

📝 Syntax & Parameters

let score = 10;
score += 5;       // score = 15
let power = 2 ** 4; // power = 16
let remainder = 17 % 5; // remainder = 2

⚡ Execution Flow

  1. Evaluate right-hand expression according to operator precedence.
  2. Perform implicit type coercion if operands differ (e.g. number + string).
  3. Assign computed result to left-hand variable target.

💡 Progressive Examples

Example 1: Modulo & Exponentiation

let num = 25;
let isEven = (num % 2 === 0);
let squared = 5 ** 2;

console.log("Is 25 Even?:", isEven);
console.log("5 Squared:", squared);

🖥️ Expected Output

Is 25 Even?: false
5 Squared: 25

🔍 Line-by-Line Code Breakdown

  • num % 2: Returns remainder of division by 2.
  • 5 ** 2: Computes $5^2 = 25$.

⚠️ Variations & Edge Cases

Using + with a string operand performs string concatenation rather than addition (e.g. 5 + "5" = "55")!

❌ Common Beginner Mistakes

String Concatenation Confusion: Adding a number to a string (10 + "20") yields `"1020"` instead of `30`.

🛠️ Real-World Practical Usage

ShoppingCart price total calculations and pagination offsets.

🎯 Tiered Practice Exercises

  2. Intermediate: Use `**` to calculate $2^{10}$.
  3. Advanced: Write a compound assignment loop updating a total price accumulator.
