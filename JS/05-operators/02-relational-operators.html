Relational & Strict Equality in JavaScript

🟢 Beginner

📖 Definition

JavaScript provides loose equality (==) and strict equality (===) which checks both value and data type.

⚡ Code Example

console.log(5 == "5");  // true (type coercion)
console.log(5 === "5"); // false (strict type check)
