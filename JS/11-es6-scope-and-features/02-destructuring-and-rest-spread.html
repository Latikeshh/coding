Destructuring & Rest/Spread Operators in JavaScript

🟢 Beginner Level | JavaScript Core Syntax

📖 Definition

Destructuring unpacks values from arrays or objects into distinct variables. The Spread Operator (...) expands iterables, while Rest Parameters gather arguments.

⚡ Code Example

const { name, role = "User" } = { name: "Alice" };
const mergedArr = [...[1, 2], ...[3, 4]]; // [1, 2, 3, 4]
