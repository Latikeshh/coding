Template Literals & Optional Chaining in JavaScript

🟢 Beginner Level | JavaScript Core Syntax

📖 Definition

Template Literals enable string interpolation (`${expr}`). Optional Chaining (?.) safely reads nested properties without throwing error. Nullish Coalescing (??) returns fallback for null/undefined.

⚡ Code Example

const user = { profile: { email: "alex@domain.com" } };
console.log(user?.profile?.email); // "alex@domain.com"
console.log(user?.settings?.theme ?? "light"); // "light"
