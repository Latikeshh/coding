Primitive Data Types in JavaScript

🟢 Beginner Level | JavaScript Core Syntax

📖 Definition

Primitive Data Types represent immutable single values stored directly on the V8 Engine Call Stack. JavaScript features 7 primitive types: String, Number, Boolean, Null, Undefined, Symbol, and BigInt.

🌐 Multilingual Summary

English

Primitives are immutable values stored directly by value in Stack memory. Assigning a primitive creates a new value copy.

Hindi

Primitive values fixed hote hain aur Call Stack memory mein store hote hain. Copy karne par new value banti hai.

⚡ Code Example

let a = 42;
let b = a; // Copy by value
b = 100;
console.log(a, b); // 42, 100 (a remains unchanged)
