Reference Data Types & Heap Memory in JavaScript

🟢 Beginner Level | JavaScript Core Syntax

📖 Definition

Reference Data Types (Objects, Arrays, Functions) are mutable data structures stored in the V8 Memory Heap. Variables store a memory reference pointer pointing to the Heap object.

🌐 Multilingual Summary

English

Reference types store memory pointers. Copying an object variable copies its memory address, sharing object mutations.

Hindi

Objects aur Arrays Memory Heap mein store hote hain. Copy karne par memory address copy hota hai.

⚡ Code Example

const user1 = { name: "Alex" };
const user2 = user1; // Copy by reference
user2.name = "Bob";
console.log(user1.name); // "Bob" (both point to same memory address!)
