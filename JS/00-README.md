# ⚡ Learn JavaScript

JavaScript is the programming language of the Web. It brings web pages to life by making them interactive, handling user events, updating content dynamically, and building full applications.

> 🟢 **Beginner-friendly:** start with the browser console, learn fundamental programming concepts, and build interactive web applications step by step.

## 📖 What You Will Learn

- How JavaScript runs in browsers and Node.js
- Variables, data types, and fundamental operators
- Decision making with conditionals and repeating tasks with loops
- Writing reusable code with functions
- Managing structured data using arrays and objects
- Selecting and updating HTML elements with DOM manipulation
- Building interactive mini-projects like counters and todo apps

## 🧪 Practice Routine

For each lesson:
1. Read the explanation and understand the code example.
2. Open your browser Developer Console (`F12`) or VS Code.
3. Type out the examples manually—avoid copy-pasting!
4. Modify variables or logic to test your understanding.
5. Solve the "Try It Yourself" and "Mini Challenge" exercises.

## ✅ Progress Checklist

- [ ] I can write and execute JavaScript in the browser console.
- [ ] I understand `let` vs `const` and when to use them.
- [ ] I can write `if/else` logic and loops.
- [ ] I can write functions with parameters and return values.
- [ ] I can store and manipulate data in arrays and objects.
- [ ] I can change text and styles on a web page using DOM manipulation.
- [ ] I built at least one interactive mini-project.
