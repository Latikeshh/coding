The if Statement in JavaScript

🟢 Beginner Level | Core Control Flow

📖 Definition

The if statement is the primary conditional construct in JavaScript. It executes a specified block of code only when a test condition evaluates to a truthy value.

🤔 Purpose

Real-world applications must react dynamically based on user input, system state, or server responses—for example, verifying if a user is logged in before rendering a dashboard.

🌐 Multilingual Explanations

English

The if statement checks a boolean condition inside parentheses (condition). If truthy, the code block inside { ... } runs. If falsy, JavaScript skips the block entirely.

Hindi

if statement pehle parentheses ke andar ki condition ko verify karta hai. Agar condition true (ya truthy) hoti hai, tabhi { } ke andar ka code execute hota hai, varna ignore ho jata hai.

Marathi

if statement madhye dileli condition true aslyasach { } madhla code run hoto. Condition false aslyas tya code block la skip kele jaate.

Hinglish

Simple terms mein, if (condition) tabhi run hota hai jab condition true ho. if (isLoggedIn) { showDashboard(); } execution line-by-line evaluate hota hai.

📝 Syntax & Parameters

if (condition) {
  // Code executed if condition is truthy
}
  • condition: Any expression evaluating to a Boolean or truthy/falsy value.
  • { ... }: The block containing statements to execute upon a truthy condition.

⚡ Execution Flow

  1. JavaScript evaluates the expression inside (condition).
  2. The runtime performs implicit Boolean coercion if the condition is not already a Boolean.
  3. If true (truthy), control enters the code block { ... }.
  4. If false (falsy), control jumps past the closing brace } without executing any inner statements.

💡 Progressive Examples

Example 1: Basic Age Check

let age = 20;

if (age >= 18) {
  console.log("Access granted. User is an adult.");
}

Example 2: Truthy Check with Objects

let userProfile = { name: "Latikesh", role: "Admin" };

if (userProfile) {
  console.log("User profile loaded: " + userProfile.name);
}

Example 3: Short-Circuiting with Compound Logic

let isAuthenticated = true;
let userRole = "ADMIN";

if (isAuthenticated && userRole === "ADMIN") {
  console.log("Welcome Super Admin! Redirecting to control panel...");
}

🖥️ Expected Output

Access granted. User is an adult.
User profile loaded: Latikesh
Welcome Super Admin! Redirecting to control panel...

🔍 Line-by-Line Code Breakdown

  • let age = 20;: Declares variable age and initializes it to numeric value 20.
  • if (age >= 18): Evaluates comparison 20 >= 18, which yields Boolean true.
  • console.log(...): Prints approval message to the developer console.

⚠️ Variations & Edge Cases

JavaScript has 6 falsy values: false, 0, "", null, undefined, and NaN. Every other value (including "0", [], and {}) is truthy!

❌ Common Beginner Mistakes

Assignment instead of Comparison: Writing if (x = 5) assigns 5 to x (which is truthy!) instead of testing equality if (x === 5).

🛠️ Real-World Practical Usage

Feature flagging in production web apps:

if (featureFlags.enableDarkMode) {
  document.body.classList.add("dark-theme");
}

🎯 Tiered Practice Exercises

  1. Beginner: Write an if statement that logs "Passed" if score is greater than or equal to 50.
  2. Intermediate: Write an if statement checking if a string is non-empty before printing its upper-case version.
  3. Advanced: Use an if statement with optional chaining (`user?.settings?.notifications`) to trigger alert sounds safely.

🚀 Mini Challenge

Create a script that checks if a shopping cart array has items (using cart.length), and if so, calculates the total price and logs "Ready for checkout".
