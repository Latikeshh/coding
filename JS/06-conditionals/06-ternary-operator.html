Ternary Operator in JS in JavaScript

🟢 Beginner

📖 Definition

The Ternary Operator (cond ? a : b) assigns inline values in JS.

⚡ Code Example

let age = 20;
let status = (age >= 18) ? "Adult" : "Minor";
console.log(status);
