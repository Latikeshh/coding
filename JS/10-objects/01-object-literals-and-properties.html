Object Literals & Static Methods in JavaScript

🟢 Beginner Level | JavaScript Core Syntax

📖 Definition

Objects store key-value properties. Static methods like Object.keys(), Object.values(), Object.entries(), Object.freeze(), and Object.assign() provide tools for manipulating objects.

⚡ Code Example

const user = { id: 101, name: "Alex" };
console.log(Object.keys(user)); // ["id", "name"]
Object.freeze(user); // Prevents property modifications
