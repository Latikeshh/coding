Date & RegExp Pattern Matching in JavaScript

🟢 Beginner Level | JavaScript Core Syntax

📖 Definition

The Date object parses and formats date/time stamps. RegExp handles regular expression pattern matching and string validation.

⚡ Code Example

const now = new Date();
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
console.log(emailRegex.test("user@domain.com")); // true
