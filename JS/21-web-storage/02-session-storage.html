Temporary Storage with sessionStorage in JavaScript

🟢 Beginner Level | JavaScript Core Syntax

📖 Definition

sessionStorage maintains a separate storage area for each given origin that is available for the duration of the page session (until tab closure).

⚡ Code Example

sessionStorage.setItem("step", "2");
console.log(sessionStorage.getItem("step")); // "2"
