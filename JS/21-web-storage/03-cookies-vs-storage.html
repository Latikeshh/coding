Cookies vs Web Storage & Security in JavaScript

🟢 Beginner Level | JavaScript Core Syntax

📖 Definition

HTTP Cookies store small data sent with every HTTP request. Combining HttpOnly and SameSite flags secures cookies against XSS and CSRF attacks.

⚡ Code Example

document.cookie = "user_pref=dark; SameSite=Lax; Secure";
