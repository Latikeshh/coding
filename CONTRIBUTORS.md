## 🤝 How to Get Featured in the Hall of Fame

Want to see your name and GitHub avatar featured on this page?

1. Read our **[Step-by-Step Contribution Guide (CONTRIBUTING.html)]({{ '/CONTRIBUTING.html' | relative_url }})**.
2. Pick an open issue or suggest a new topic/example.
3. Submit a Pull Request (PR) on GitHub.
4. Once your PR is reviewed and merged, your GitHub avatar will automatically appear in the **Dynamic Contributor Grid** above!
