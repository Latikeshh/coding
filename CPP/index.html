🚀 ISO C++17 / C++20 Master Curriculum

C++ is a high-performance, object-oriented, systems-level programming language used in game engines (Unreal Engine), high-frequency trading systems, operating system kernels, compilers, database engines, embedded firmware, and robotics.

🟢 Curriculum Baseline: ISO C++17 standard baseline with dedicated ISO C++20 modules (Concepts, Ranges, Modules, Coroutines, Formatted I/O). Every code example is verified with g++ -Wall -Wextra -Wpedantic.

✅ Learning Checklist

  • I can compile modern C++17/20 code cleanly with compiler warning flags (-Wall -Wextra -Wpedantic).
  • I understand memory lifecycle, stack vs heap allocation, dynamic lifetime, and RAII.
  • I can use distinct smart pointers (std::unique_ptr, std::shared_ptr, std::weak_ptr) appropriately without memory leaks.
  • I master OOP principles including dynamic polymorphism, virtual destructors, and pure virtual interfaces.
  • I can leverage the C++ Standard Template Library (containers, iterators, generic algorithms, and lambdas).
  • I understand move semantics, lvalues/rvalues, std::move casting, and rvalue references (&&).
