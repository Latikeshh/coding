Constants & Qualifiers (const & constexpr)

🟢 Beginner

📖 Definition

In C++, const promises that a value will not change after initialization. constexpr enforces compile-time evaluation of constant expressions.

💡 Code Example

#include <iostream>

constexpr double square(double x) {
    return x * x;
}

int main() {
    const double PI = 3.14159;
    constexpr double AREA_UNIT = square(5.0); // Evaluated at compile time

    std::cout << "PI: " << PI << "\nUnit Area: " << AREA_UNIT << "\n";
    return 0;
}

👀 Output

PI: 3.14159
Unit Area: 25
