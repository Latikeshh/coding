C++ Standard Template Library (STL) Containers

🟢 Intermediate Level | Sequence, Associative & Unordered Containers

📖 Standard Containers

The C++ STL provides templated container classes such as std::vector, std::map, std::set, and std::unordered_map.

📝 Code Example

#include <iostream>
#include <vector>
#include <unordered_map>

int main() {
    std::vector<int> nums = {10, 20, 30};
    nums.push_back(40);

    std::unordered_map<std::string, int> ages;
    ages["Alice"] = 25;
    ages["Bob"] = 30;

    std::cout << "Alice's age: " << ages["Alice"] << std::endl;
    return 0;
}
