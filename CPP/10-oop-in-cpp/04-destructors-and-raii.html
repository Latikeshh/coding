04. Destructors & RAII in C++

🟡 Intermediate Level | Resource Acquisition Is Initialization & Scope Cleanup

📖 What is a Destructor?

A Destructor (~ClassName()) is automatically executed when an object goes out of scope or is deleted via raw pointers. RAII leverages destructors to prevent resource leaks.

📝 Code Example

#include <iostream>
#include <fstream>

class FileHandler {
private:
    std::ofstream file;

public:
    FileHandler(const std::string& filename) {
        file.open(filename);
        std::cout << "File opened" << std::endl;
    }

    ~FileHandler() {
        if (file.is_open()) {
            file.close();
            std::cout << "File closed automatically" << std::endl;
        }
    }
};

int main() {
    {
        FileHandler fh("log.txt");
    } // FileHandler destructor closes file here
    return 0;
}
