03. Inheritance Basics in C++

🟢 Intermediate Level | Base Classes, Derived Classes & Access Specifiers

📖 What is Inheritance?

Inheritance allows a derived class to acquire properties and behaviors from a base class, establishing an IS-A relationship hierarchy.

📝 Code Example

#include <iostream>

class Vehicle {
protected:
    std::string brand;

public:
    Vehicle(std::string b) : brand(b) {}
    void startEngine() const {
        std::cout << brand << " engine started." << std::endl;
    }
};

class Car : public Vehicle {
public:
    Car(std::string b) : Vehicle(b) {}
};

int main() {
    Car myCar("Toyota");
    myCar.startEngine();
    return 0;
}
