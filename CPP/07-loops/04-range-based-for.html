Range-based for Loop (C++11)

🟢 Beginner

📖 Definition

Introduced in C++11, the range-based for loop (for (const auto& element : range)) cleanly iterates over elements of containers like arrays, std::vector, and initializer lists without managing raw index subscripts.

💡 Code Example

#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers{10, 20, 30, 40, 50};

    for (const auto& num : numbers) {
        std::cout << "Number: " << num << "\n";
    }
    return 0;
}
