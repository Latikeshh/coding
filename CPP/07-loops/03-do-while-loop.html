The do-while Loop in C++

🟢 Beginner Level | Post-tested Exit-controlled Loop

📖 Definition

The do-while loop in C++ executes the loop block first before evaluating the condition at the end. It guarantees at least one execution pass.

📝 Code Example

#include <iostream>

int main() {
    int input;
    do {
        std::cout << "Enter a positive number: ";
        std::cin >> input;
    } while (input <= 0);

    std::cout << "Valid input: " << input << std::endl;
    return 0;
}
