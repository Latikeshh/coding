Range-Based for Loop in C++11

🟢 Intermediate Level | Modern C++ Container Traversal

📖 Definition

Introduced in **C++11**, the Range-Based for loop executes a code block over every element in a range or container (such as std::vector, std::array, or C-style array) without requiring explicit iterator management.

🤔 Purpose

Eliminates complex iterator syntax (for (auto it = vec.begin(); it != vec.end(); ++it)) and avoids out-of-bounds indexing bugs.

🌐 Multilingual Explanations

English

The syntax for (const auto& item : container) binds a constant reference to each element in sequence, avoiding expensive object copies.

Hindi

C++11 mein for (const auto& item : vector) se direct container elements iterate kar sakte hain. Copy-free performance ke liye reference & use karein.

Marathi

Range-based for loop mule vector sahaj iterate hoto.

Hinglish

Modern iteration: for (auto& elem : container) { elem *= 2; } mutating elements ke liye follow karein.

📝 Syntax & Parameters

// Read-only (no copy)
for (const auto& element : container) {
    // Read element
}

// Mutating (in-place modification)
for (auto& element : container) {
    // Modify element
}

⚡ Execution Flow

  1. C++ calls std::begin(container) and std::end(container) internally.
  2. For each element between begin and end iterators, reference binding occurs.
  3. Executes loop body statements until end iterator is reached.

💡 Progressive Examples

Example 1: Mutating Vector Elements In-Place

#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers = {1, 2, 3, 4};

    // Multiply every element by 10 using reference &
    for (auto& n : numbers) {
        n *= 10;
    }

    for (const auto n : numbers) {
        std::cout << n << " ";
    }
    std::cout << "\n";
    return 0;
}

🖥️ Expected Output

10 20 30 40

🔍 Line-by-Line Code Breakdown

  • for (auto& n : numbers): Binds mutable reference `n` to each vector element.
  • n *= 10;: Modifies original vector element in-place.

⚠️ Variations & Edge Cases

In C++20, init-statements are supported: for (auto vec = getVector(); const auto& elem : vec) { ... }.

❌ Common Beginner Mistakes

Forgetting Reference `&`: Using for (auto item : vec) creates a copy of every element per iteration, degrading performance for heavy objects.
