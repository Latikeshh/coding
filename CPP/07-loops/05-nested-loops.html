Nested Loops & Grid Processing

🟢 Beginner

📖 Definition

A nested loop is a loop placed inside the body of another loop. Outer loop iterations trigger complete runs of inner loops, commonly used for multi-dimensional matrices and grids.

💡 Code Example

#include <iostream>

int main() {
    for (int row = 1; row <= 3; ++row) {
        for (int col = 1; col <= 3; ++col) {
            std::cout << "(" << row << "," << col << ") ";
        }
        std::cout << "\n";
    }
    return 0;
}
