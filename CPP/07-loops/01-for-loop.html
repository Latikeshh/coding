The C++ for Loop

🟢 Beginner

📖 Definition

A for loop provides an entry-controlled loop structure ideal for counter-driven iteration. It consists of three parts: initialization, condition, and increment/decrement expression.

💡 Code Example

#include <iostream>

int main() {
    for (int i = 1; i <= 5; ++i) {
        std::cout << "Iteration count: " << i << "\n";
    }
    return 0;
}

👀 Output

Iteration count: 1
Iteration count: 2
Iteration count: 3
Iteration count: 4
Iteration count: 5
