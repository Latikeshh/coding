while & do-while Loops in C++

🟢 Beginner Level | Pre-tested & Post-tested C++ Loops

📖 Definition

The while loop tests a scalar condition prior to running the body. The do-while loop executes the body first, testing the condition at the end (guaranteeing at least one pass).

🤔 Purpose

Used in game loops, event polling, and stream input processing where iteration counts are dynamic.

🌐 Multilingual Explanations

English

In C++, while (condition) checks the scalar expression first. Non-zero evaluates as true; 0 evaluates as false.

📝 Syntax & Parameters

// Pre-tested while loop
while (condition) {
    // Body
}

// Post-tested do-while loop
do {
    // Body
} while (condition);

⚡ Execution Flow

  1. while: Test condition $\rightarrow$ if non-zero, run body $\rightarrow$ repeat.
  2. do-while: Run body $\rightarrow$ Test condition $\rightarrow$ if non-zero, repeat.

💡 Progressive Examples

Example 1: Stream Input Draining

#include <iostream>

int main() {
    int count = 3;

    while (count > 0) {
        std::cout << "Countdown step: " << count << "\n";
        count--;
    }
    return 0;
}

🖥️ Expected Output

Countdown step: 3
Countdown step: 2
Countdown step: 1

🔍 Line-by-Line Code Breakdown

  • while (count > 0): Evaluates if integer count is strictly positive.
  • count--: Decrements loop variable.

⚠️ Variations & Edge Cases

Always place a trailing semicolon after while (condition); in a `do-while` loop construct.

❌ Common Beginner Mistakes

Infinite Loop: Omitting state modifications inside the loop body causes an infinite loop hanging the process.

🛠️ Real-World Practical Usage

Game engine main loops and event dispatchers.
