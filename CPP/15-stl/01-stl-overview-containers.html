C++ Standard Template Library (STL) Architecture

🟡 Intermediate

📖 Definition

The C++ Standard Template Library (STL) is a powerful collection of generic data structures, iterators, and algorithms. Its three pillars—Containers (data storage), Iterators (traversal pointers), and Algorithms (processing operations)—are decoupled via generic templates.

💡 Code Example

#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> data{40, 10, 30, 20};
    std::sort(data.begin(), data.end()); // Generic STL algorithm on container iterators

    for (int x : data) std::cout << x << " ";
    std::cout << "\n";
    return 0;
}
