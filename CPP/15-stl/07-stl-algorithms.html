Generic STL Algorithms (<algorithm> & <numeric>)

🟡 Intermediate

📖 Definition

The <algorithm> and <numeric> headers supply optimized generic algorithms: std::sort, std::find, std::binary_search, std::transform, std::accumulate, and std::count_if operating seamlessly across container iterator ranges.

💡 Code Example

#include <iostream>
#include <vector>
#include <algorithm>
#include <numeric>

int main() {
    std::vector<int> v{5, 10, 15, 20};

    int sum = std::accumulate(v.begin(), v.end(), 0);
    std::cout << "Vector Sum: " << sum << "\n";
    return 0;
}
