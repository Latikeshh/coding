Unordered Hash Containers: std::unordered_map & set

🟡 Intermediate

📖 Definition

Introduced in C++11, std::unordered_map<K, V> and std::unordered_set<T> store unsorted elements in hash tables, delivering average-case constant time O(1) lookup performance.

💡 Code Example

#include <iostream>
#include <unordered_map>

int main() {
    std::unordered_map<int, std::string> users;
    users[101] = "Alice";
    users[102] = "Bob";

    std::cout << "User 101: " << users[101] << "\n";
    return 0;
}
