Container Adapters: stack, queue & priority_queue

🟡 Intermediate

📖 Definition

Container adapters wrap underlying sequence containers to restrict access interfaces:

  • std::stack: Last-In First-Out (LIFO) stack interface (push, pop, top).
  • std::queue: First-In First-Out (FIFO) queue interface (push, pop, front, back).
  • std::priority_queue: Max-heap priority queue (top returns highest priority element).

💡 Code Example

#include <iostream>
#include <stack>

int main() {
    std::stack<int> s;
    s.push(10);
    s.push(20);

    while (!s.empty()) {
        std::cout << s.top() << " "; // LIFO access
        s.pop();
    }
    std::cout << "\n";
    return 0;
}
