Sequence Containers: vector, deque & list

🟡 Intermediate

📖 Definition

Sequence containers maintain sequential order:

  • std::vector: Contiguous dynamic array (O(1) random access, fast push_back).
  • std::deque: Double-ended queue (O(1) push_front and push_back).
  • std::list: Doubly linked list (O(1) middle insertions/deletions, O(N) traversal).

💡 Code Example

#include <iostream>
#include <deque>

int main() {
    std::deque<int> dq;
    dq.push_back(20);
    dq.push_front(10); // O(1) double-ended insertion

    std::cout << "Front: " << dq.front() << ", Back: " << dq.back() << "\n";
    return 0;
}
