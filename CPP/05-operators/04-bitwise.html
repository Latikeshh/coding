Bitwise Operators & Bit Manipulation

🟡 Intermediate

📖 Definition

Bitwise operators manipulate individual binary bits: bitwise AND (&), OR (|), XOR (^), NOT (~), left shift (<<), and right shift (>>).

💡 Code Example

#include <iostream>

int main() {
    unsigned int a = 5;  // 0101 in binary
    unsigned int b = 3;  // 0011 in binary

    std::cout << "a & b = " << (a & b) << "\n"; // 0001 = 1
    std::cout << "a | b = " << (a | b) << "\n"; // 0111 = 7
    std::cout << "a << 1 = " << (a << 1) << "\n"; // 1010 = 10
    return 0;
}
