Operator Precedence & Order of Evaluation

🟡 Intermediate

📖 Definition

Operator precedence determines the grouping order of operators in complex expressions. When operators share equal precedence, associativity (Left-to-Right or Right-to-Left) determines evaluation order. Use parentheses () to make grouping explicit.

💡 Code Example

#include <iostream>

int main() {
    int res1 = 10 + 2 * 5;   // 20 (* has higher precedence than +)
    int res2 = (10 + 2) * 5; // 60 (parentheses override precedence)

    std::cout << "res1: " << res1 << ", res2: " << res2 << "\n";
    return 0;
}
