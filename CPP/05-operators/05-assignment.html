Assignment & Compound Assignment Operators

🟢 Beginner

📖 Definition

Simple assignment (=) stores a right-hand value into a left-hand variable. Compound assignment operators (+=, -=, *=, /=, %=) combine arithmetic with assignment.

💡 Code Example

#include <iostream>

int main() {
    int score = 50;
    score += 25; // Equivalent to score = score + 25
    std::cout << "Updated Score: " << score << "\n";
    return 0;
}
