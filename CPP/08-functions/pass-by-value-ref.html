Pass-by-Value vs Pass-by-Reference in C++

🟢 Intermediate Level | C++ Memory Efficiency

📖 Definition

Pass-by-Value passes a copy of the argument to the function. Pass-by-Reference (Type& arg) passes an alias to the original variable, allowing in-place modifications and zero-copy performance.

🤔 Purpose

Eliminates expensive object copy operations when passing heavy containers (like std::vector or std::string) to functions.

📝 Syntax & Parameters

// Pass-by-value (Copies data)
void incrementVal(int x);

// Pass-by-reference (Modifies original)
void incrementRef(int& x);

// Pass-by-const-reference (Zero-copy read-only)
void display(const std::string& str);

⚡ Execution Flow

  1. Pass-by-value invokes copy constructor or bitwise memory copy onto stack.
  2. Pass-by-reference binds reference alias directly to caller's variable memory address.
  3. Function executes without copying underlying data.

💡 Progressive Examples

Example 1: Swapping Variables via Reference

#include <iostream>

void swap(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 10, y = 20;
    swap(x, y);

    std::cout << "x: " << x << ", y: " << y << "\n";
    return 0;
}

🖥️ Expected Output

x: 20, y: 10

🔍 Line-by-Line Code Breakdown

  • void swap(int& a, int& b): Accepts references `a` and `b` bound to `x` and `y`.
  • a = b;: Modifies actual memory location of caller's variable `x`.

⚠️ Variations & Edge Cases

Attempting to pass rvalues (literals like `swap(5, 10)`) to non-const reference parameters causes a compilation error.

❌ Common Beginner Mistakes

Passing Vectors by Value: Writing void parse(std::vector<int> vec) copies every element in the vector upon invocation.

🛠️ Real-World Practical Usage

High-performance game engine math and renderer pipeline calls.
