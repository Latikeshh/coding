Function Declarations & Definitions

🟢 Beginner

📖 Definition

A function in C++ is a named block of code that executes a specific task. Prototypes declare a function's signature before its usage, while definitions supply the implementation body.

💡 Code Example

#include <iostream>

// Function prototype
int addNumbers(int a, int b);

int main() {
    int sum = addNumbers(15, 25);
    std::cout << "Sum: " << sum << "\n";
    return 0;
}

// Function definition
int addNumbers(int a, int b) {
    return a + b;
}
