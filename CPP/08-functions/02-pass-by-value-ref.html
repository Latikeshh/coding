Pass-by-Value vs Pass-by-Reference in C++

🟢 Beginner

📖 Definition

Pass-by-value creates a local copy of arguments. Pass-by-reference (&) passes an alias to the original object, avoiding copy overhead and allowing direct modification. const T& provides zero-copy read-only access.

💡 Code Example

#include <iostream>

void modifyByRef(int& val) {
    val *= 2;
}

int main() {
    int number = 50;
    modifyByRef(number);
    std::cout << "Modified value: " << number << "\n";
    return 0;
}
