Constructors & Member Initializer Lists

🟡 Intermediate

📖 Definition

A constructor initializes an object upon creation. Member initializer lists (Class() : member1(val1) {}) initialize members directly prior to the constructor body execution, which is mandatory for const and reference members.

💡 Code Example

#include <iostream>

class Point {
private:
    int x;
    int y;
public:
    // Member initializer list
    Point(int xVal, int yVal) : x(xVal), y(yVal) {}

    void print() const { std::cout << "(" << x << ", " << y << ")\n"; }
};

int main() {
    Point p(10, 20);
    p.print();
    return 0;
}
