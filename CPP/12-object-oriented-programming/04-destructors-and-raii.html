Destructors & RAII Lifecycle

🟡 Intermediate

📖 Definition

A destructor (~Class()) automatically executes when an object leaves scope. Under RAII, resource cleanup (closing files, releasing heap memory) is bound to object destruction.

💡 Code Example

#include <iostream>

class ResourceGuard {
public:
    ResourceGuard() { std::cout << "Resource Acquired\n"; }
    ~ResourceGuard() { std::cout << "Resource Released Automatically\n"; }
};

int main() {
    {
        ResourceGuard guard;
    } // guard destroyed here
    return 0;
}
