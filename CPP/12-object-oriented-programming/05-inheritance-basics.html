Inheritance Basics in C++

🟡 Intermediate

📖 Definition

Inheritance (class Derived : public Base) enables a derived class to inherit member variables and methods from a base class, promoting code reuse and establishing "is-a" relationships.

💡 Code Example

#include <iostream>

class Animal {
public:
    void eat() const { std::cout << "Eating...\n"; }
};

class Dog : public Animal {
public:
    void bark() const { std::cout << "Woof!\n"; }
};

int main() {
    Dog dog;
    dog.eat();  // Inherited from Animal
    dog.bark();
    return 0;
}
