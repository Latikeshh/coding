Virtual Functions, Vtables & Dynamic Polymorphism

🔴 Advanced

📖 Definition

Declaring a base class function virtual enables dynamic dispatch at runtime via a virtual method table (vtable). Derived classes override it using the override keyword. Base classes with virtual functions must declare a virtual ~Base() = default; destructor to prevent undefined behavior when deleting via base pointers.

💡 Code Example

#include <iostream>
#include <memory>

class Shape {
public:
    virtual void draw() const { std::cout << "Drawing Shape\n"; }
    virtual ~Shape() = default;
};

class Circle : public Shape {
public:
    void draw() const override { std::cout << "Drawing Circle\n"; }
};

int main() {
    std::unique_ptr<Shape> shape = std::make_unique<Circle>();
    shape->draw(); // Dynamic dispatch calls Circle::draw()
    return 0;
}
