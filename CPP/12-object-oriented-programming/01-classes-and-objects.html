Classes & Objects in C++

🟡 Intermediate

📖 Definition

A class defines a user-defined blueprint combining data members (state) and member functions (behavior). An object is an instantiated instance of a class occupying memory.

💡 Code Example

#include <iostream>
#include <string>

class Student {
public:
    std::string name;
    int id;

    void printInfo() const {
        std::cout << "Student: " << name << " (ID: " << id << ")\n";
    }
};

int main() {
    Student s1;
    s1.name = "Aria";
    s1.id = 101;
    s1.printInfo();
    return 0;
}
