Strongly Typed Enums (enum class)

🟡 Intermediate

📖 Definition

C++11 introduced enum class (strongly typed / scoped enumerations) to prevent scope pollution and accidental implicit conversions to integer types that occur with legacy unscoped C-style enums.

💡 Code Example

#include <iostream>

enum class Status { Pending, Active, Suspended };

int main() {
    Status s = Status::Active;

    if (s == Status::Active) {
        std::cout << "Account is active!\n";
    }
    return 0;
}
