Student Record Management System (Capstone Project 02)

🔴 Advanced

📖 Project Architecture

A C++ system combining STL containers (std::vector, std::unordered_map), exception handling, and generic algorithms to manage student enrollment records and GPA calculations.

💡 Complete Source Code

#include <iostream>
#include <vector>
#include <string>

struct Student {
    int id;
    std::string name;
    double gpa;
};

int main() {
    std::vector<Student> database{
        {101, "Alice", 3.9},
        {102, "Bob", 3.7}
    };

    for (const auto& s : database) {
        std::cout << "ID: " << s.id << " | Name: " << s.name << " | GPA: " << s.gpa << "\n";
    }
    return 0;
}
