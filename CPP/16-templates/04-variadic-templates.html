Variadic Templates & Fold Expressions (C++17)

🔴 Advanced

📖 Definition

Introduced in C++11, variadic templates accept a variable number of template parameters via parameter packs (typename... Args). C++17 fold expressions ((... + args)) cleanly unpack parameter packs without recursion.

💡 Code Example

#include <iostream>

template <typename... Args>
auto sumAll(Args... args) {
    return (... + args); // C++17 fold expression
}

int main() {
    std::cout << "Sum: " << sumAll(1, 2, 3, 4, 5) << "\n";
    return 0;
}
