Function Templates & Type Deduction

🔴 Advanced

📖 Definition

A function template (template<typename T> void foo(T x)) acts as a pattern from which the compiler generates concrete function instances based on argument types deduced at compile time.

💡 Code Example

#include <iostream>

template <typename T>
T getMax(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    std::cout << "Max Int: " << getMax(10, 20) << "\n";
    std::cout << "Max Double: " << getMax(3.14, 2.71) << "\n";
    return 0;
}
