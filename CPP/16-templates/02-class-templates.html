Class Templates & CTAD

🔴 Advanced

📖 Definition

A class template (template<typename T> class Box) allows building generic classes operating on any data type. C++17 Class Template Argument Deduction (CTAD) allows inferring template arguments directly from constructor arguments.

💡 Code Example

#include <iostream>

template <typename T>
class Container {
private:
    T item;
public:
    Container(T val) : item(val) {}
    T getItem() const { return item; }
};

int main() {
    Container<int> c1(42);
    Container c2("CTAD String"); // CTAD deduces const char* in C++17

    std::cout << c1.getItem() << ", " << c2.getItem() << "\n";
    return 0;
}
