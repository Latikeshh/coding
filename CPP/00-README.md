# 🚀 Learn C++

C++ is a high-performance, object-oriented programming language widely used in game engines (Unreal Engine), systems programming, desktop applications, competitive programming, and high-frequency trading.

> 🟢 **Beginner-friendly:** learn C++ fundamentals step by step, from basic I/O and object-oriented programming (OOP) to modern C++ vectors and classes.

## 📖 What You Will Learn

- Setting up `g++` compiler and running C++ programs
- Standard I/O streams using `std::cout` and `std::cin`
- Variables, data types, string manipulation (`std::string`)
- Decision making with `if/else` and loops (`for`, `while`, range-based `for`)
- Writing functions, default arguments, and pass-by-reference (`&`)
- Dynamic containers using `std::vector`
- Object-Oriented Programming (OOP): classes, objects, constructors, inheritance, and polymorphism
- Practical C++ mini projects

## 🧪 Practice Routine

1. Read the explanation and understand the C++ code example.
2. Type the code in VS Code or your compiler.
3. Compile using `g++ -std=c++17 filename.cpp -o program` and run it.
4. Experiment by modifying logic or adding class methods.
5. Complete the practice challenges.

## ✅ Progress Checklist

- [ ] I can compile and run C++ code using `g++`.
- [ ] I can use `std::cout`, `std::cin`, and `std::string`.
- [ ] I understand pass-by-value vs pass-by-reference (`&`).
- [ ] I can store and iterate over data using `std::vector`.
- [ ] I understand OOP principles: classes, private vs public members, and constructors.
- [ ] I can implement inheritance and virtual functions.
- [ ] I built at least one C++ project.
