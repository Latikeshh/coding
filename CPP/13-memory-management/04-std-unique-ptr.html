std::unique_ptr Deep Dive (Exclusive Ownership)

🔴 Advanced

📖 Definition & Core Mechanics

std::unique_ptr<T> is a zero-overhead smart pointer that enforces Exclusive Ownership over a heap resource. It deleted its copy constructor (unique_ptr(const unique_ptr&) = delete) so it cannot be copied, but supports move semantics (std::move) to transfer ownership. When a unique_ptr leaves scope, it automatically invokes delete on its managed raw pointer.

🛠️ Key Operations & Helper Functions

  • std::make_unique<T>(args...) (C++14): Factory function providing exception-safe allocation.
  • uPtr.get(): Accesses the underlying raw pointer without transferring ownership.
  • uPtr.release(): Relinquishes ownership and returns raw pointer, leaving uPtr null.
  • uPtr.reset(newPtr): Deallocates current resource and assigns a new raw pointer.

💡 Complete Code Example

#include <iostream>
#include <memory>

class DatabaseConnection {
public:
    DatabaseConnection() { std::cout << "Connected to DB\n"; }
    ~DatabaseConnection() { std::cout << "Disconnected from DB\n"; }
    void query() const { std::cout << "Executing SQL Query\n"; }
};

int main() {
    // 1. Creation with std::make_unique
    std::unique_ptr<DatabaseConnection> conn1 = std::make_unique<DatabaseConnection>();
    conn1->query();

    // 2. Transfer Ownership via std::move
    std::unique_ptr<DatabaseConnection> conn2 = std::move(conn1);

    if (!conn1) {
        std::cout << "conn1 is now null after std::move\n";
    }
    conn2->query();

    return 0; // conn2 destructor automatically closes DB connection
}

Executing SQL Query
