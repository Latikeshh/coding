Stack Frame vs Heap Dynamic Memory

🔴 Advanced

📖 Definition

Stack memory manages local function variables automatically using push/pop stack frames with fast CPU register access and limited size. Heap memory provides large dynamic storage managed manually or via smart pointers, requiring explicit allocation/deallocation overhead.

💡 Code Example

#include <iostream>

void demoMemoryLayout() {
    int stackVar = 10; // Automatic stack variable
    int* heapVar = new int(20); // Dynamic heap allocation

    std::cout << "Stack Address: " << &stackVar << "\n";
    std::cout << "Heap Address:  " << heapVar << "\n";

    delete heapVar; // Deallocate heap
}

int main() {
    demoMemoryLayout();
    return 0;
}
