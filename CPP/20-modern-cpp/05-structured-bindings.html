Structured Bindings (C++17)

🔴 Advanced

📖 Definition

Introduced in C++17, structured bindings (auto [x, y] = expression;) unpack tuple-like types, std::pair, C-style arrays, and public data member structs directly into distinct named variables.

💡 Code Example

#include <iostream>
#include <tuple>
#include <string>

struct User {
    std::string name;
    int age;
};

int main() {
    User u{"Aria", 25};
    auto [n, a] = u; // C++17 structured binding

    std::cout << "Name: " << n << ", Age: " << a << "\n";
    return 0;
}
