Header Files, Include Guards & #pragma once

🟡 Intermediate

📖 Definition

Header files (.hpp / .h) declare class interfaces and function prototypes. Include guards (#ifndef HEADER_H ... #endif) or #pragma once prevent multiple inclusion redefinition errors in translation units.

💡 Code Example

#pragma once // Non-standard but universally supported include guard

namespace MathUtils {
    constexpr double PI = 3.14159265;
}
