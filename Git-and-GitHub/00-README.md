# 🔀 Learn Git & GitHub — Version Control & Collaboration Masterclass

Git is the world's most popular distributed version control system, and GitHub is the premier cloud platform for code hosting, collaboration, open-source development, and CI/CD automation. Mastering Git and GitHub is an essential core skill for every software engineer, web developer, and DevOps practitioner.

> 🟢 **Beginner to Advanced:** Start with basic repository initialization and commit lifecycles, master branching, merging, conflict resolution, rebasing, and stashing, and proceed to GitHub remotes, pull requests, SSH authentication, GitHub Actions CI/CD, and professional open-source workflows.

---

## 📖 What You Will Learn

- Distributed version control fundamentals vs centralized systems
- Git installation, environment setup, and global configuration (`git config`)
- Repository creation (`git init`), file states, working directory, staging area (`index`), and commit history
- Inspecting changes (`git status`, `git diff`, `git log --oneline --graph`)
- Ignoring files cleanly using `.gitignore` patterns
- Undoing changes safely (`git restore`, `git reset --soft/mixed/hard`, `git revert`)
- Branching strategies (`git branch`, `git switch`, `git checkout`)
- Merging techniques (Fast-forward vs 3-Way Merge) and resolving merge conflicts step-by-step
- Advanced Git mechanics: `git rebase`, `git stash`, `git cherry-pick`, and `git tag`
- Remote repository management (`git remote`, `git push`, `git pull`, `git fetch`)
- GitHub collaboration: Forking, Branch Protection, Pull Requests (PRs), and Code Reviews
- SSH key authentication setup and security best practices
- GitHub Features: Issues, Project Boards, GitHub Pages hosting, and GitHub Actions CI/CD
- Terminal productivity: Git aliases, custom log formats, and team Git workflows (GitFlow, Trunk-Based)

## 🧪 Practice Routine

1. Read the explanation and understand the terminal concept.
2. Open your terminal (Git Bash, Zsh, PowerShell, or macOS Terminal).
3. Type out commands manually in a practice folder — never copy-paste!
4. Inspect repository status using `git status` and `git log --oneline --graph`.
5. Solve the "Try It Yourself" and "Mini Challenge" tasks in each lesson.

## ✅ Progress Checklist

- [ ] I can initialize Git repositories and configure user identity.
- [ ] I understand the 3 Git trees: Working Directory, Staging Area, and Commit History.
- [ ] I can write clean, meaningful commit messages.
- [ ] I can create branches, merge changes, and resolve merge conflicts confidently.
- [ ] I understand the difference between `git merge` and `git rebase`.
- [ ] I can push and pull code from GitHub using SSH keys or personal access tokens.
- [ ] I can fork repositories, open Pull Requests, and participate in code reviews.
- [ ] I can host static web projects using GitHub Pages.
- [ ] I understand basic GitHub Actions CI/CD workflows and security best practices.
