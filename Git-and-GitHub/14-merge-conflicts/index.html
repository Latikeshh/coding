Handling Merge Conflicts in Git

🟢 Module Overview: Master conflict markers, 3-way merge resolution, and staging resolved commits.

📖 What are Merge Conflicts?

A Merge Conflict occurs when Git is unable to automatically reconcile differences between competing commits across two branches modifying the same lines of code.

📚 Module Lessons

  • 1. Conflict Markers: Identifying <<<<<<< HEAD, =======, and >>>>>>> branch syntax.
  • 2. Resolution Workflow: Inspecting changes, editing conflicting files, and staging solutions with git add.
