12. Margins, Padding & Margin Collapse

🟢 Beginner

📖 Definition

Padding pushes content inward from the border. Margin pushes adjacent elements outward. Adjacent vertical block margins collapse into a single margin equal to the larger value.

💡 Code Example

.spaced-box {
  padding: 20px; /* Inside spacing */
  margin-bottom: 30px; /* Outer spacing */
}
