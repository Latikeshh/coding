25. CSS Filters (backdrop-filter), Masks & Clip-Paths

🟡 Intermediate

1. Definition

CSS filters (blur(), brightness(), contrast(), drop-shadow()) apply graphical effects. backdrop-filter applies blurred frosted-glass effects to content behind an element. clip-path clips elements to geometric shapes (polygon/circle).

2. Why It Is Used

Filters and backdrop-filters create modern glassmorphism UI navigation bars, modal backdrops, and custom cropped avatar shapes without editing raw image files in Photoshop.

3. How It Works

backdrop-filter operates on pixels rendered directly underneath the element's box before rendering the element's translucent background color.

4. Syntax

.glass-panel {
  background-color: rgba(15, 23, 42, 0.65);
  backdrop-filter: blur(12px);
  -webkit-backdrop-filter: blur(12px);
}

5. CSS Graphical Filter Functions Table

FunctionOperationExample Syntax
blur(px)Applies Gaussian blurfilter: blur(8px);
backdrop-filterBlurs content BEHIND elementbackdrop-filter: blur(10px);
drop-shadow()Shadow following PNG alpha transparent silhouettefilter: drop-shadow(0 4px 8px rgba(0,0,0,0.2));
clip-pathClips element to polygon or circle shapeclip-path: circle(50%);

6. Beginner Example

.grayscale-image {
  filter: grayscale(100%);
  transition: filter 0.3s ease;
}
.grayscale-image:hover {
  filter: grayscale(0%);
}

7. Intermediate Example

.star-badge {
  width: 100px;
  height: 100px;
  clip-path: polygon(50% 0%, 61% 35%, 98% 35%, 68% 57%, 79% 91%, 50% 70%, 21% 91%, 32% 57%, 2% 35%, 39% 35%);
  background-color: #f59e0b;
}

8. Advanced Glassmorphism Header Example

.glass-header {
  position: sticky;
  top: 0;
  z-index: 900;
  background-color: rgba(15, 23, 42, 0.75);
  backdrop-filter: blur(12px) saturate(180%);
  -webkit-backdrop-filter: blur(12px) saturate(180%);
  border-bottom: 1px solid rgba(255, 255, 255, 0.1);
}

9. Line-by-Line Code Explanation

  • backdrop-filter: blur(12px) saturate(180%);: Applies a 12px blur combined with saturation boost to underlying page content, rendering an iOS-style frosted glass effect.

10. Expected Terminal / Browser Output

A translucent navigation bar displaying a blurred frosted-glass window overlay above scrolling background elements.

11. Common Mistakes & Pitfalls

  • Using opaque background colors with backdrop-filter: If background-color is 100% solid, backdrop-filter effects underneath will be hidden. Use alpha transparency (e.g. rgba(...)).

12. Important Rules & Limitations

  • Always include -webkit-backdrop-filter vendor prefix for Safari browser compatibility.
