10. Background Colors, Images & Gradients

🟢 Beginner

📖 Definition

CSS background properties style the backdrop of elements: background-color, background-image, background-repeat, background-size (cover/contain), and modern CSS3 linear-gradient() and radial-gradient().

💡 Code Example

.hero-banner {
  background: linear-gradient(135deg, #1e3a8a, #3b82f6);
  color: #ffffff;
  padding: 60px 20px;
}
