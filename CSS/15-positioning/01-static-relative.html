01. Static Flow & Relative Positioning

🟢 Beginner

📖 Definition

position: static is the default document layout flow. position: relative offsets an element from its normal static position using top, right, bottom, or left without affecting surrounding elements, and establishes a positioning context for absolutely positioned children.
