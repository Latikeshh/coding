02. Absolute Overlay & Fixed Viewport Positioning

🟡 Intermediate

📖 Definition

position: absolute removes an element from normal flow and places it relative to its nearest positioned ancestor. position: fixed positions an element relative to the browser viewport window (staying pinned during scroll).
