01. CSS Custom Properties (--variable-name, var())

🟢 Beginner

📖 Definition

CSS Custom Properties (CSS Variables) allow storing reusable values prefixed with -- (e.g. --primary-color: #2563eb) and retrieving them via var(--primary-color), supporting cascade inheritance and dynamic theme switching.
