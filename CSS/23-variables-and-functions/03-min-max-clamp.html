03. Fluid Sizing Math (min, max, clamp)

🟡 Intermediate

📖 Definition

min() selects the smallest value, max() selects the largest value, and clamp(min, preferred, max) bounds a value between upper and lower limits, enabling fluid responsive typography (e.g. font-size: clamp(1rem, 2.5vw, 2rem)).
