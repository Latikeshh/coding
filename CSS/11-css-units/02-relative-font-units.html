Relative Font Units (rem, em, %)

🟢 Beginner

📖 Definition

Relative Font Units (rem, em, %, ch) scale dynamically relative to font sizes. rem scales relative to the root <html> font size (default 16px), ensuring accessibility when users increase font preferences.

🌍 Multilingual Summary

English

rem scales relative to root font size (1rem = 16px default). em scales relative to parent font size.

Hindi

rem root <html> font size ke respect mein scale hota hai, jo accessible layouts ke liye best hai.

⚡ Code Example

html {
  font-size: 16px; /* Default browser root font size */
}

h1 {
  font-size: 2rem; /* 2 x 16px = 32px */
  margin-bottom: 1rem; /* 16px spacing */
}
