26. Advanced Selectors (:is(), :where(), :has() Parent Selector)

🔴 Advanced

📖 Definition

Modern CSS introduces relational pseudo-classes: :is() (groups selectors with highest specificity), :where() (groups selectors with zero specificity), and :has() (the relational parent selector targeting parent elements that contain specific children).

💡 Code Example

/* Target a card parent container ONLY IF it contains an image */
.card:has(img) {
  padding-top: 0;
}

/* Match any heading inside main without specificity inflation */
:where(h1, h2, h3) {
  margin-top: 0;
}
