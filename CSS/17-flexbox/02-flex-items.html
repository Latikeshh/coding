02. Flex Item Sizing (grow, shrink, basis, align-self)

🟡 Intermediate

📖 Definition

Flex item properties control individual child sizing: flex-grow dictates expanding into free space, flex-shrink dictates shrinking on overflow, flex-basis sets initial main size, and align-self overrides container alignment for a single child.
