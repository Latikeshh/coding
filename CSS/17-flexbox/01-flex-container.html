01. Flex Container Properties (direction, justify, align)

🟡 Intermediate

📖 Definition

Declaring display: flex creates a 1D flex formatting context. flex-direction sets the main axis (row or column). justify-content aligns items along the main axis; align-items aligns items along the cross axis.
