03. History & W3C Standards Evolution of CSS

🟢 Beginner

1. Definition

CSS was proposed by Håkon Wium Lie on October 10, 1994 at CERN, developed with Bert Bos, and standardized by the World Wide Web Consortium (W3C). CSS Resets (e.g. Eric Meyer Reset) and Normalize.css eliminate cross-browser default user-agent style discrepancies.

2. Why It Is Used

Understanding CSS history helps developers write cross-browser compatible code, appreciate modern modular specifications (Flexbox, Grid, Container Queries), and avoid obsolete HTML presentational tags (like <font> or <center>).

3. How It Works

W3C Working Groups maintain CSS specifications across levels. Rather than releasing monolithic CSS4 specifications, modern CSS evolves through living, independent module specifications (e.g., CSS Color Level 5, CSS Grid Level 2).

4. Syntax

/* Modern CSS Feature Query */
@supports (display: grid) {
  .gallery { display: grid; }
}

6. Beginner Example

/* CSS Reset snippet */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

7. Intermediate Example

/* Standard Normalize font inheritance */
html {
  font-family: system-ui, -apple-system, sans-serif;
  line-height: 1.5;
  -webkit-text-size-adjust: 100%;
}

8. Advanced Production Theme Example

/* Modern living spec theme adaptation */
:root {
  color-scheme: light dark;
  --bg-main: oklch(0.98 0.01 240);
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg-main: oklch(0.15 0.02 240);
  }
}

9. Line-by-Line Code Explanation

  • color-scheme: light dark;: Informs the browser that the page natively supports light and dark operating system themes.
  • oklch(0.98 0.01 240);: Modern W3C Level 4 color notation offering perceptually uniform lightness across devices.

10. Expected Terminal / Browser Output

A web application that automatically switches default background colors and scrollbar themes based on operating system preferences.

11. Common Mistakes & Pitfalls

  • Waiting for "CSS4": CSS is no longer released as single monolithic versions; individual features are updated independently.

12. Important Rules & Limitations

  • Always test cutting-edge living spec features in CanIUse.com before deploying to enterprise production.
