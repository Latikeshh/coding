01. Pseudo-classes (:hover, :focus, :nth-child)

🟡 Intermediate

📖 Definition

A pseudo-class (:selector) targets elements based on state or position: user interaction (:hover, :focus-visible), form state (:checked, :disabled), or structural index (:nth-child(even), :first-child).
