02. Pseudo-elements (::before, ::after, ::placeholder)

🟡 Intermediate

📖 Definition

A pseudo-element (::selector) styles specific parts of an element: inserting decorative content without extra HTML (::before, ::after requiring content: ""), styling input hints (::placeholder), or user text selection (::selection).
