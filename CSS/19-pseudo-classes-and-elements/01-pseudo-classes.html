01. Pseudo-classes (:hover, :focus-visible, :focus-within, :nth-child)

🟡 Intermediate

1. Definition

A Pseudo-class (:selector) targets elements based on state or position: user interaction (:hover, :focus-visible, :focus-within), form state (:checked, :disabled), or structural index (:nth-child(n of .class), :first-child, :not()).

2. Why It Is Used

Pseudo-classes apply dynamic interactive styling (like button hover feedback or active form field rings) without requiring JavaScript state handlers.

3. How It Works

The browser continuously checks element state flags (like cursor hover position or keyboard focus). When a state changes to true, the browser applies the pseudo-class rule set dynamically.

4. Syntax

button:hover {
  background-color: #1d4ed8;
}

.form-group:focus-within {
  border-color: #2563eb;
}

5. Pseudo-class Categories Table

CategoryPseudo-classesTarget Description
User Action:hover, :active, :focus-visibleCursor hover, click press, keyboard focus ring
Container State:focus-withinTarget parent container when ANY child is focused
Form Control:checked, :disabled, :validCheckbox/radio status, disabled input styling
Structural:nth-child(even), :nth-child(n of .card)Index pattern matching with class filtering

6. Beginner Example

a:hover {
  text-decoration: underline;
  color: #2563eb;
}

7. Intermediate Example

/* Striped table rows */
tbody tr:nth-child(even) {
  background-color: #f8fafc;
}

8. Advanced Focus-Within Form Field Example

/* Highlights label and wrapper when input is focused */
.input-group:focus-within {
  border-color: #2563eb;
  box-shadow: 0 0 0 3px rgba(37, 99, 235, 0.2);
}

9. Line-by-Line Code Explanation

  • .input-group:focus-within: Applies blue ring styling to the entire outer container whenever any nested <input> inside it receives focus.

10. Expected Terminal / Browser Output

Form fields and search inputs that highlight seamlessly when clicked or tabbed into via keyboard.

11. Common Mistakes & Pitfalls

  • Confusing :nth-child() with :nth-of-type(): :nth-child counts all sibling elements regardless of tag name unless qualified.

12. Important Rules & Limitations

  • Always use :focus-visible instead of :focus for custom button outlines so mouse clicks do not show persistent focus rings.
