02. Media Queries (@media & Mobile-First Strategy)

🟡 Intermediate

📖 Definition

Media Queries (@media (min-width: 768px) { ... }) apply conditional CSS styling based on screen width, orientation, resolution, or device capabilities. Mobile-first design writes base CSS for small screens, using min-width to add tablet/desktop layout enhancements.
