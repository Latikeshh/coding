28. CSS Architecture (BEM), @supports & Dark Mode

🔴 Advanced

📖 Definition

BEM (Block Element Modifier) methodology (.card__title--active) keeps selector specificity flat and maintainable. Feature queries (@supports) detect browser property compatibility. Dark Mode toggles color themes using CSS variables and prefers-color-scheme.

💡 Code Example

/* BEM Naming Convention */
.btn { display: inline-block; padding: 10px 20px; }
.btn__icon { margin-right: 8px; }
.btn--primary { background-color: #2563eb; color: white; }

/* Dark Mode Theme via Custom Properties */
@media (prefers-color-scheme: dark) {
  :root {
    --bg-main: #0f172a;
    --text-main: #f8fafc;
  }
}
