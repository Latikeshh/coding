08. Width, Height, min/max Constraints & aspect-ratio

🟢 Beginner

📖 Definition

Sizing properties control element dimensions. Using max-width: 100% prevents images and containers from overflowing small mobile viewports, while modern aspect-ratio: 16/9 preserves responsive proportions.

💡 Code Example

.responsive-container {
  width: 100%;
  max-width: 1200px; /* Constrains desktop expansion */
  margin: 0 auto;
}

.hero-video {
  width: 100%;
  aspect-ratio: 16 / 9; /* Modern C++ aspect ratio preservation */
}
