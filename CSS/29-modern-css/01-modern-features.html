01. Modern Features (object-fit, object-position, aspect-ratio, Scroll Snap)

🟡 Intermediate

1. Definition

object-fit: cover scales images proportionally inside aspect containers without distortion. aspect-ratio: 16 / 9 preserves container ratios, and CSS Scroll Snap aligns touch carousels.

2. Why It Is Used

Modern features eliminate image distortion bugs, replace aspect-ratio padding hacks, and create native touch-friendly horizontal carousels without JavaScript libraries.

3. How It Works

object-fit: cover crops an <img> element to fill its container while preserving aspect ratio. scroll-snap-type: x mandatory forces touch swipes to snap to scroll-snap-align: center coordinates.

4. Syntax

.avatar-img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: center;
}

.carousel {
  display: flex;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
}
.carousel-item {
  scroll-snap-align: start;
}

5. Object Fit Options Reference Table

ValueBehavior
fillDefault; stretches image to fit box (distorts ratio)
containScales image to fit completely inside box without cropping
coverFills box completely (crops edges to preserve ratio)
noneIgnores box dimensions; retains original image pixel size

6. Beginner Example

.hero-photo {
  width: 100%;
  height: 400px;
  object-fit: cover;
}

7. Intermediate Example

.video-card {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
  border-radius: 12px;
}

8. Advanced Touch Carousel Scroll Snap Example

.slider {
  display: flex;
  gap: 16px;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
  scroll-behavior: smooth;
  padding: 16px 0;
}

.slider-card {
  flex: 0 0 80%;
  scroll-snap-align: center;
  border-radius: 12px;
}

9. Line-by-Line Code Explanation

  • scroll-snap-type: x mandatory;: Forces horizontal scroll containers to snap cleanly to child scroll-snap-align: center card boundaries upon user release.

10. Expected Terminal / Browser Output

A native touch-friendly horizontal card carousel that snaps smoothly to each card during swipes.

11. Common Mistakes & Pitfalls

  • Setting object-fit without declaring width and height: object-fit has no effect unless explicit box dimensions (width & height) are defined on the image.

12. Important Rules & Limitations

  • aspect-ratio works seamlessly across all modern evergreen browsers.
