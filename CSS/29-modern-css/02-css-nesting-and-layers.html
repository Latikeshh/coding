02. Native CSS Nesting, Cascade Layers (@layer) & @property Registration

🔴 Advanced

1. Definition

Native CSS Nesting allows nesting child rules inside parent blocks using &. Cascade Layers (@layer) control style precedence independently of selector specificity. @property registers custom variables with strict types and initial values for animatable custom properties.

2. Why It Is Used

Native Nesting replaces Sass build steps. @layer prevents third-party CSS frameworks from overriding component styles, and @property enables smooth gradient transitions.

3. How It Works

@property --gradient-angle tells the browser rendering engine that a custom variable is a <angle> type, allowing keyframe transitions between 0deg and 360deg.

4. Syntax

/* Native CSS Nesting */
.card {
  padding: 20px;
  & .card-title { color: #2563eb; }
  &:hover { transform: translateY(-4px); }
}

/* Custom Property Registration */
@property --gradient-angle {
  syntax: '<angle>';
  initial-value: 0deg;
  inherits: false;
}

6. Beginner Example

.btn {
  background: #2563eb;
  &:hover {
    background: #1d4ed8;
  }
}

7. Intermediate Example

@layer base, components;

@layer base {
  button { background: gray; }
}

@layer components {
  .btn-primary { background: blue; } /* Always overrides @layer base! */
}

8. Advanced Animatable Gradient Angle Example

@property --angle {
  syntax: '<angle>';
  initial-value: 0deg;
  inherits: false;
}

.animated-border {
  background: conic-gradient(from var(--angle), #2563eb, #10b981, #2563eb);
  animation: rotateGradient 4s linear infinite;
}

@keyframes rotateGradient {
  to { --angle: 360deg; }
}

9. Line-by-Line Code Explanation

  • @property --angle { syntax: '<angle>'; ... }: Informs the browser that --angle is an angle value, enabling smooth rotation animations in keyframes.

10. Expected Terminal / Browser Output

A rotating gradient border spinning continuously at 60fps.

11. Common Mistakes & Pitfalls

  • Trying to animate unregistered CSS variables: Unregistered variables default to string tokens and cannot be animated via @keyframes without @property.

12. Important Rules & Limitations

  • Native CSS nesting requires using & when nesting element tag selectors (e.g. & p).
