24. Logical Properties & Writing Modes (margin-inline, padding-block)

🟡 Intermediate

1. Definition

CSS Logical Properties (margin-inline, padding-block, inset-inline, border-block) control layout spacing relative to block and inline flow directions (writing-mode), automatically adapting across Left-to-Right (LTR) and Right-to-Left (RTL) international languages.

2. Why It Is Used

Logical properties replace hardcoded physical properties (margin-left, padding-top) so international multi-language websites seamlessly adjust margins and padding without separate RTL stylesheets.

3. How It Works

inline-size corresponds to width in horizontal writing modes, while block-size corresponds to height. margin-inline-start maps to left margin in LTR and right margin in RTL.

4. Syntax

.international-card {
  padding-block: 2rem;   /* Top & Bottom */
  padding-inline: 1.5rem; /* Left & Right */
  inset-inline-start: 0;  /* Left in LTR / Right in RTL */
}

5. Physical vs Logical Properties Mapping Table

Physical PropertyLogical Property EquivalentDirectional Flow Mapping
width / heightinline-size / block-sizeHorizontal / Vertical sizing
margin-left / rightmargin-inline-start / endText start / text end side
padding-top / bottompadding-block-start / endBlock start / block end side
left / right / topinset-inline / inset-blockPositioning offset bounds

6. Beginner Example

.box {
  margin-inline: auto; /* Replaces margin: 0 auto for horizontal centering */
}

7. Intermediate Example

.article-card {
  padding-block: 1.5rem;
  padding-inline: 1rem;
  border-inline-start: 4px solid #2563eb;
}

8. Advanced Multilingual Layout Example

/* Supports vertical Asian text writing modes */
.vertical-text-card {
  writing-mode: vertical-rl;
  padding-block: 2rem; /* Automatically becomes left & right padding! */
}

9. Line-by-Line Code Explanation

  • border-inline-start: 4px solid #2563eb;: Places an accent border on the left side in English (LTR) and automatically moves it to the right side in Arabic/Hebrew (RTL).

10. Expected Terminal / Browser Output

A multi-language web application component whose margins, padding, and accent borders swap sides dynamically based on document text direction.

11. Common Mistakes & Pitfalls

  • Mixing physical and logical properties: Combining margin-left: 20px with margin-inline-end: 10px causes specificity confusion. Use logical properties consistently.

12. Important Rules & Limitations

  • Logical properties are fully supported across all modern evergreen browsers.

13. Multilingual Explanation: English
