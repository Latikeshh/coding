12. Margins, Padding & Vertical Margin Collapse Rules

🟢 Beginner

1. Definition

Padding creates space inside an element's border. Margin creates transparent space outside the border to separate adjacent elements. Vertical block margins collapse into a single margin equal to the larger value.

2. Why It Is Used

Spacing rules control legibility and visual rhythm. Auto margins (margin-inline: auto) center fixed block containers horizontally.

3. How It Works

In standard block layout, when two vertical margins touch (e.g. margin-bottom: 20px on an h1 and margin-top: 30px on a paragraph), they do not add up to 50px—they collapse so the final gap is 30px.

4. Syntax

.box {
  padding: 20px;            /* 4-side shorthand */
  margin: 10px 20px 10px 20px; /* Top Right Bottom Left */
}

5. Shorthand Values Reference Table

Value CountShorthand SyntaxExpansion Mapping
1 Valuemargin: 20px;All 4 sides equal (Top, Right, Bottom, Left)
2 Valuesmargin: 10px 20px;Top/Bottom = 10px, Left/Right = 20px
3 Valuesmargin: 10px 20px 30px;Top = 10px, Left/Right = 20px, Bottom = 30px
4 Valuesmargin: 10px 20px 30px 40px;Top, Right, Bottom, Left (Clockwise)

6. Beginner Example

.card-inner {
  padding: 16px;
  margin-bottom: 24px;
}

7. Intermediate Example

/* Centering a fixed-width container */
.container {
  width: 100%;
  max-width: 1100px;
  margin-inline: auto; /* Equivalent to margin: 0 auto */
  padding-inline: 1.5rem;
}

8. Advanced Example (Preventing Margin Collapse)

/* Preventing parent-child margin collapse */
.parent-box {
  display: flow-root; /* Creates a BFC that prevents internal margin collapse */
}

.child-heading {
  margin-top: 40px;
}

9. Line-by-Line Code Explanation

  • display: flow-root;: Establishes a new Block Formatting Context (BFC), containing child vertical margins inside the parent box.

10. Expected Terminal / Browser Output

Elements separated by clean predictable spacing without unintended margin collapse glitches.

11. Common Mistakes & Pitfalls

  • Expecting inline elements to respect vertical margins: Vertical margins on <span> elements are ignored unless display: inline-block or block is declared.

12. Important Rules & Limitations

  • Margin collapse only occurs vertically between adjacent block-level elements.
