01. CSS Transitions (property, duration, timing-function, cubic-bezier)

🟢 Beginner

1. Definition

CSS Transitions interpolate property values smoothly over time (e.g., transition: background-color 0.3s cubic-bezier(0.4, 0, 0.2, 1)) when an element changes states (such as :hover or :focus).

2. Why It Is Used

Transitions provide visual feedback for interactive buttons, navigation links, and hover cards, making web interfaces feel responsive and polished.

3. How It Works

When a state change occurs, the browser calculates intermediate property values frame by frame based on duration and the mathematical acceleration curve of the timing function.

4. Syntax

.button {
  transition: background-color 0.3s ease, transform 0.2s ease;
}

5. Timing Function Variations Table

Timing FunctionAcceleration CurveBest Practice Usage
easeSlow start, fast middle, slow endDefault general transitions
linearConstant speed throughoutColor fades & progress bars
ease-in-outSymmetrical slow start & slow endSmooth UI dialog transitions
cubic-bezier(...)Custom mathematical Bezier curveSpring & bounce animations

6. Beginner Example

.btn {
  background-color: #2563eb;
  transition: background-color 0.2s ease;
}
.btn:hover {
  background-color: #1d4ed8;
}

7. Intermediate Example

.card {
  transition: transform 0.3s cubic-bezier(0.4, 0, 0.2, 1), box-shadow 0.3s ease;
}
.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 10px 20px rgba(0, 0, 0, 0.1);
}

8. Advanced Multi-Property Delay Example

.nav-drawer {
  transition: transform 0.4s cubic-bezier(0.16, 1, 0.3, 1), opacity 0.2s ease 0.1s;
}

9. Line-by-Line Code Explanation

  • transition: transform 0.4s ...: Animates card transform over 0.4 seconds using a custom natural ease-out cubic-bezier curve.

10. Expected Terminal / Browser Output

A card component that lifts smoothly 4px upward with an expanding shadow when hovered.

11. Common Mistakes & Pitfalls

  • Animating non-GPU properties: Animating height or margin causes CPU reflows. Animate transform and opacity instead.

12. Important Rules & Limitations

  • Declare transition on the base class rule (not the :hover rule) so the reverse transition plays smoothly when unhovered.

13. Multilingual Explanation: English
