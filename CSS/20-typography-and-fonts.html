20. Typography, Web Fonts & @font-face Integration

🟢 Beginner

1. Definition

CSS typography properties style text: font-family fallback stacks, web safe fonts, Google Fonts integration, custom font files via @font-face, font-size, font-weight, line-height, letter-spacing, text-align, and text-transform.

2. Why It Is Used

Typography controls readability, user comprehension, and visual hierarchy. Integrating custom web fonts builds brand identity across all user operating systems.

3. How It Works

@font-face downloads custom font files (.woff2) from a web server and maps them to a custom font-family name usable throughout your CSS.

4. Syntax

@font-face {
  font-family: 'CustomFont';
  src: url('fonts/custom-font.woff2') format('woff2');
  font-display: swap;
}

body {
  font-family: 'CustomFont', system-ui, sans-serif;
}

6. Beginner Example

p {
  font-family: Arial, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
}

7. Intermediate Example

h1 {
  font-size: 2.5rem;
  font-weight: 800;
  letter-spacing: -0.025em;
  text-transform: uppercase;
}

8. Advanced Custom @font-face Loading Example

@font-face {
  font-family: 'Inter';
  font-style: normal;
  font-weight: 400 700; /* Variable font weight range */
  src: url('fonts/inter-variable.woff2') format('woff2');
  font-display: swap; /* Flash of unstyled text prevention */
}

9. Line-by-Line Code Explanation

  • font-display: swap;: Immediately displays fallback system fonts while custom .woff2 files load, preventing invisible text during web page load.

10. Expected Terminal / Browser Output

Clean, readable typography utilizing modern custom web fonts without page load rendering delays.

11. Common Mistakes & Pitfalls

  • Forgetting fallback generic font families: Omitting sans-serif or serif at the end of font-family stacks breaks formatting if custom fonts fail to load.

12. Important Rules & Limitations

  • Always use modern compressed .woff2 font formats for fastest loading speed.
