06. Basic Selectors (Element, Class, ID, Grouping)

🟢 Beginner

📖 Definition

Selectors target HTML elements to apply CSS declarations. Basic selector types include Universal (*), Element (p), Class (.btn), ID (#main), and Grouping (h1, h2, h3).

💡 Code Example

/* Universal Reset */
* { box-sizing: border-box; }

/* Class Selector (Reusable) */
.card-title { color: #1e3a8a; }

/* ID Selector (Unique) */
#hero-header { font-size: 2.5rem; }
