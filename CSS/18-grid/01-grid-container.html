01. Grid Container & Track Sizing (fr, minmax)

🟡 Intermediate

📖 Definition

display: grid establishes a 2D layout context. grid-template-columns defines column track sizing using the fr (Fraction) unit, and repeat(auto-fit, minmax(250px, 1fr)) creates auto-responsive card grids without media queries.
