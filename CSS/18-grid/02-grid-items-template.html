02. Grid Items, Spanning & Template Areas

🟡 Intermediate

📖 Definition

Child elements can span multiple tracks using grid-column: span 2 or grid-row: 1 / 3. grid-template-areas maps named string templates (e.g. "header header" "sidebar main") into visual layouts.
