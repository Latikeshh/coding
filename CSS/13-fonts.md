# Fonts

> 🟢 Beginner

## 📖 Definition

Fonts control the style of the text, including the typeface, size, and weight.

## 🤔 Why Do We Use It?

Fonts help make a page readable and visually consistent. Different headings and body text can use different font styles to improve hierarchy.

## 🧠 Simple Explanation

Fonts are the way letters look. A title can use a bigger and bolder font, while the main text uses a cleaner and simpler one.

## 📝 Syntax

```css
body {
  font-family: Arial, sans-serif;
  font-size: 16px;
}
```

## 💡 Example

```css
body {
  font-family: Arial, sans-serif;
}

h1 {
  font-size: 32px;
  font-weight: bold;
}
```

## 🌐 HTML + CSS Example

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Fonts Example</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Restaurant Review</h1>
  <p>The food was fresh, warm, and well prepared.</p>
</body>
</html>
```

```css
body {
  font-family: Arial, sans-serif;
}

h1 {
  font-size: 32px;
  font-weight: bold;
}
```

## 👀 What You Will See

The page uses a clean sans-serif font, and the heading is larger and more noticeable than the paragraph.

## 🧪 Try It Yourself

Try a different font-family such as `Verdana` or `Georgia` and compare the result.

## ✅ Remember

- `font-family` controls the text style.
- `font-size` changes how large text appears.
- `font-weight` makes text lighter or bolder.
