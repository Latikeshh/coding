# History & Standards of CSS

> 🟢 Beginner

## 📖 Definition

CSS (Cascading Style Sheets) was proposed by Håkon Wium Lie in 1994 and developed alongside Bert Bos at W3C to separate document content from visual presentation.

> 🌐 **Multilingual Summary / संक्षेप / स्पष्टीकरण**
>
> - **English:** CSS was created to separate HTML structure from visual styling. Today, CSS3 is developed as modular specifications.
> - **Hindi:** CSS का विकास HTML स्ट्रक्चर और डिज़ाइन को अलग रखने के लिए किया गया था।
> - **Marathi:** HTML मजकूर आणि डिझाईन वेगळे करण्यासाठी CSS ची निर्मिती झाली.
> - **Hinglish:** CSS ko HTML structure aur design ko separate rakhne ke liye banaya gaya tha. Modern CSS modular standards par chalta hai.

## 📜 Historical Milestones

```text
1994 → CSS proposed by Håkon Wium Lie
1996 → CSS1 W3C Recommendation
1998 → CSS2 Recommendation
2011 → CSS2.1 Standard
2010s+ → CSS3 Modular Specifications (Flexbox, Grid, Animations)
```
