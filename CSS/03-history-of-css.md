# History of CSS

> 🟢 Beginner

## 📖 Definition

CSS history explains how CSS was introduced and developed as a way to separate content from visual design on the web.

## 🤔 Why Do We Use It?

Understanding the history helps us understand why CSS was created and why it is such an important part of modern web design.

## 🧠 Simple Explanation

At the beginning of the web, HTML was mostly used for structure and meaning. Developers wanted a cleaner system to control design, so CSS was created to separate content from style.

## Who Developed CSS?

CSS was developed mainly by Håkon Wium Lie and Bert Bos in the mid-1990s.

## Why Was CSS Created?

The early web needed a way to keep pages structured and readable without mixing content and design in the same code. CSS gave designers a better way to style pages consistently.

## Approximate Timeline

```text
1994 → CSS was first proposed
1996 → CSS1
1998 → CSS2
2004–2011 → CSS2.1
2010s onward → CSS3 and modern CSS modules
```

## Important Historical Points

- CSS was created in the context of the early World Wide Web.
- It was designed to separate structure and presentation.
- CSS1 introduced the first standard style rules.
- CSS2 expanded layout and formatting features.
- CSS2.1 cleaned up and clarified earlier standards.
- CSS3 is not one single final version in the same way as CSS1 or CSS2. Modern CSS is developed as separate, modular specifications.

## 👀 What You Will See

You will understand that CSS grew out of the need to make websites easier to design and maintain.

## 🧪 Try It Yourself

Read one short article or note about the early web and compare it to the way CSS separates content and style today.

## ⚠️ Common Mistakes

- Saying CSS appeared fully finished in one exact year.
- Thinking CSS3 is one single version like CSS1.
- Forgetting that CSS is part of a broader web evolution.

## ✅ Remember

- CSS was created to separate design from structure.
- Håkon Wium Lie and Bert Bos are important names in CSS history.
- Modern CSS is built from many shorter, evolving specifications.
