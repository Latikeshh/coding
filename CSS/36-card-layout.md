# Card Layouts

> 🟢 Beginner

## 📖 Definition

A card layout is a common design pattern where content is organized into individual blocks with padding, borders, shadows, and spacing.

## 🤔 Why Do We Use It?

Cards help group related information in a neat and visually appealing way.

## 🧠 Simple Explanation

Each card behaves like a small container, making content easier to scan.

## Common card styles

- `background-color`
- `padding`
- `border-radius`
- `box-shadow`
- `border`

## 📝 Syntax

```css
.card {
  background: #fff;
  padding: 20px;
  border-radius: 12px;
  box-shadow: 0 4px 10px rgba(0, 0, 0, 0.1);
}
```

## 👀 What You Will See

The card stands out from the page with a clean box-like design.

## 🧪 Try It Yourself

Change the shadow and border radius to see how the card feels different.

## ⚠️ Common Mistakes

- Overusing heavy shadows.
- Making cards too tall or too wide.
- Ignoring spacing around the group of cards.

## ✅ Remember

- Cards are great for organizing information.
- They are a standard building block in modern web design.
- Simple styling works best.
