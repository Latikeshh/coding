02. Relative Font & Parent Units (rem, em, %)

🟢 Beginner

📖 Definition

Relative font units scale dynamically: rem scales relative to root <html> font-size (1rem = 16px default), em scales relative to current element/parent font-size, and % scales relative to parent box dimensions.
