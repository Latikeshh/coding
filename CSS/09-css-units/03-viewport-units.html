03. Viewport & Dynamic Units (vw, vh, dvh, svh)

🟢 Beginner

📖 Definition

Viewport units scale relative to screen window dimensions: 1vw = 1% of viewport width, 1vh = 1% of viewport height. Dynamic mobile units dvh and svh adapt to collapsible browser address bars.
