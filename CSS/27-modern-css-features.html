27. Modern CSS3 Features (object-fit, Logical Properties)

🟡 Intermediate

📖 Definition

Modern CSS features improve internationalization and media styling: object-fit: cover scales images proportionally inside aspect containers, CSS Logical Properties (margin-inline, padding-block) adapt to LTR/RTL text directions, and CSS Scroll Snap aligns scroll carousels.

💡 Code Example

.avatar-img {
  width: 100px;
  height: 100px;
  object-fit: cover; /* Prevents image distortion */
  border-radius: 50%;
}

.padded-container {
  padding-block: 2rem; /* Logical top and bottom padding */
  padding-inline: 1.5rem; /* Logical left and right padding */
}
