03. Responsive Navigation Bars & Drawer Menus

🟡 Intermediate

1. Definition

Navigation Bars align brand logos, link lists, and search controls horizontally using Flexbox on desktop viewports, transforming into mobile toggle drawer menus via media queries.

2. Why It Is Used

Navigation bars provide global site navigation across all screen sizes while preserving header vertical space on mobile devices.

3. How It Works

A desktop header uses display: flex with justify-content: space-between. At mobile breakpoints (max-width: 768px), the nav links menu converts to a fixed off-canvas drawer controlled via CSS class toggles.

4. Syntax

.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 1rem 2rem;
  background-color: #0f172a;
}

6. Beginner Example

.header-nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

7. Intermediate Example

.navbar-sticky {
  position: sticky;
  top: 0;
  z-index: 1000;
  background-color: rgba(15, 23, 42, 0.9);
  backdrop-filter: blur(8px);
}

8. Advanced Mobile Off-Canvas Drawer Example

@media (max-width: 768px) {
  .nav-menu {
    position: fixed;
    top: 0;
    left: 0;
    width: 280px;
    height: 100vh;
    background: #0f172a;
    transform: translateX(-100%);
    transition: transform 0.3s ease;
  }
  .nav-menu.active {
    transform: translateX(0);
  }
}

9. Line-by-Line Code Explanation

  • transform: translateX(-100%);: Hides mobile navigation drawer off-screen to the left until .active class is added via JavaScript toggle button.

10. Expected Terminal / Browser Output

A responsive header navigation bar that transforms smoothly into a mobile drawer menu when resized.

11. Common Mistakes & Pitfalls

  • Forgetting z-index on sticky headers: Sticky headers without z-index will scroll underneath page images and cards.

12. Important Rules & Limitations

  • Always set a high z-index (e.g. 1000) on sticky navigation headers.
