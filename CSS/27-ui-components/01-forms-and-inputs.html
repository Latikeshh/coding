01. Styling Forms, Inputs & Custom Focus Rings

🟢 Beginner

1. Definition

Styling form inputs (input, textarea, select) ensures visual consistency across operating systems while maintaining accessibility using :focus-visible outline rings, custom checkboxes, and custom select dropdown controls.

2. Why It Is Used

Default browser form controls render differently on iOS, Android, Windows, and macOS. Custom CSS styling establishes branded, accessible UI forms across all platforms.

3. How It Works

Using appearance: none removes OS default button/select chrome, allowing custom borders, padding, background icons, and :focus-visible ring highlights to take effect.

4. Syntax

.custom-input {
  appearance: none;
  width: 100%;
  padding: 10px 14px;
  border: 1px solid #cbd5e1;
  border-radius: 6px;
}

.custom-input:focus-visible {
  outline: 2px solid #2563eb;
  outline-offset: 2px;
}

5. Form Component States Table

State Pseudo-classTarget Behavior
:focus-visibleActive keyboard focus ring (Avoids mouse focus ring)
:invalidDisplays red validation borders on failed pattern/required checks
:disabledDims opacity (0.6) and sets cursor: not-allowed

6. Beginner Example

input[type="text"] {
  padding: 8px 12px;
  border: 1px solid #ccc;
  border-radius: 4px;
}

7. Intermediate Example

.form-control {
  width: 100%;
  padding: 12px 16px;
  border: 1px solid #94a3b8;
  border-radius: 8px;
  transition: border-color 0.2s, box-shadow 0.2s;
}

.form-control:focus-visible {
  border-color: #2563eb;
  box-shadow: 0 0 0 3px rgba(37, 99, 235, 0.2);
}

8. Advanced Custom Checkbox Control Example

.custom-checkbox {
  appearance: none;
  width: 20px;
  height: 20px;
  border: 2px solid #94a3b8;
  border-radius: 4px;
  display: inline-grid;
  place-content: center;
}

.custom-checkbox:checked {
  background-color: #2563eb;
  border-color: #2563eb;
}

.custom-checkbox:checked::before {
  content: "✓";
  color: white;
  font-size: 14px;
}

9. Line-by-Line Code Explanation

  • appearance: none;: Removes native operating system widget styling to permit custom checkbox designs.
  • place-content: center;: Centers the generated checkmark pseudo-element perfectly inside the box.

10. Expected Terminal / Browser Output

A modern custom checkbox and accessible form input that highlights cleanly when focused via keyboard.

11. Common Mistakes & Pitfalls

  • Setting outline: none without a replacement: Removing focus outlines breaks accessibility for keyboard navigation users.

12. Important Rules & Limitations

  • Always connect <label for="..."> tags to matching input id="..." values for screen reader accessibility.
