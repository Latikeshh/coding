03. History & W3C Standards Evolution of CSS

🟢 Beginner

📖 Definition

CSS was proposed by Håkon Wium Lie on October 10, 1994 at CERN, developed with Bert Bos, and standardized by the World Wide Web Consortium (W3C). Today CSS is maintained as evolving modular specifications.

📜 Historical Milestones Table

StandardYearKey Innovations & Features
CSS11996Basic fonts, colors, margins, text alignment
CSS2 / CSS2.11998 / 2011Absolute/relative positioning, z-index, media types
CSS32011+Modular specs: Flexbox, Grid, Animations, Custom Properties
Modern Living SpecPresentContainer Queries, :has() parent selector, fluid clamp()

💡 Code Example: Modern Living Standard Features

/* Modern CSS with Custom Properties and Media Query */
:root {
  --primary-color: #2563eb;
}

@media (prefers-color-scheme: dark) {
  :root {
    --primary-color: #60a5fa;
  }
}

h1 {
  color: var(--primary-color);
}
