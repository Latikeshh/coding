# 🎨 Learn CSS

CSS stands for Cascading Style Sheets. It is the language that controls the look of a web page: colors, spacing, layout, typography, and design.

> 🟢 **Beginner-friendly:** start with simple selectors and small style changes, then build up from there.

## 📖 What CSS Is Used For

- Change colors and backgrounds
- Adjust text size, font, and spacing
- Add borders and layout structure
- Create buttons, cards, and navigation bars
- Make pages responsive on smaller screens

## 🧪 Practice

For each lesson:

1. Read the definition and example.
2. Copy the code into an HTML file together with a stylesheet.
3. Change one property value.
4. Refresh the page and observe the result.
5. Complete the mini task at the end.

## ✅ Progress Checklist

- [ ] I can connect CSS to an HTML file.
- [ ] I understand how selectors target elements.
- [ ] I can style text, colors, and backgrounds.
- [ ] I know how margins, padding, and borders work.
- [ ] I can use flexbox or grid for layout.
- [ ] I built at least one small styled page.
