# 🎨 Learn CSS

CSS stands for Cascading Style Sheets. It is the language that controls the look of a web page: colors, spacing, layout, typography, and design.

> 🟢 Beginner-friendly: start simple, practice often, and build up from selectors to layouts and responsive design.

## 📖 What CSS is used for

- Change colors and backgrounds
- Adjust text size, spacing, and alignment
- Add borders, shadows, and layout structure
- Create cards, forms, navigation bars, and buttons
- Make pages responsive on different screen sizes

## 🎯 Suggested learning flow

## 🧪 Practice routine

For each lesson:

1. Read the definition and example.
2. Copy the code into an HTML file and link a stylesheet.
3. Change one property value.
4. Refresh the page and observe the result.
5. Build one small variation of the example.

## ✅ Progress checklist

- [ ] I can connect CSS to HTML.
- [ ] I understand selectors and specificity.
- [ ] I can style text, colors, and backgrounds.
- [ ] I know the box model and spacing rules.
- [ ] I can use flexbox and grid.
- [ ] I understand responsive design basics.
- [ ] I built at least one styled page.
