# 🎨 Learn CSS — Cascading Style Sheets & Web Design

Welcome to the **CSS Learning Path**! CSS (Cascading Style Sheets) is the language that controls the visual appearance, styling, layout, typography, colors, animations, and responsive design of web pages.

> 🟢 **Beginner to Advanced:** Start with syntax and selectors, master the Box Model, Flexbox, Grid, CSS custom properties, responsive design, animations, and component styling.

---

## 🌍 Multilingual Explanation / संकल्पना / स्पष्टीकरण

> - **English:** CSS defines how HTML elements are styled and displayed on different screen sizes (colors, fonts, layout, spacing, animations).
> - **Hindi:** CSS वेब पेज को सुंदर बनाता है, जैसे कलर्स, फोंट्स, मार्जिन, पैडिंग, और रेस्पॉन्सिव लेआउट।
> - **Marathi:** CSS वेब पेजचे डिझाईन, रंग, फॉन्ट, जागा (spacing), आणि लेआउट नियंत्रित करते.
> - **Hinglish:** CSS se web page ki styling, colors, layout, flexbox, grid, aur responsiveness control ki jaati hai.

---

## 📖 What You Will Learn

- Connecting CSS to HTML (Inline, Internal, External)
- Selectors, Specificity, Cascade rules, and Inheritance
- Typography, Fonts, Colors (HEX, RGB, HSL, alpha), and Backgrounds
- The CSS Box Model (`content`, `padding`, `border`, `margin`)
- Layout systems: `display` modes, `positioning`, `Float/Clear`, **Flexbox**, and **CSS Grid**
- Responsive Web Design, Media Queries, and viewport units
- Pseudo-classes (`:hover`, `:focus`), Pseudo-elements (`::before`, `::after`)
- Transitions, 2D/3D Transforms, and `@keyframes` Animations
- CSS Variables (Custom Properties), CSS Functions (`calc()`, `clamp()`), and DevTools
- Building styled UI components (Cards, Navigation bars, Forms) and Mini Projects
