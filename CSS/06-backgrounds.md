# Backgrounds

> 🟢 Beginner

## 📖 Definition

Backgrounds are the visual layer behind HTML elements. CSS can change background colors, patterns, and images.

## 🤔 Why Do We Use It?

Backgrounds make layouts look more complete and can help separate sections on a page.

## 🧠 Simple Explanation

A background is like the wall behind a poster. It gives the content space and helps it stand out.

## 📝 Syntax

```css
section {
  background-color: #e8f1ff;
  background-image: url("pattern.png");
}
```

## 💡 Example

```css
.banner {
  background-color: #dfefff;
  padding: 30px;
}
```

## 🌐 HTML + CSS Example

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>School Event</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <section class="banner">
    <h1>Science Fair</h1>
    <p>Join us on Saturday for a day of experiments and projects.</p>
  </section>
</body>
</html>
```

```css
.banner {
  background-color: #dfefff;
  padding: 30px;
}
```

## 👀 What You Will See

The banner section gets a soft blue background and extra space around the text.

## 🧪 Try It Yourself

Give a section a different background color and see how it changes the feel of the page.

## ✅ Remember

- `background-color` changes the solid color behind an element.
- `padding` creates space inside the element.
- Backgrounds can improve readability when used carefully.
