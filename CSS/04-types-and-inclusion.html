04. Types of CSS (Inline, Internal, External & @import)

🟢 Beginner

📖 Definition

CSS can be applied to an HTML document via four methods: Inline CSS (style="..." attribute), Internal CSS (<style> tag in <head>), External CSS (separate .css file linked via <link>), and @import (importing stylesheets inside CSS).

📊 Comparison Table

MethodLocationReusabilityProduction Recommendation
External CSSExternal .css file via <link>Entire WebsiteGold Standard / Best Practice
Internal CSS<style> inside HTML <head>Single Page OnlyOkay for standalone single pages
Inline CSSstyle="..." on HTML tagSingle ElementAvoid! High specificity clutter
@importInside CSS fileStylesheet levelAvoid! Blocks parallel downloads

💡 Code Example: External Link Method (Best Practice)

<!-- Inside HTML <head> -->
<link rel="stylesheet" href="css/style.css">
