04. Types of CSS (Inline, Internal, External & @import)

🟢 Beginner

1. Definition

CSS can be included in HTML documents via four distinct methods: Inline CSS (style="..." attribute), Internal CSS (<style> tag inside <head>), External CSS (separate .css file linked via <link>), and @import directives inside stylesheets.

2. Why It Is Used

Using the proper inclusion method determines maintainability, page load performance, browser caching, and selector specificity control. External CSS is the universal production gold standard.

3. How It Works

When the HTML parser encounters a <link rel="stylesheet"> tag in <head>, it initiates a parallel HTTP request for the external file. In contrast, @import blocks parallel downloading until parent stylesheets finish loading, slowing page performance.

4. Syntax

<!-- External Linking Method (Recommended) -->
<link rel="stylesheet" href="../assets/css/custom.css">

6. Beginner Example

<!-- Inline CSS Example -->
<h1 style="color: #2563eb; text-align: center;">Inline Styled Heading</h1>

7. Intermediate Example

<!-- Internal CSS Example -->
<head>
  <style>
    body { background-color: #f8fafc; }
    .alert-box { padding: 15px; background-color: #fef3c7; border-left: 4px solid #f59e0b; }
  </style>
</head>

8. Advanced Example (External Modular Link)

<head>
  <link rel="stylesheet" href="../assets/css/base.css">
  <link rel="stylesheet" href="../assets/css/layout.css">
  <link rel="stylesheet" href="../assets/css/components.css">
</head>

9. Line-by-Line Code Explanation

  • <link rel="stylesheet" href="../assets/css/base.css">: Links modular CSS stylesheets in sequential order so resets load before layout rules.

10. Expected Terminal / Browser Output

A web page cleanly formatted by external stylesheets where changing one rule in layout.css updates thousands of pages simultaneously.

11. Common Mistakes & Pitfalls

  • Using @import heavily: Nesting multiple @import calls inside CSS creates serial download waterfalls that delay page rendering.

12. Important Rules & Limitations

  • Inline styles override class and ID rules regardless of stylesheet ordering due to highest specificity (1,0,0,0).
