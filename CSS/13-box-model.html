13. The CSS Box Model (box-sizing: border-box)

🟢 Beginner

📖 Definition

The CSS Box Model treats every element as a 4-layered box: Content → Padding → Border → Margin. Universal *, *::before, *::after { box-sizing: border-box; } forces element dimensions to absorb padding and borders inward.

💡 Code Example

*, *::before, *::after {
  box-sizing: border-box;
}

.box {
  width: 300px;
  padding: 20px;
  border: 5px solid #2563eb; /* Total width stays exactly 300px under border-box */
}
