03. Sticky Headers, z-index & Stacking Contexts (isolation)

🟡 Intermediate

1. Definition

position: sticky acts as relative positioning until a scroll threshold is met, whereupon it sticks like fixed positioning within its parent. z-index controls 3D stacking order, and isolation: isolate creates an independent stacking context.

2. Why It Is Used

Sticky positioning keeps table headers and navigation bars visible during scrolling. Stacking contexts prevent z-index battles where child elements accidentally bleed over parent modals.

3. How It Works

Sticky elements remain in flow until top: 0 touches the viewport boundary. Stacking contexts create independent depth layers where z-index values are evaluated locally.

4. Syntax

.sticky-nav {
  position: sticky;
  top: 0;
  z-index: 100;
}

.isolated-card {
  isolation: isolate; /* Creates local stacking context */
}

5. Stacking Order Rules Table

Stack LayerElement TypeDefault z-index
Layer 1 (Bottom)Background & BordersAuto
Layer 2Non-positioned block elementsAuto
Layer 3Positioned elements (relative, absolute, sticky)Explicit z-index number
Layer 4 (Top)Top-layer popovers & dialogsTop Layer Context

6. Beginner Example

.table-header {
  position: sticky;
  top: 0;
  background-color: #f8fafc;
}

7. Intermediate Example

.dropdown-menu {
  position: absolute;
  top: 100%;
  left: 0;
  z-index: 50;
}

8. Advanced Stacking Context Isolation Example

/* Prevents child badge z-index 9999 from bleeding over global navbar */
.card-component {
  position: relative;
  isolation: isolate;
}

.card-badge {
  position: absolute;
  top: -10px;
  right: -10px;
  z-index: 10;
}

9. Line-by-Line Code Explanation

  • isolation: isolate;: Explicitly creates a new stacking context, capping internal z-index values inside .card-component.

10. Expected Terminal / Browser Output

Sticky table headers that remain pinned at screen top during table scrolling without overlapping global page navigation menus.

11. Common Mistakes & Pitfalls

  • Forgetting top: 0 on sticky elements: position: sticky does nothing unless an offset threshold (like top: 0) is declared.

12. Important Rules & Limitations

  • Sticky elements stop sticking when their parent container scrolls completely out of view.
