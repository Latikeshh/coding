16. Float, Clear & Legacy Clearfix Layouts

🟢 Beginner

📖 Definition

float: left / right shifts an element to the side, allowing text content to wrap around it. clear: both prevents elements from wrapping around preceding floated boxes. Clearfixes (e.g. ::after { content: ""; display: table; clear: both; }) prevent parent containers from collapsing around floated children.
