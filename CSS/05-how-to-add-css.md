# How to Add CSS

> 🟢 Beginner

## 📖 Definition

Connecting an external CSS file to an HTML document via the `<link>` element tells the browser where to find and load layout, color, and font rules.

> 🌐 **Multilingual Summary / संक्षेप / स्पष्टीकरण**
>
> - **English:** `<link rel="stylesheet" href="style.css">` connects HTML and CSS files.
> - **Hindi:** `<link rel="stylesheet" href="style.css">` टैग HTML और CSS फाइलों को आपस में जोड़ता है।
> - **Marathi:** `<link>` टॅग वापरून HTML आणि CSS फाइल्स जोडल्या जातात.
> - **Hinglish:** HTML aur CSS ko link karne ke liye `<link rel="stylesheet" href="filename.css">` use karo.

## 📝 Syntax & Attribute Meaning

- `rel="stylesheet"`: Tells the browser the linked resource is a CSS stylesheet.
- `href="style.css"`: Defines the relative or absolute path to the CSS file.

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Linking CSS</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>CSS Connected Successfully</h1>
</body>
</html>
```
